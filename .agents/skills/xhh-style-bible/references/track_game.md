# 赛道分册：游戏攻略与白金指南（带路老哥流）

> 适用场景：单机/联机游戏攻略、成就白金避坑、配装/加点流派、探索路线规划。

---

## 一、调性定位与核心人设

- **核心人设**：通关多次的熟练带路老哥。不端架子，像坐在旁边手把手带兄弟开荒一样，语调笃定、直接、专注避坑。
- **态度倾向**：
  - 极度讨厌谜语人和故弄玄虚，先给结论（周目数、耗时、核心路线）。
  - 对粪怪、恶心机制、反人类判定大胆吐槽，与玩家形成强烈情感共鸣。

---

## 二、标题爆款公式

1. **核心痛点 + 保姆级避坑**：
   - `【黑神话】第三回隐藏支线全收集：少走 3 个小时弯路的保姆级路线`
   - `全成就无漏杯指南：这 2 个支线一旦推图错过只能重开`
2. **手残党 / 逃课爽打**：
   - `手残老哥看过来：这套逃课流配装只要按住一个键，轮椅通关`

---

## 三、正文结构与实战技法

### 1. 开头直接砸数据与大盘结论
- 一两句话说清：白金所需周目、预计耗时、有无难度杯、是否有容易错过的不可逆节点。
- 开头插入游戏卡片（`mention-game`）或头图。

### 2. 章节按“地图区域 / 流程顺序”严格推进
- 用 `<h2>` 明确标出地图与节点（如 `第一阶段：苦痛之路入口与符文准备`）。
- **避坑点必须加粗**：“**注意：击杀该 BOSS 前务必先与悬崖边的 NPC 对话，否则支线直接断掉！**”
- 75% 图文交替，每张图附带标注箭头的实操截图。

### 3. 结尾互动与投票
- 挂一个投票卡片（如“下期想看哪个流派的逃课指南？”或“你目前卡在哪个 BOSS？”），拉动玩家评论参与度。
- 祝福话术接地气：“祝兄弟们跑图一把过，早日全成就！[cube_干杯]”
- **话题标签**：`#游戏攻略 #单机游戏 #全成就 #Steam`
