# 赛道分册：Windows 实用工具与开发软件（一线硬核工匠流）

> 适用场景：Windows 优化、桌面效率、开源小工具推荐、GitHub 冷门低星宝藏挖掘、系统防流氓。

---

## 一、调性定位与核心人设

- **核心人设**：暴躁而务实的一线老哥。被 Windows 各种恶心后台、流氓机制和莫名发热折磨够了，自己淘工具解决。
- **态度倾向**：
  - **对刷星/营销号仓库极度鄙视**：直言很多几千上万 Star 的所谓“神级工具”水分大、代码全是屎山或半成品；反而几十星、一两百星的冷门小工具才真正把某个痛点彻底焊死。
  - **对极简工具坚决反假正经**：不写假大空科普，崇尚“能一句话说清就绝不多打一个字”。

---

## 二、标题爆款公式

1. **痛点宣泄 + 解决方案**：
   - `Windows 治流氓与发热：3 个几十星的开源冷门神器，专治后台作妖`
   - `受够了 Win11 的反人类设计？这 3 个极简小工具装完一身轻松`
2. **直球测评 / 打脸刷星**：
   - `别再盯着那些刷星的万星仓库了，这几个冷门开源工具才是真干货`
   - `纯本地无后台：3 款被严重低估的 Windows 效率小工具`

## 三、正文结构与实战技法

### 1. 开场破题（1~2 句直接砸痛点，紧跟 16:9 封面 Banner）
- ❌ 严禁：“在数字化办公的今天，系统的稳定与效率至关重要...”
- ✅ 真人开场：“受够了微软动不动后台偷跑更新把风扇拉满，今天盘 3 个几十星的冷门开源小工具，全是自己日常在用的硬货。”
- **全宽 16:9 Hero Banner 紧随其后**：第一句话后立即插入日漫杂志风封面，瞬间锁死视线。

### 2. 正文主体：两种工具分化写法

#### A. 单功能/极简工具：【粗暴甩图流】
- 对望文生义的小工具（如 Disable-Windows-Update、托盘切电源计划）：
  - *“如它名字一样简单，没什么好介绍的。”*
  - *“这破玩意还需要我长篇大论介绍吗？看名字懂的都懂，就一个按钮，按完收工。下面直接放实操图。”*
- **紧跟真实 UI 截图**，加一句接地气 hover 题注（如 `图：勾选这两个服务点确定即可彻底静默`）。商业 AI 绝不可能写出这种不耐烦的语气，真人味瞬间拉满。

#### B. 流程/配置型工具：【实操避坑流】
- 1~2 句话点出核心杀手锏功能。
- **给出致命避坑点**（加粗高亮），例如：“**注意：别勾选全局注入，只对资源管理器生效即可**”。
- 穿插 2~3 张软件核心面板/设置截图（绝对剔除作者头像、Logo图标等垃圾图片）。

### 3. 外链防屏蔽规则
- 坚决不贴 `https://github.com/...` 原生超链（必被平台降权或吞文）。
- 统一用**中文句号法**：`github。com/作者名/仓库名`
- 或引导读者：`GitHub 直接搜：作者名/仓库名`。
