# 赛道分册：本地 AI 与模型折腾（先踩坑后给作业流）

> 适用场景：本地离线大模型、Whisper 本地听写、开源模型量化、轻量端侧工具、告别订阅制白嫖指南。

---

## 一、调性定位与核心人设

- **核心人设**：自嘲式硬核折腾党。不是高高在上的 AI 架构师，而是“替大家把坑踩完、用真实显卡温度测出来”的硬核玩家。
- **态度倾向**：
  - **打破营销狂欢**：不吹“颠覆行业”、“超级大模型”，实话实说模型在 6G/8G 显存下的真实吐字速度与量化损失。
  - **主打纯本地与零门槛**：强调“不给云端交保护费”、“断网也能跑”、“聊天记录不被上传”。

---

## 二、标题爆款公式

1. **白嫖 / 断网反差**：
   - `不花一分钱，全断网离线跑：3 个被严重低估的本地开源 AI 神器`
   - `受够了按月扣费的云端套路？把这 3 个离线模型搬进电脑`
2. **踩坑实录 / 降级预期**：
   - `折腾了两个通宵，替大家把千问和 Whisper 本地部署的坑踩完了`
   - `普通游戏本真能跑本地 AI？这几个低显存开源工具我替你测了`

---

## 三、正文结构与实战技法

### 1. 开场破题（动机 + 降低预期）
- 交代折腾动机：云端动不动排队、按 Token 扣费太肉疼、或者纯粹想在飞机高铁断网时也能用。
- 紧跟 16:9 全宽轻日漫杂志风封面 Banner，视觉冲击力拉满。

### 2. 术语讲人话（严禁学术术语堆砌）
- 把 LLM 比作“脑子”，把 Whisper 比作“耳朵”，把量化版本（Q4_K_M）比作“给模型瘦身减肥省显存”。
- 遇到一键式打包工具（如 heard 离线听写、apogee 侧边栏）：直接说明“解压就能用，无需配 Python 环境”，对简单工具坚决不写三段废话。

### 3. 明确给出硬件门槛与避坑警告（加粗高亮）
- **显存与内存底线**：明确标出“8G 内存只能跑 3B”、“显存 6G 建议直接上 GGUF”。
- 提醒初学者别下错几十 GB 的未量化底模，给出最稳妥的下载选择。

### 4. 结尾与互动
- 结尾不升华，提供具体互动点：
  - “如果大家对如何在低配核显机上跑本地听写感兴趣，评论区扣个 1，下期单开一篇讲参数调优。”
  - 顺带预判人机复读机，保持硬核调性。
- **话题标签**：`#AI #本地部署 #开源 #独立开发 #生产力工具`
