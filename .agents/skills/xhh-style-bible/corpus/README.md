# 小黑盒热帖语料库（xhh-corpus）

给「去 AI 味 + 赛道/题材」skill 练手用的**真帖语料**。全部来自小黑盒社区热榜/搜索。

筛选口径（2026-10-24 用户拍板）：
- **常规赛道**（AI/CodeX/杂谈/校园）：只要**参与创作计划（帖子可充电）**且**正文 ≥150 字**的帖子。
  纯图水帖和不在创作计划的帖子已被过滤（实测热榜按点赞排最前的帖子大多不可充电、正文为空，
  跟"值得学的创作"是两拨人）。
- **游戏攻略赛道**：**站内搜索跨游戏采集**（关键词：攻略/全成就/通关攻略/配装推荐/新手攻略/mod教程），
  不卡可充电，但要求话题里有**具体游戏社区**（只有 Steam/数码硬件这类泛话题的一律不算），
  且正文 ≥150 字。练语料的核心标准就一条：**写得像人**。
  （实测攻略作者其实大量参与创作计划——本赛道 66 篇里 38 篇可充电，空洞骑士攻略被充 1.6 万次）

采集时间：2026-10-24。采集方式见「怎么采的」。

| 字段 | 含义 |

## 怎么采的（复用要点）

1. **接口有签名，不能裸 fetch**：信息流 `/bbs/app/topic/feeds`、详情 `/bbs/app/link/tree`
   都要 `hkey` 动态签名，脚本拼不出来。解法是**搭页面自己的请求便车**：
   滚动页面触发分页请求，用 playwright 监听 response 拿数据。
2. **热榜排序**：话题页默认就是 hot-rank（`h_src` 解码可见），不用改参数。
3. **可充电判定**：详情页 `/bbs/app/link/tree` 响应里 `result.link.battery.enabled == 1`
   即该帖参与创作计划可被充电；`battery.count` = 已被充电人数（高质量创作的好指标）。
   ⚠️ 别用 `is_author_award`——那是评论作者维度的字段，会误判。
4. **全文抽取**：详情页 SSR，全文在 `document.body.innerText`，按「标题→全部评论」标记切片。
5. 帖子页 URL：`https://www.xiaoheihe.cn/app/bbs/link/<linkid>`。

## 拿它练「去 AI 味 + 赛道」skill 的建议路径

### 第一步：从语料里拆「人味」特征（对比 AI 味清单）
对照着读 `by_track/` 里的高充电帖，把特征写进 skill：
- **图怎么放/组件怎么用**：先读 `layout_stats.md` 的「写法启示」——图文穿插是主流、列表是 AI 味重灾区、
  投票是互动钩子、最高充电帖 cube 表情为 0，这些都有数据背书
- **开头**：真人几乎不写"在当今快速发展的时代"，直接甩场景/结论（stats.md 有 20 条开头采样）
- **句长**：短句、口语连词（"就""其实""讲真""绷不住"），一段最多 2~3 句
- **节奏**：先给结论/成果再讲过程；敢用不完整句
- **瑕疵感**：真人会有 typo 式随意、括号补丁（"（别学我）"）、自嘲
- **cube 表情**：放情绪点不放装饰位，一段最多 1~2 个
- **AI 味黑名单**（从反面总结）："首先/其次/总之"、"值得注意的是"、"让我来为大家"、
  排比三连、每段等长、结尾升华

### 第二步：按赛道做调性卡
每个赛道读 Top 10，提炼：标题句式（数字/疑问/悬念比例见 stats.md）、
正文结构（教程帖的步骤颗粒度）、话题标签习惯（见 stats.md 高频标签）、
互动钩子（评论区扣 1 / 投票 / 提问结尾）。

### 第三步：做成 skill 的形态建议
- 一个 `xhh-style-bible` skill：调性卡（按赛道）+ 人味特征清单 + AI 味黑名单 +
  cube 表情使用规范（表情全名见 post-xiaoheihe skill 的 assets/cube_emojis.json）
- 用语料当 few-shot：每个赛道挑 3~5 篇充电最高的做范文
- 验收标准：写完的稿子往 stats.md 的特征分布上靠（长度落在该赛道 P25~P75）

### 已知的坑（别再踩）
- 热榜高赞 ≠ 好范文：纯图水帖点赞很高但不可充电，常规赛道已过滤；游戏赛道例外不过滤（见筛选口径）
- 游戏社区热榜帖绝大多数是纯图（以撒 253 帖热榜只有 17 篇 ≥150 字），
  所以游戏赛道改走**站内搜索**抓攻略帖——搜索能直接命中"全成就/配装/通关"这类写法样本
- `description` 字段对图文帖是全文，对文章帖只是摘要，全文一律用 `full_text`
- 游戏攻略赛道不卡可充电（但实测 66 篇里 38 篇可充电，攻略作者其实大量参与创作计划）
