# 小黑盒写作风格库（xhh-style-bible 2.0 · 渐进式精简版）

> 本库基于 **167 篇可充电热帖** 深度审计重构。
> 采用 **渐进式披露（Progressive Disclosure）** 架构：通用人味总纲常驻，具体赛道分册按需读取，杜绝上下文浪费。

---

## 一、真实小黑盒爆款的“三大核心人味密码”

1. **真实的狼狈感与免责式自嘲（主动劝退/降低预期）**
   - **AI 的毛病**：永远全知全能、客观完美、热心鼓励。
   - **真人的做法**：先泼冷水、交代局限、袒露狼狈（“笔者上学是法学专业，不曾系统学过编程，注定不具备什么专业性，纯当玩嘛”）。
2. **烟火气与具体物理场景（拒绝虚浮的抽象名词）**
   - **AI 的毛病**：“提升学习效率”、“实现多场景智能化管理”。
   - **真人的做法**：“大一买教材花了600，生活费只剩800”、“宿舍晚上十一点准时拉闸熄灯断网”、“把笔记本塞书包带去图书馆自习”。
3. **鲜明的主观偏见与直接吐槽（坚决打破中立客观）**
   - **AI 的毛病**：“A 与 B 各有千秋，用户应根据自身场景权衡选择。”
   - **真人的做法**：“作为腾讯出品，臃肿卡顿影响智商，但看在白送积分的份上...（腾讯嘛......）”。

## 二、真人写作十大总纲（核心执行准则）

1. **开场要“个人动机唠嗑”，而不是“宏大背景科普”**：直接交代为什么折腾、遇到了什么恶心痛点，坚决禁止“随着...的发展”。
2. **呼吸感句式**：允许口语长难逗号流，长短句自然错落，段落控制在 2~4 行（适合手机阅读）。
3. **真实口语与情绪词**：高频词为 **其实、说白了、直接、顺手、真不行、完蛋、哦豁、这破玩意、老实说**；善用括号吐槽 `（别学我）`。
4. **拒绝机械对称列表**：严禁 AI 式“1. 高效性 2. 便捷性”；只允许真实的步骤分步推进。
5. **加粗只放结论与避坑点**：如 **必须选 Debian 13**、**别随意禁用 Windows Update**，绝不加粗整段大话。
6. **图文穿插与 16:9 Hero 封面**：
   - 封面优先做成 16:9 横版轻日漫风，**紧跟在开场第一句灵魂破题之后作为 Hero Banner**。
   - 75% 篇幅保持图文交替穿插，下方配接地气题注，严禁文章末尾堆图集。
7. **Cube 表情克制使用**：正经干货 0 表情，杂谈/吐槽 1~3 个，专攻翻车打脸处（如 `[cube_摸鱼]`、`[cube_泪目]`）。
8. **结尾不升华，留白或给具体动作**：留白、催更、或直白下班收工（“欧克，本期就到这里，打完收工，下期见！”）。
9. **极简工具“粗暴甩图流”（反 AI 虚伪长篇大论）**：
   - 遇到望文生义、单功能小工具，坚决不写三段虚伪科普，直接简单粗暴：
     *“如它名字一样简单，没什么好介绍的。”*
     *“这破玩意还需要我介绍吗？看名字懂的都懂，就一个按钮，按完收工，下面直接放实操图。”*
10. **评论区人机“降维预判打击法”（反向预判扣帽子机器人）**：
    - 针对社区里无论写得多硬核都要机械复读“又是AI”的低智杠精，在开头或收尾直接反向预判：
      *“另外提前预判评论区某些老哥：别天天在评论区当上下文比老旧豆包还短的劣质小模型了，见个排版整齐的帖子就只会复读‘又是AI’，稍微用用脑子，幻觉比劣质AI还重。有疑问的正常老哥评论区抓我，下期见！[cube_干杯]”*

## 三、AI 味终极黑名单（交稿前扫描）

| 维度 | 严禁出现的 AI 恶习 | 真人自然表达替换方案 |
| :--- | :--- | :--- |
| **开篇** | 随着...的发展、在当今快节奏的...中、众所周知 | 直接说遇到什么坑、为什么折腾、或直接甩结论 |
| **连接词** | 首先 / 其次 / 再次 / 综上所述 / 总而言之 | 第一步、另外、说个关键的、老实说、顺带提一嘴 |
| **假大空** | 赋能、闭环、抓手、维度、深度融合、提升生产力 | 能替我省两个小时、少掉几根头发、纯粹白嫖爽到了 |
| **客套废话**| 希望这篇文章能够对您有所帮助、让我们拭目以待 | 觉得有用点个赞就行、赶紧去领防抢光、有问题评论区抓我 |
| **生硬外链**| 直接放 `https://github.com/...`（必被降权/吞文） | **中文句号法**：`github。com/xxx/yyy`；或写 **GitHub搜索：作者/仓库** |
