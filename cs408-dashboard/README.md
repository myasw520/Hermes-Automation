# 408 计算机考研全景知识图谱与院校择校智库 (工程化版)

本项目是针对 408 计算机统考高分备考与标杆院校择校深度打造的高清、高交互、模块化数据看板。

---

## 📁 模块化项目结构

```
cs408-dashboard/
├── index.html                  # 模块化页面入口
├── server.py                   # 本地 Python 轻量 HTTP 服务
├── start.bat                   # Windows 一键启动脚本 (双击运行)
├── css/
│   ├── base.css                # 主题变量、重置、全局滚动条定制
│   ├── layout.css              # 侧边栏导航、主视口、Flex 滚动布局
│   ├── graph.css               # 拓扑图 Canvas 布局、悬浮 HUD、鹰眼导航仪、详情抽屉
│   └── colleges.css            # 院校数据库表格、固定表头、分页栏、避坑指南
└── js/
    ├── data/
    │   ├── colleges-data.js    # 18 所标杆高校 2023-2025 逐年线数据库
    │   ├── syllabus-nodes.js   # 408 全考纲 47 个核心知识节点
    │   └── syllabus-links.js   # 基础知识链与跨学科 7 大压轴命题链路
    ├── graph-engine.js         # 高清 Retina Canvas 引擎 (自适应居中、平移缩放、鹰眼小地图)
    ├── colleges-view.js        # 院校多维筛选、实时检索、分页翻页引擎
    └── app.js                  # 路由控制与全应用入口
```

---

## 🚀 启动与使用方式

### 方式一：双击启动 (推荐)
直接双击运行目录下的 **`start.bat`** 脚本，系统将自动启动轻量 Python 本地服务器并在默认浏览器中弹出看板页面 (`http://localhost:8088`)。

### 方式二：命令行启动
```bash
python server.py
```

## 🌟 核心特性与解决的痛点

1. **彻底解决“不能翻动/不能滚动”问题**：
   - 修复 CSS Flex 容器 `min-height: 0` 无法触发垂直滚动条的规范性 Bug。
   - 院校表格增加 **分页翻页控件 (`[上一页] [1] [2] [下一页]`)** 与 **固定表头 (Sticky Header)**，数据翻阅顺畅自如。
2. **彻底解决“拓扑图字体看不清楚”问题**：
   - 接入物理级 `window.devicePixelRatio` 原生像素渲染管线，在 Windows 125%/150% 等高缩放屏幕上文字与连线如矢量图般锐利。
   - 考点全部采用 **12px~14px 粗体 + 独立防眩光胶囊衬底 (Capsule Pill)**，杜绝连线干扰。
3. **全景自适应与自由导航**：
   - 打开即自动全景居中 (`fitToScreen`)，47 个考点无缝落入视野中心。
   - 支持鼠标左键拖拽平移、滚轮平滑缩放/平移模式一键切换、方向键微调、双击自适应居中。
   - 配备 **画中画鹰眼全景导航仪 (Minimap)**，点击或拖动小地图即可任意区域快速漫游。
4. **易维护、易拓展**：
   - 院校数据、知识点、核心逻辑完全解耦为独立模块，方便后续对接爬虫或自动化持续更新。
