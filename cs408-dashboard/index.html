⚠️ 计算机考研小白必读：4 大致命“认知陷阱”避坑红宝书 数据采集时间：2026年10月21日 · 权威研招网对齐
1. 复试线 ≠ 录取线（断层陷阱）

院线只是入围线！因差额复试比（120%-150%），真实录取最低分/中位数往往比复试线高出 25~45分！目标初试分务必参考拟录取名单。

2. 招生计划 ≠ 统考名额（推免陷阱）

简章写招100人，顶尖985推免率高达 70%~80%，实际留给统考仅10~20人！务必在研招网查阅《拟录取推免生名单》扣除推免。

3. 专硕住宿政策黑洞（经济陷阱）

清华深研院、北大、复旦、南开等高校专硕已明确不提供校内宿舍！一线城市校外租房每年额外支出 3~5 万元，报考前必须算清账。

4. 408 统考调剂优势（退路陷阱）

考408统考是全网通调剂，绝大多数院校接受408调剂；若选自命题，不仅高校改考408无法调剂，压分自命题更直接断送调剂生路。

⚖️ 计算机考研公共课抉择：选“11 (数一+英一)” 还是 “22 (数二+英二)”？ 官方大纲对齐
方案 A：选考“11 (数一 + 英一)” —— 适合学硕/直博
  • 考查范围：高数(56%) + 线代(22%) + 概率论(22%)。全大纲覆盖，含三重积分、曲线曲面积分、无穷级数。
  • 复习工作量：约为数二英二的 1.6 ~ 1.8 倍，需投入极多时间死磕高数生僻章节。
  • 调剂优势：高调低霸权。初试考数一英一者，调剂时可单向申请要求数二英二的专硕院校。
方案 B：选考“22 (数二 + 英二)” —— 【小白首选黄金组合】
  • 考查范围：高数(78%) + 线代(22%)。彻底不考概率论！砍掉三重积分、曲线曲面积分、级数。
  • 复习工作量：公共课省下数百小时，能够腾出核心战略时间死磕 408 统考与做题。
  • 性价比：专硕招考名额占全国 80% 以上，找大厂工作和待遇与学硕完全一致。

🇬🇧 英语一 vs 英语二 题型与提分难度对比

1. 阅读理解 (Part A 40分)

英一：长难句抽象，多选自英美哲理与社科期刊，题目陷阱多，过线难。
英二：多选自商业、科技与社会生活，文章主旨清晰，答案定位更直接，均分普遍高 8~12 分。

2. 翻译题型 (Part C 10~15分)

英一 (10分)：从极难学术长文中挑出 5 个超长句，生词怪词多，全国均分仅 3~4 分。
英二 (15分)：通篇翻译一段约 150 词的连贯小短文，语境流畅，得分率普遍在 10 分以上。

3. 写作大作文 (Part B 15~20分)

英一 (20分)：图画作文，需要准确提炼漫画中的深层哲理寓意并升华。
英二 (15分)：图表作文（柱状/饼状/折线），三段式套路模板极度规范，提分见效快。

经典 41 题：双指针快慢扫描（链表判环与找中点） 
// 寻找单链表中点/倒数第k个结点

ListNode* findMiddle(ListNode* head) {

    if (!head || !head->next) return head;

    ListNode *slow = head, *fast = head;

    while (fast && fast->next) {

        slow = slow->next;          // 慢指针步长 1

        fast = fast->next->next;    // 快指针步长 2

    }

    return slow; // 当fast到底时，slow恰好位于中点

}

// 时间复杂度: O(N) 一趟遍历; 空间复杂度: O(1) 仅需指针常数空间
操作系统：经典生产者-消费者 PV 信号量模板 
semaphore mutex = 1;     // 互斥信号量：保护缓冲区互斥访问

semaphore empty = N;     // 资源信号量：空闲缓冲区数量

semaphore full = 0;      // 资源信号量：已存放的产品数量

void producer() {

    while (1) {

        Item item = produce_item();

        P(empty);       // 先申请空位 (防止死锁，必须先P资源再P互斥)

        P(mutex);       // 加锁缓冲区

        put_into_buffer(item);

        V(mutex);       // 解锁缓冲区

        V(full);        // 增加就绪产品

    }

}

void consumer() {

    while (1) {

        P(full);        // 先申请产品

        P(mutex);       // 加锁缓冲区

        Item item = take_from_buffer();

        V(mutex);       // 解锁缓冲区

        V(empty);       // 归还空位

        consume_item(item);

    }

}
