# 小红书爆款笔记数据集与质量校准交付文档 (XHS Viral Notes Dataset Delivery)

## 一、 项目背景与交付概述
本数据集专为校准 **「xhs-note-craft」Skill** 的文案生成与质检规则而采集，通过大样本真实统计，将传统的“经验主义直觉”转变为“具备数学支撑的真实分布基准”。

- **样本总量**：214 条真实高赞爆款样本（单篇点赞数 ≥ 10,000，最高超 10 万+）
- **时间范围**：近 6 个月内发布的活跃爆款笔记
- **垂直领域**：覆盖 6 大核心赛道（职场/效率、生活/情感、学习/考证、美食/旅行、好物/工具、美妆/穿搭）
- **官方合规规范**：包含小红书《社区公约》、《社区规范》、《违规处罚说明》、《创作者学院笔记发布规范》4 份完整官方原文文档。

## 四、 核心数学统计结论与 Skill 校准映射表

基于 214 条真实样本动态统计，对比原规则得出的关键校准结论如下：

| 校验维度 | 原先经验规则 | 真实样本统计基准 | 校准建议 (Action Item) |
| :--- | :--- | :--- | :--- |
| **话题标签 (Tags)** | 建议 5~8 个，超过扣分 | **≥8 个标签占 62.6%**（打满 10 个占 30.8%） | **放宽至 5~10 个**，取消 8~10 个标签的扣分判定 |
| **表情符 (Emoji)** | 必须包含 5~12 个，否则扣分 | **48.6% 的爆款完全为 0 Emoji**（均值仅 4.3 个） | **废除强制数量下限**，Emoji 改为风格增强项而非硬指标 |
| **标题表情 (Title Emoji)**| 与正文混合统计 | **19.6% 标题包含 1~2 个 Emoji** | **标题与正文拆分**，允许标题包含 1~2 个吸睛 Emoji |
| **正文字数 (Body Length)**| 笼统要求 > 200 字 | 中位数 310.5 字，均值 410.8 字（300~800 字占 34.1%） | **分垂类设定字数底线**（干货考证 ≥300 字，穿搭好物 ≥150 字） |
| **标题数字化 (Hook)** | 推荐带数字 | **28.0% 标题包含清晰阿拉伯数字** | 在 Hook 模型中对含具体数字、对照的标题给予**显式加分** |
| **纯图笔记 (Carousel)** | 混在文案规则质检 | 纯图流（仅标签 0 字文案）占 1.9% | **纯图与图文分流**，纯图流只检配图张数与视觉标签 |
