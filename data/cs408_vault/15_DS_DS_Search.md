# 📚 408 考点深度剖析与变式题库：查找与散列表(Hash)

## ⚡ 一、核心考点秒懂精髓

- **折半查找**：每次比较将查找区间缩小一半，判定树是平衡的二叉排序树形态。n 个元素的判定树形态唯一（由 ⌊(low+high)/2⌋ 取中间点决定），树高 h = ⌊log₂n⌋+1，第 i 层结点比较次数为 i，ASL = Σ(每层结点数 × 层号)/n。
- **散列表**：以 O(1) 均摊时间通过散列函数 H(key) 直接定位。冲突处理中：
  - **线性探测法**：易产生“堆积（聚集）”，删除只能打懒惰标记，查找成功 ASL 需逐元素数比较次数；
  - **二次探测法**：探测序列为 +1², −1², +2², −2²,…（408 标准序列），避免堆积；
  - **链地址法**：同义词挂同一链表，新元素**头插或尾插（真题默认插入链表头部）**。
- **装填因子** α = 表中元素数 / 表长。三种冲突处理方法的 ASL 都是 **α 的函数，与表长 n 无关**（这是重要理论结论）。

**考场口诀**：
> 折半 ASL = 各层结点数×层号之和 ÷ n；散列 ASL 成功 = Σ每个元素比较次数 / 元素数，失败 = Σ空位前的探测次数 / 散列地址数（模 m 的余数个数，不是表长之外的数——失败 ASL 分母恒为散列函数的模值范围）。
> 快捷式：链地址法成功 ASL ≈ 1 + α/2（近似），线性探测成功 ≈ (1+1/(1−α))/2，失败 ≈ (1+1/(1−α)²)/2（理论公式，计算大题必须按定义逐个手数）。

## ⚠️ 二、考场高频杀手陷阱透析

**陷阱 1：查找失败 ASL 的分母与计算范围错误**
查找失败时，分母是**散列函数的模值个数**（如 H(key)=key%13，则分母是 13，从地址 0 到 12 逐个模拟失败探测），而不是表长 m（若表长为 16，地址 13~15 根本不可能被 H 函数映射到，不计入）。考生常错用表长 16 作分母。同理，线性探测失败时，从地址 p 出发一直数到**第一个空位置**（含空位本身的那一次比较），若一直探测到表尾回绕，需注意循环（408 默认不回绕的题目居多，务必读题）。

**陷阱 2：线性探测下“元素位置 ≠ 散列地址”，回推比较次数出错**
元素插入时若冲突会漂移到后面的空位；计算成功 ASL 时必须**按最终存储位置反推该元素的散列地址**，再数从 H(key) 到实际位置的比较次数。考生易犯错误：直接按地址顺序数，或忘了某些后面元素探测时要跳过前面已占位置（间接增加比较次数——这就是堆积效应）。

**陷阱 3：折半查找判定树中点选取规则与删除元素后 ASL 变化**
408 规定 mid = ⌊(low+high)/2⌋。当区间长度为偶数时取**中间偏左**（小的那个）元素为根。考生手绘判定树时若按“向上取整”画，整棵树结构全错。另外，判定树中**失败结点（外部结点）的比较次数 = 其父结点所在层号**，计算失败 ASL 时容易把失败结点层级数错一层。

**陷阱 4（附加）：α 上限问题**
线性探测要求 α ≤ 1（表必须有空位），链地址法可 α > 1；α 越大 ASL 越大，但**α 与 ASL 是统计平均关系，不保证个例**——选择题问“α 小则一定快”是错的。

## 🎯 三、经典真题同源变式题 1（单项选择）

【题目背景】
设散列表长度 m = 11，散列函数 H(key) = key mod 11，采用**二次探测法**处理冲突（探测序列：H+1², H−1², H+2², H−2²，对结果取 mod 11）。依次插入关键字序列：22, 33, 44, 55, 66, 77。查找成功时的平均查找长度为（ ）。

A. 1.5　　B. 2.0　　C. 2.5　　D. 3.0

【正确答案】：**B**

【深度解析】：
逐个插入（mod 11）：
- 22 → H=0，空，放地址 0（1 次比较）
- 33 → H=0 冲突；+1²→1 空，放地址 1（2 次）
- 44 → H=0 冲突；+1²→1 冲突；−1²→(0−1)mod11=10 空，放地址 10（3 次）
- 55 → H=0 冲突；1 冲突；10 冲突；+2²→4 空，放地址 4（4 次）
- 66 → H=0 冲突；1 冲突；10 冲突；4 冲突；−2²→(0−4)mod11=7 空，放地址 7（5 次）
- 77 → H=0 冲突；1 冲突；10 冲突；4 冲突；7 冲突；+3²→9 空，放地址 9（6 次）

ASL成功 = (1+2+3+4+5+6)/6 = 21/6 = **3.5**？

——修正验证：注意探测序列 408 标准是 +1², −1², +2², −2² 交替，上面推导正确。故精确值为 3.5，但选项中无 3.5。**这正是本题的设计陷阱所在**——若考生误用线性探测：22→0，33→1，44→2，55→3，66→4，77→5，ASL = (1+2+3+4+5+6)/6 = 3.5 相同？

换正确命题数据重新给题（保证严谨）：

【修订题目】设散列表长度 m = 13，H(key) = key mod 13，采用**线性探测法**。依次插入关键字：14, 27, 40, 53, 66, 79, 1。查找成功时 ASL 为（ ）。
计算：14→1（1次）；27→1冲突→2（2次）；40→1冲突→2冲突→3（3次）；53→1,2,3冲突→4（4次）；66→1..4冲突→5（5次）；79→1..5冲突→6（6次）；1→1,2,3,4,5,6冲突→7（7次）。
ASL = (1+2+…+7)/7 = 28/7 = **4.0**。

A. 3.0　　B. 3.5　　C. 4.0　　D. 4.5

【正确答案】：**C**

【深度解析】：
- 全部关键字 mod 13 均为 1，依次线性堆积，第 k 个插入元素比较 k 次，ASL = 28/7 = 4.0，选 **C**。
- A（3.0）：误以为比较次数从 0 计数或漏算最后一次命中比较。
- B（3.5）：误按链地址法计算（每条同义词链尾插，长度 7，ASL=(7+6+…+1)/7 同为 4；但若误用近似公式 1+α/2 = 1+7/26 ≈ 1.27 也非 3.5）——典型干扰来自公式滥用。
- D（4.5）：误把失败探测也计入成功查找，或多算一次空位比较。

## 🚀 四、经典真题同源变式题 2（综合应用/大题）

【综合大题】
已知散列表长度 m = 13，散列函数 H(key) = key mod 13，采用**线性探测法**处理冲突。依次插入关键字序列：
**{26, 36, 41, 38, 44, 15, 68, 12}**

(1) 画出散列表最终存储状态（地址 0~12）。
(2) 计算装填因子 α。
(3) 分别计算查找成功和查找失败的平均查找长度 ASL。
(4) 编写 C 代码函数 `int HashSearch(int T[], int key)`：在长度 13 的线性探测散列表 T 中查找 key，返回比较次数（未找到返回 −1）；要求不使用循环回绕（探测到表尾即失败），时间 O(m)。

【解题思路】：
1. 逐个计算 H(key)，冲突则线性探测下一空位，记录每个元素最终位置及比较次数。
2. α = 元素数/表长 = 8/13。
3. 成功 ASL：Σ比较次数/8；失败 ASL：对地址 0~12 逐个模拟从该地址到第一个空位（含）的探测次数，Σ/13。
4. 代码模拟探测过程并计数。

【参考步骤/代码】：

插入过程：
- 26→0（1次）；36→10（1次）；41→2（1次）；38→12（1次）；44→5（1次）；15→2冲突→3（2次）；68→3冲突→4（2次）；12→12冲突→0冲突→1（3次）。

最终表：

| 地址 | 0 | 1 | 2 | 3 | 4 | 5 | 6~9 | 10 | 11 | 12 |
|---|---|---|---|---|---|---|---|---|---|---|
| 关键字 | 26 | 12 | 41 | 15 | 68 | 44 | 空 | 36 | 空 | 38 |

- α = 8/13 ≈ 0.62
- ASL成功 = (1+3+1+2+2+1+1+1)/8 = 12/8 = **1.5**
- 失败探测次数（到第一个空位，含空位）：
  - 地址0：0空？否，0有26→1有12→2有41→3有15→4有68→5有44→6空：7次
  - 地址1：1~5占用→6空：6次；地址2：5次；地址3：4次；地址4：3次；地址5：2次；地址6：空1次；地址7：1次；地址8：1次；地址9：1次；地址10：10有36→11空：2次；地址11：1次；地址12：12有38→（到表尾，按题意不回绕则失败需13次比较；若按回绕计则12→0…→6空共8次）——**取回绕约定**：12→0,1,2,3,4,5,6空：8次。
  - Σ = 7+6+5+4+3+2+1+1+1+1+2+1+8 = 42
  - ASL失败 = 42/13 ≈ **3.23**

```c
#define M 13
#define NULLKEY -32768   // 空位标记

int HashSearch(int T[], int key) {
    int addr = key % M, cnt = 1;
    while (cnt <= M) {                 // 不回绕：最多探测 M 次
        if (T[addr] == key) return cnt;         // 命中
        if (T[addr] == NULLKEY) return -1;      // 遇空位，查找失败
        addr++;                        // 线性探测下一地址
        cnt++;
        if (addr >= M) return -1;      // 到表尾，约定不回绕即失败
    }
    return -1;
}
```

插入函数（配套）：

```c
void HashInsert(int T[], int key) {
    int addr = key % M;
    while (T[addr] != NULLKEY) addr++;   // 线性探测找空位
    T[addr] = key;
}
```

【时空复杂度分析】：
- **时间**：查找/插入最坏探测整个表（如本题全部同义词堆积），为 O(m)；平均意义下 ASL 仅为 α 的函数，成功约 O(1/(1−α))，均摊 O(1)。
- **空间**：散列表本身 O(m)，查找与插入过程仅用常数个辅助变量，额外空间复杂度 O(1)。
- **注意**：本题约定“探测到表尾不回绕”，若题目要求循环回绕，则 `addr = (addr+1) % M` 且需用“探测满一圈”判停，失败 ASL 计算也应相应回绕——此约定差异是近年大题区分度来源，务必依题作答。
