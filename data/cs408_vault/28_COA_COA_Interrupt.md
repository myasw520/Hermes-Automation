# 📚 408 考点深度剖析与变式题库：中断系统与异常处理

## ⚡ 一、核心考点秒懂精髓

**底层核心机制：**
- **内中断（异常）**：来自 CPU 内部、与当前指令执行相关，同步发生。分类：**故障**——可修复，修复后重新执行该指令，如缺页、越界、除零；**陷阱**——程序有意安排（系统调用、条件陷阱指令），执行“下一条”指令前转入；**终止**——硬件致命错误（如内存校验错），直接终止进程。
- **外中断（中断）**：来自 CPU 外部、与指令流异步。分为**可屏蔽中断**与**不可屏蔽中断（NMI）**。
- **中断隐指令**（硬件自动完成，不是指令集里的指令）：①**关中断**；②**保存断点**（PC、PSW）；③**引出中断服务程序**（向量地址→取 ISR 入口，方式：向量中断 / 软件查询）。
- **多重中断（中断嵌套）**：前提是**开中断**（ISR 保存现场和屏蔽字后置开中断）；运行中的服务程序通过设置**中断屏蔽字**动态改变**响应处理优先级**——屏蔽字中"1"表示屏蔽该位对应的中断源，**屏蔽字中 1 的个数越多，处理优先级越高**；自身位必须置 1。响应优先级由硬件排队器固定，不可更改；处理优先级由屏蔽字可变。

**记忆口诀：**
> **“隐指令三件事：关中断、存断点、找入口；屏蔽字多一个 1，处理优先级高一级。”**
> **“响应排队硬件定，处理优先屏蔽改；内同步外异步，故障重来陷阱走。”**

## ⚠️ 二、考场高频杀手陷阱透析

**陷阱 1：断点返回位置混淆——Fault 回本条，Trap 回下一条。**
缺页中断（Fault）处理完必须**重新执行发生缺页的那条指令**（PC 不自动 +1 或保存的是本条指令地址）；而陷阱指令（如 int/system call）执行完后返回**下一条指令**。408 选择题常设“缺页中断返回后从下一条指令执行”的假说法。同时注意：每条指令执行**结束前** CPU 会扫描是否有外中断请求，故外中断检测点是“指令周期末尾”。

**陷阱 2：保存断点 vs 保存现场的责任主体混淆。**
**中断隐指令（硬件）只保存 PC 和 PSW（断点）**；通用寄存器等**现场由中断服务程序（软件）负责保存**。同理，恢复现场、开中断由 ISR 末尾的**中断返回指令 iret（属于最后一条指令的软件动作范畴）**完成。选项“隐指令保存所有通用寄存器内容”必错。

**陷阱 3：屏蔽字与优先级的正反推算错误。**
- 考生常把屏蔽字矩阵**按行看错方向**：标准约定**第 i 行第 j 列为 1 表示 i 能屏蔽 j**；对角线恒为 1。
- 推处理优先级捷径：**数每行 1 的个数（含自身）**，1 越多优先级越高，全序直接排出。
- 易漏点：**响应优先级与处理优先级可以不同**；CPU 只有在“开中断且请求未被屏蔽且优先级高于当前”时才嵌套；单重中断系统中 ISR 全程关中断，不存在嵌套。
- NMI（不可屏蔽中断）**不受屏蔽字控制**， even 最高屏蔽字也挡不住。

## 🎯 三、经典真题同源变式题 1（单项选择题）

【题目背景】某机有 4 个中断源 D₁~D₃（共三级：A、B、C、D），硬件响应优先级为 A > B > C > D。现通过修改屏蔽字获得新的处理优先级 C > A > D > B。屏蔽字中 1 表示屏蔽，0 表示开放。问：CPU 执行 C 的服务程序期间，若 A、B、D 同时发出请求，各服务程序执行顺序（嵌套次序）为？

- A. C → A → D → B
- B. C → D → B → A
- C. C → A → B → D
- D. A → C → D → B

【正确答案】：**A**

【深度解析】：
先构造屏蔽字（1 = 屏蔽优先级不高于自己的源）。按新处理优先级 C > A > D > B：

| 当前服务 | 屏蔽 A | 屏蔽 B | 屏蔽 C | 屏蔽 D |
|---|---|---|---|---|
| C | 1 | 1 | 1 | 1 |
| A | 1 | 1 | **0** | 1 |
| D | 0 | 1 | 0 | 1 |
| B | 0 | 1 | 0 | 1 |

C 服务期间 A、B、D 同时请求：B、D 被 C 的屏蔽字屏蔽，**只有 A 穿透**（C 的 A 位为 0），且开中断，故 C 被 A 打断 → 转 A。A 的屏蔽字屏蔽 B、D 但不屏蔽 C（C 已在被打断状态，请求被挂起）。A 服务完毕返回 C，此时 D、B 仍挂起，D 处理优先级高于 B，D 打断 C → D → B。最终顺序：**C → A → D → B**，选 A。
- B 错：误用硬件响应优先级 B > D 排序。
- C 错：把屏蔽字列/行方向看反，得 B 先于 D。
- D 错：误认为响应优先级 A 最高故 A 先执行——忽略“进入 C 服务时已设置 C 的屏蔽字”，挂起的 A 请求只能等 C 开中断后才响应，首层必为 C。
> 鉴别点：同时请求挂起后“谁能打断谁”只看**当前正在运行者的屏蔽字**，而非全局优先级。

## 🚀 四、经典真题同源变式题 2（综合应用大题）

【综合大题】
某机主频 1 GHz，CPU 执行每条指令平均需 4 个时钟周期。设备 D 采用程序中断方式 I/O，每次中断传送 1 个字（4 B）。相关数据：
- 中断响应（隐指令）需 6 个时钟周期；
- 中断服务程序入口/出口处理（保存现场、恢复现场、iret）共 24 条指令；
- 每次中断的数据传送及设备服务需 10 条指令；
- 设备 D 准备一个字需 0.1 ms，采用多重中断（开中断）方式连续工作。

（1）每次中断的 CPU 开销折合多少时间（ns）？
（2）CPU 用于 D 的 I/O 时间占 CPU 总时间的最大百分比是多少？
（3）若 D 的准备时间缩短为 2 μs，能否仍用中断方式有效工作？说明理由。

【解题思路】：
1. 每时钟周期 = 1/1 GHz = 1 ns；每条指令 = 4 ns。
2. 一次中断开销 = 隐指令（周期数）+ ISR 指令数 × 4 周期/条。
3. 请求频率 = 1/准备时间；占比 = 请求频率 × 单次开销 ÷ 1。
4. 判据：单次开销必须小于设备准备时间，否则数据丢失，需改 DMA。

【参考答案/步骤】：

（1）隐指令开销：6 个时钟周期 = 6 ns。
ISR 开销：(24 + 10) 条 × 4 周期 = 136 个时钟周期 = 136 ns。
单次中断总开销 = 6 + 136 = **142 ns**。

（2）每 0.1 ms = 10⁵ ns 产生一次中断，故
最大占用率 = 142 / 100000 = **0.142%**。

（3）准备时间 2 μs = 2000 ns 时，中断请求频率提高到每 2000 ns 一次，占用率 = 142/2000 = **7.1%**。虽然 CPU 时间开销尚可承受（<100%），但关键判据是：**单次中断总开销 142 ns < 准备间隔 2000 ns**，服务能在下一字准备好之前完成，数据不会丢失，故**仍可继续采用中断方式有效工作**（占比升至 7.1%，效率下降但仍可行）。仅当准备时间缩短到与 142 ns 同数量级（如 150 ns 以下）时才必须改用 DMA/通道方式。

【时空复杂度分析】：
- 时间：每次中断开销为常数 O(1)（隐指令 O(1) + ISR 指令数固定）；长期看每字开销恒定，故单位时间 I/O 总开销与请求频率成正比，为 O(f)（f 为中断频率）。
- 空间：中断栈只需保存固定的现场（PC、PSW 及若干寄存器，深度受嵌套级数上限约束 ≤ 中断源个数 n），空间复杂度 O(n)，n 为可嵌套中断源数；本题单设备场景为 O(1)。

> **命题鉴别说明**：第 (3) 问为高频失分区——考生只算百分比不看“服务时间 < 准备间隔”这一硬约束，或反之只看约束忽略 CPU 百分比是否饱和，需双重验证。
