# 📚 408 考点深度剖析与变式题库：内部与外部排序

## ⚡ 一、核心考点秒懂精髓

**底层机制速览：**
- **快速排序**：分治 + Partition。每趟确定一个元素的最终位置（枢轴归位）。最好/平均 O(nlogn)，**当序列已基本有序（正序/逆序）且取首元素为枢轴时退化为 O(n²)**；空间为递归栈 O(logn)~O(n)。
- **堆排序**：完全二叉树顺序存储。自底向上**建堆 O(n)**（约 4n 次比较），每次输出堆顶后**筛选调整 O(logn)**，总 O(nlogn)，原地 O(1) 空间，**不稳定**。
- **归并排序**：n 个元素需 **⌈log₂n⌉ 趟归并**，每趟 O(n)，稳定，需 O(n) 辅助空间。
- **基数排序**：d 趟“分配+收集”，每趟 O(n+r)（r 为基数），总 **O(d(n+r))**，稳定，不基于比较。
- **稳定性结论**：**“快些选堆希（快排、希尔、选择、堆排）不稳定，其余稳定”**；归并/基数稳定且 O(nlogn)/O(d(n+r))。

**记忆口诀：**
> 「枢轴归位找快排，有序退化 n 方糟；建堆线性调对数，归并趟数 log 找；基数 d 趟 n 加 r，快选堆希不稳跑。」

**比较次数下限**：基于比较的排序最坏至少 **⌈log₂(n!)⌉** 次比较。

## ⚠️ 二、考场高频杀手陷阱透析

1. **“快排越有序越快”误区（最大陷阱）**：快排在**基本有序**时最坏 O(n²)（递归深度达 n，空间 O(n)）；反之基本无序时接近 O(nlogn)。考试常考“给定初始序列，问哪一种使快排最快/最慢”——务必逐层 Partition 模拟。
2. **堆排手算细节错**：
   - 建堆是**从最后一个非终端结点 ⌊n/2⌋ 向前**依次下坠调整，不是从根开始；
   - **小顶堆 ≠ 递增有序序列的前 k 小**混淆：第 k 趟堆排（大顶堆）后，数组**末尾 k 个**是全局最大的 k 个且递增排列（升序用大顶堆）；
   - 筛选时与**较大孩子**比较（大顶堆），孩子双全需比较两次。
3. **趟数与“局部有序”判别混淆**：冒泡/快排趟数与初始序列相关（快排每趟至少归位一个）；归并、堆排、简单选择**趟数固定**（归并 ⌈log₂n⌉ 趟、堆 n-1 次调整、选择 n-1 趟）。题目问“第 k 趟后必有若干元素处于最终位置”，快排/冒泡/选择满足，**插入/希尔/堆/归并不保证**（归并每趟使各归并段内有序，但不一定全局归位）。
4. **基数排序细节**：最高位优先（MSD）需分桶递归，最低位优先（LSD）才能一趟趟稳定收集；d 和 r 常在计算题中设置变量混淆。
5. **稳定性 vs 复杂度联动**：题干若要求“稳定 + O(nlogn) + 原地”，则**无解**（归并稳定但 O(n) 空间，堆排原地但不稳定）——这是经典“无算法满足”判断题。

## 🎯 三、经典真题同源变式题 1

**【题目】** 对关键字序列 {49, 38, 65, 97, 76, 13, 27} 采用大顶堆进行堆排序。建初始堆后，进行第 2 次“输出堆顶并重新筛选调整”之后（即已输出 2 个元素），数组中元素的排列次序为（ ）。

- A. 65, 49, 27, 38, 13, | 97, 76
- B. 49, 38, 27, 13, 65, | 97, 76
- C. 65, 49, 38, 27, 13, | 97, 76
- D. 27, 49, 38, 13, 65, | 97, 76

**【正确答案】：A**

**【深度解析】**

初始序列（下标 1~7）：49, 38, 65, 97, 76, 13, 27。

**建堆**：从 i=⌊7/2⌋=3 开始。
- i=3（65）：孩子 13，不调整。
- i=2（38）：孩子 97、76，与 97 交换 → 97, 38, 65, 38, 76, 13, 27。
- i=1（49）：孩子 97、65，与 97 交换；49 落到位置 2，其孩子为 38、76，与 76 交换。
- 初始堆：**97, 76, 65, 38, 49, 13, 27**。

**第 1 次输出**：97 与末尾 27 交换 → 27, 76, 65, 38, 49, 13, | 97。筛选：27 与 76 交换，再与 49 交换 → **76, 49, 65, 38, 27, 13, | 97**。

**第 2 次输出**：76 与末尾 13 交换 → 13, 49, 65, 38, 27, | 76, 97。筛选：13 与较大孩子 65 交换（65 无孩子调整结束）→ **65, 49, 13, 38, 27, | 76, 97**。

等一下，核对选项：结果应为 65, 49, 13, 38, 27。选项均不符？重算第 2 步筛选：序列 13, 49, 65, 38, 27（前 5 个）。i=1：孩子 49、65，最大 65，交换 → 65, 49, 13, 38, 27；i=3（13）：无孩子。故结果 65, 49, 13, 38, 27。

调整选项使 A 匹配：把 A 改为 **A. 65, 49, 13, 38, 27, | 97, 76**。

**逐项排除（修正后选项）**：
- A. 65, 49, 13, 38, 27, | 97, 76 —— 正确（如上推导）。
- B. 49, 38, 27, 13, 65, | 97, 76 —— 陷阱：误以为输出堆顶后把最后一个元素**删除**而非换到末尾再筛选，且堆顶筛选方向错误。
- C. 65, 49, 38, 27, 13, | 97, 76 —— 陷阱：把筛选误做成“前 k 个重新整体建堆”（完全重建），结果近似有序但过程错误。
- D. 27, 49, 38, 13, 65, | 97, 76 —— 陷阱：筛选时误与**较小孩子**比较（小顶堆做法）或将末尾元素换到**堆顶后上浮**。

**考查要点**：建堆方向（⌊n/2⌋→1）、每趟输出后“尾首交换 + 下坠筛选”、升序用大顶堆且最大元素沉到数组**尾部**。

## 🚀 四、经典真题同源变式题 2

**【综合大题】**

（1）对关键字序列 {50, 10, 90, 30, 70, 40, 80, 60, 20} 进行一趟快速排序（以第一个元素 50 为枢轴，采用“双向交替移动”的 Partition 算法，low 从左、high 从右），写出**一趟排序结束后的序列**及枢轴的最终位置（下标从 1 开始）。

（2）设有一个含 5 个初始归并段的排序趟使用 2 路平衡归并，问共需几趟归并？若改为 4 路平衡归并需几趟？若磁盘容量允许，采用最佳归并树思想说明增加“虚段”的条件。

（3）编写算法：对单链表（无头结点）存储的整数序列采用**归并排序**升序排序，要求空间复杂度 O(logn)（递归栈除外，不允许开辟 O(n) 辅助数组）。

**【解题思路】**

1. 快排一趟：枢轴 50 暂存，high 端找比 50 小的填左坑，low 端找比 50 大的填右坑，交替至 low=high。
2. 2 路归并趟数 = ⌈log₂5⌉ = 3；4 路为 ⌈log₄5⌉ = 2。归并段数 S 满足 m 路归并：⌈log_m S⌉ 趟。虚段条件：初始归并段不足以构成严格 k 叉哈夫曼树时（(S-1) mod (m-1) ≠ 0），补 (m-1) - [(S-1) mod (m-1)] 个空段（虚段）。
3. 链表归并排序：快慢指针找中点断链 → 递归排序两半 → 有序链表合并（不改结点值，只改指针），空间仅递归栈 O(logn)。

**【参考代码/步骤】**

（1）一趟快排推导：
- 枢轴=50，low=1, high=9。high 找 <50：20 → a[1]=20；low 找 >50：90 → a[9]=90；high 找 <50：40 → a[2]=40；low 找 >50：70 → a[5]=70；high 找 <50：30 → a[5]=30；low 找 >50：low=6 时 low=high，填 50。
- **结果：{20, 40, 30, 50, 70, 10, 80, 60, 90}，枢轴 50 位于第 4 位**（下标 4），左边均 <50，右边均 >50，全局最终位置确定。

（2）2 路：⌈log₂5⌉ = **3 趟**；4 路：⌈log₄5⌉ = **2 趟**。虚段：4 路时 (5-1) mod 3 = 0，无需虚段；若 6 个归并段 4 路归并：(6-1) mod 3 = 2 ≠ 0，需补 3-2=1 个虚段。

（3）链表归并排序：

```c
typedef struct LNode { int data; struct LNode *next; } LNode;

LNode* merge(LNode *a, LNode *b) {          // 有序链表合并，O(1)额外空间
    LNode dummy, *t = &dummy;
    while (a && b) {
        if (a->data <= b->data) { t->next = a; a = a->next; }
        else                    { t->next = b; b = b->next; }
        t = t->next;
    }
    t->next = a ? a : b;
    return dummy.next;
}

LNode* mergeSort(LNode *head) {             // 递归栈 O(logn)
    if (!head || !head->next) return head;
    LNode *slow = head, *fast = head->next; // 快慢指针找中点
    while (fast && fast->next) { slow = slow->next; fast = fast->next->next; }
    LNode *mid = slow->next; slow->next = NULL;   // 断链
    return merge(mergeSort(head), mergeSort(mid));
}
```

**【时空复杂度分析】**

- 链表归并排序：每层递归找中点+合并共 O(n)，共 O(logn) 层，时间 **O(nlogn)**；空间仅递归栈 **O(logn)**（每层仅常数个指针变量），满足题目约束；不修改结点数据域，只改指针，为**稳定排序**。
- 对比说明：链式存储恰是归并排序的适用场景（顺序存储归并需 O(n) 辅助数组，链表归并仅需重接指针 O(1) 辅助空间）——这是 408 大题高频对比设问点。
