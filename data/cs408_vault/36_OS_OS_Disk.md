# 📚 408 考点深度剖析与变式题库：磁盘调度与SPOOLing技术

## ⚡ 一、核心考点秒懂精髓

**底层核心机制：**
- 磁盘一次访盘时间 = **寻道时间 Ts + 旋转延迟 Tr + 传输时间 Tt**。寻道通常是主导项（毫秒级），故磁盘调度的本质是**最小化总移动道数**。旋转延迟平均为旋转一周时间的一半（如 7200rpm 盘平均 4.17ms）。
- 磁盘调度算法对比：
  - **FCFS**：按请求到达顺序服务，公平但平均寻道长。
  - **SSTF**：每次选距当前磁道最近的请求，贪心可能导致“饥饿”（边缘请求被无限插队）。
  - **SCAN（电梯算法）**：沿一个方向扫到**磁道尽头**才折返（经典定义要求到边界，即 0 或最大道号）。
  - **LOOK**：SCAN 的改进，扫到**该方向最远的请求**即折返，不必到物理边界。
  - **C-SCAN**：单向扫描，扫到边界后**快速回到另一端**重新开始，提供更均匀的等待时间。
- **SPOOLing**：用磁盘上的输入井/输出井 + 输入/输出进程，将**独占设备（如打印机）改造为共享设备**；核心是“用可共享的磁盘模拟独占设备”，提高了设备利用率与系统吞吐量，但**占用磁盘空间与CPU时间**。

**记忆口诀：**
> 「寻道为主算移动，SCAN 到底 LOOK 止；SSTF 贪心有饿死，假脱机井改共享。」

**解题捷径：** 画一条 0~N 的数轴标出磁头当前位置与请求点，按算法规则依次连线，**累加相邻两点间距离的绝对值**即可；SCAN/C-SCAN 先确认磁头移动方向（题目必给），C-SCAN 别忘回程不计服务（回程寻道数=磁道总数跨度，视题目是否计入）。

## ⚠️ 二、考场高频杀手陷阱透析

**陷阱1：SCAN 与 LOOK 的边界混淆（丢分重灾区）**
408 经典真题（2009年）故意在“距最远请求 1 道之隔”设置边界。许多考生把“扫描到最远请求”当作 SCAN，实际经典 SCAN 必须移动到**磁道最边缘（0 号或最大号）**才折返；若题目说“移动到最远请求即调头”，那是 LOOK。审题必须抠“到达磁盘边缘/最远请求”字眼，两者相差的正是“最远请求到边界”的额外距离。

**陷阱2：忽略磁头初始移动方向的隐含约束**
SSTF 无方向问题，但 SCAN/C-SCAN/LOOK **必须先确定方向**。真题常给“磁头正在向磁道号增大方向移动”的表述，考生漏读此条件导致整条调度序列全错。另注意 C-SCAN 折返时是否计入寻道时间，各教材处理不同，须按题目说明（408 标准答案通常将返回过程也计入移动道数，但服务仅在正向）。

**陷阱3：SPOOLing 概念性错误——共享性与虚拟化对象张冠李戴**
- 误选“SPOOLing 使 CPU 与 I/O 并行”为主功能——这只是附带效果，本质是**独占设备→共享（逻辑）设备**的虚拟化。
- 误认为 SPOOLing 消除了对设备的独占使用——物理上打印机仍是串行打印，虚拟化只体现在**用户层面的排队共享**。
- 混淆输入井/输出井所在位置：井在**磁盘**，不在内存缓冲区；输入井模拟脱机输入时的“低速输入设备暂存区”。

## 🎯 三、经典真题同源变式题 1（单项选择）

【题目背景】
某磁盘磁道编号为 0~199，磁头当前位于 **95 号**磁道，**正在沿磁道号减小方向**移动。当前磁道请求队列依次到达：58，130，40，160，72，180。分别采用 **SSTF** 与 **SCAN（扫描到 0 号磁道边缘才折返）** 算法，两种算法下磁头移动道数之差为多少？

- A. 11
- B. 30
- C. 47
- D. 65

【正确答案】**B**

【深度解析】
- **SSTF 推导**（从 95 出发，无方向约束）：
 95→72(23)→58(14)→40(18)→130(90)→160(30)→180(20)。
 总计 23+14+18+90+30+20 = **195**。
- **SCAN 推导**（向减小方向，须扫到 0 号边缘）：
 95→72(23)→58(13)→40(15)→**0**(40，到达边缘折返)→130(130)→160(30)→180(20)。
 总计 23+13+15+40+130+30+20 = **271**。
- 差值 = 271 − 195 = **30**，选 **B**。
- **干扰项陷阱**：
  - A（11）：把 SCAN 误当 LOOK（95→72→58→40 后直接折返，总 251，差 56 也不对；实际是考生用 LOOK 计算又漏加某段），考查边界混淆。
  - C（47）：SSTF 从 95 先去 130（走错方向贪心）得 95→130→160→180→72→58→40 = 212，271−212 = 59 计算再错成 47。
  - D（65）：忘记 SCAN 需到 0 号边缘，少算 0→130 或 40→0 段。
- **关键提醒**：SSTF 不看方向只看最近；SCAN 本题方向向下且必须触底 0 号道。

## 🚀 四、经典真题同源变式题 2（综合应用）

【综合大题】
某系统采用 **C-SCAN（单向电梯）** 算法管理磁盘，磁道号 0~199，磁头当前在 **100 号**，沿磁道号**增大**方向移动，到达 199 号边缘后立即返回 0 号继续正向扫描（返回过程不计入服务，但返回移动道数计入总移动量）。请求队列：55，170，90，130，20，150。

（1）给出服务序列与总移动道数；
（2）若磁盘转速 6000 rpm，每道 160 个扇区，忽略寻道与传输外的其他开销，平均旋转延迟是多少 ms？
（3）编写 C 代码：输入磁头位置、方向、请求队列，实现 C-SCAN 总移动量计算，要求时间 O(n log n)、空间 O(1) 额外空间（排序原地完成）。

【解题思路】
1. C-SCAN 正向扫描方向上依次服务所有请求 → 触顶 199 → 跳回 0 → 继续正向服务剩余请求。
2. 服务序列：130→150→170→（触顶199→回0）→20→55→90。
3. 旋转延迟 = 半圈时间 = 60000ms/6000rpm ÷ 2 = 5ms。
4. 代码：原地排序后按方向遍历两段。

【参考代码/步骤】

```c
// 手写原地快速排序（或使用 qsort）
void qsort_(int a[], int l, int r) {
    if (l >= r) return;
    int p = a[(l + r) / 2], i = l, j = r;
    while (i <= j) {
        while (a[i] < p) i++;
        while (a[j] > p) j--;
        if (i <= j) { int t = a[i]; a[i] = a[j]; a[j] = t; i++; j--; }
    }
    qsort_(a, l, j); qsort_(a, i, r);
}

int cscan_total(int head, int dir, int req[], int n, int MAX /*=199*/) {
    qsort_(req, 0, n - 1);           // O(n log n)，原地
    int total = 0, i, pos = head;
    if (dir > 0) {
        for (i = 0; i < n && req[i] < head; i++);      // 定位首个 >= head
        for (; i < n; i++) { total += req[i] - pos; pos = req[i]; } // 正向服务
        total += MAX - pos + MAX;   // 到199边缘 + 跳回0
        pos = 0;
        for (i = 0; i < n && req[i] < head; i++) {   // 服务折返前的小道号
            total += req[i] - pos; pos = req[i];
        }
    }
    return total;
}
```

**（1）手工验证：** 100→130(30)→150(20)→170(20)→199(29)→0(199)→20(20)→55(35)→90(35)。
总移动 = 30+20+20+29+199+20+35+35 = **388 道**。
**（2）** 平均旋转延迟 = (60/6000)/2 = **5 ms**。

【时空复杂度分析】
- **时间复杂度**：快速排序平均 O(n log n)（最坏 O(n²)，可用三数取中缓解），其后两次线性遍历 O(n)，总计 **O(n log n)**，满足题目约束。
- **空间复杂度**：快排递归栈平均 O(log n)，排序原地无辅助数组，额外空间 **O(log n)**（若题目允许 qsort 的栈深视为常数级忽略，可近似 O(1)；严格说明递归栈即可得分）。
