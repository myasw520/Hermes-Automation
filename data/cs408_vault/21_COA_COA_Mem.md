# 📚 408 考点深度剖析与变式题库：存储系统与多级结构

## ⚡ 一、核心考点秒懂精髓

**底层机制：**
- **SRAM**：每个存储元为双稳态触发器（6 管电路），只要不断电状态自保持，无需刷新；存取快、集成度低、功耗大、位价高 → 用作 **Cache**。
- **DRAM**：存储元为电容（单管/三管），靠电荷存储信息，电荷会泄漏，**必须定期刷新**（典型 2ms 内全部刷新一遍）。刷新方式：
  - **集中刷新**：一段时间集中逐行刷新，产生“死时间/死区”；
  - **分散刷新**：每个存取周期后半段刷新一行，无死区但系统存取周期加倍；
  - **异步刷新**：二者折中，2ms 内每隔一段时间刷一行，死时间最短（最长死时间 = 一个存取周期）。
- **多模块交叉编址**：低位交叉编址（流水线式并行），连续访问 m 个字所需时间 **T = r + (m−1)·τ**（r 为主存一个存取周期，τ 为总线传送周期，r = m·τ 时理想带宽提高 m 倍）；高位交叉为顺序编址，仅起容量扩展作用，无流水加速。

**口诀：**
> SRAM 触发器稳态自保持，DRAM 电容漏电必刷新；**低位交叉是流水：T = 首字周期 + (m−1)×传送周期**；高位交叉只扩容，不提速。

## ⚠️ 二、考场高频杀手陷阱透析

**陷阱 1：刷新“按行”还是“按芯片”？—— 单位混淆**
刷新以**行**为单位，刷新一遍全部单元所需时间 = 行数 × 存取周期（或刷新周期）。考生常误用"128 行 × 128 列"总单元数计算，导致时间算大 128 倍。记住：**刷新计数单位是行数，不是总容量**。

**陷阱 2：把“死时间”算错为整个刷新周期**
集中刷新的死时间 = 刷新所有行的时间（行数 × 存取周期），且**死区周期性地每 2ms 出现一次**；异步刷新的死时间仅为**一个存取周期**。误选“无死区”或“死时间为 2ms”均是命题人预设陷阱。

**陷阱 3：交叉访存加速比公式套错 —— 忽略“r 与 τ 的关系”**
低位交叉连续读 n 个字：T = r + (n−1)τ，要求 **τ ≤ r/m 且程序访存地址连续、不冲突（不同体）、无转移缺页打断流水**。若题目给出数组跳跃访问（如列主序访问按行存的数组），同一模块连续命中，流水失效，退化为逐个串行。另一坑：**带宽** = 总字数/总时间，勿忘除以时间而非乘。

## 🎯 三、经典真题同源变式题 1（单项选择题）

**【题目】** 某计算机主存储器采用 8 个存储器芯片低位交叉编址，每个存取周期 r = 40ns，总线传送周期 τ = 5ns。CPU 连续读取 16 个主存字（地址连续且不发生访存冲突），则读取这 16 个字的总时间及此时主存的最大带宽（字/ns）分别约为：

- A. 640ns；0.025 字/ns
- B. 115ns；约 0.139 字/ns
- C. 120ns；约 0.133 字/ns
- D. 75ns；约 0.213 字/ns

**【正确答案】B**

**【深度解析】**
- 正向推导：第一个字需完整存取周期 r = 40ns 读出，其后每 τ = 5ns 流水读出一个字，剩余 15 个字需 15×5 = 75ns。总时间 T = 40 + 15×5 = **115ns**。带宽 = 16/115 ≈ 0.139 字/ns。
- **A 项陷阱**：16×40 = 640ns 是完全串行（无交叉、高位交叉或单模块）的结果，考察是否混淆高低位交叉。
- **C 项陷阱**：误用 T = r + 16×τ = 40+80 = 120ns，多算了一个 τ——第一个字已包含在 r 内，不是 16 个都另加 τ。这是 408 真题（2011 年第 43 题模型）最经典的“差一个 τ”失分点。
- **D 项陷阱**：误用 T = r + (8−1)τ = 40+35 = 75ns，即错误地以模块数 8 封顶计算后未处理第 9~16 个字；连续读 16 字超过模块数时，第 8 个 τ 之后每 τ 出一个字，必须用 (16−1)τ。

## 🚀 四、经典真题同源变式题 2（综合应用大题）

**【综合大题】**
某 DRAM 芯片容量为 4096 × 4096 × 8bit，其存储元需要定期刷新，最大刷新间隔为 4ms，读/写周期与刷新周期均为 100ns（刷新按行进行，采用“边读边写”内部方式）。

1. 若采用**集中刷新**，求刷新一遍全部单元所需时间及“死时间”占整个 4ms 时间的百分比（保留 2 位小数）。
2. 若采用**异步刷新**，为使死时间最短且不超时，求刷新间隔的设置值及最大死时间。
3. 若改用**分散刷新**，说明存取周期将变为多少，并指出其优缺点。

**【解题思路】**
- 第 1 问：刷新以行为单位，4096 行 × 100ns；死区即集中刷新这段时间，除以 4ms 得百分比。
- 第 2 问：4ms ÷ 4096 行得相邻两行刷新的最大允许间隔；每次只刷一行，死时间 = 一个刷新周期。
- 第 3 问：分散刷新把刷新嵌入每个存取周期，周期 = 读/写 + 刷新 = 200ns。

**【参考步骤】**

1. 刷新一遍：4096 × 100ns = 409600ns = **409.6μs**。
   死时间百分比 = 409.6μs / 4000μs = **10.24%**。
2. 刷新间隔 = 4ms / 4096 = **0.9765625μs ≈ 976.5ns**（每隔约 0.977μs 刷一行）；最大死时间 = 一个刷新/存取周期 = **100ns**。
3. 分散刷新时系统存取周期 = 100 + 100 = **200ns**。优点：无死区，控制简单；缺点：存取周期加倍，主存有效速率减半，且刷新过于频繁（4ms 内实际刷了远多于 4096 次，即对每行多次冗余刷新）。

**【时空复杂度分析】**
本题非算法题，给出计算复杂度通式：n 行 DRAM，刷新周期 t_c，则
- 集中刷新死时间 = n·t_c，占空比 = n·t_c / T_refresh；
- 异步刷新死时间 = t_c（与 n 无关）；
- 分散刷新使系统周期变为 2t_c，带宽降为 1/2。
当 n 增大（芯片容量翻倍），集中刷新死区线性增长——这正是大容量 DRAM 普遍采用异步刷新的根本原因，也是命题人常考的“为什么”追问点。
