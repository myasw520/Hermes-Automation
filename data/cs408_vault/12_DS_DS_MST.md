# 📚 408 考点深度剖析与变式题库：最小生成树(MST)

## ⚡ 一、核心考点秒懂精髓

- **Prim 算法**：以**顶点**为中心的“贪心扩散”。维护顶点集 U 与候选集 V-U，每轮从 V-U 中选取**与 U 连通代价最小**的顶点加入 U，并松弛其邻接边lowcost数组。适合**稠密图**（E≈V²），邻接矩阵实现，时间复杂度 **O(V²)**，与边数无关。
- **Kruskal 算法**：以**边**为中心的“全局挑边”。将所有边按权值**非降序排序**，依次考察：若当前边两端点属于不同连通分量（**并查集 Find 判定**）则加入 MST 并 Union 合并，否则舍弃（避免成环）。适合**稀疏图**（E≪V²），时间复杂度 **O(E log E)**（排序主导）。

**考场口诀**：
> **"Prim 找点 O(V²) 稠密亲，Kruskal 挑边 O(ElogE) 稀疏灵；MST 不唯一但总权必唯一，各边权互异则树必唯一。"**

## ⚠️ 二、考场高频杀手陷阱透析

**陷阱 1：MST 唯一性误判（最高频丢分点）**
考生常误认为“最小生成树总是唯一的”。**真相**：MST 可能不唯一，但**总权值一定唯一（相同）**；仅当**各边权值互不相同**时 MST 才唯一。判断 MST 是否唯一的经典方法：交换次小边验证存在等权替代边。408 曾直接考察“权值互不相同的图，其 MST 唯一”这一判定。

**陷阱 2：复杂度分析张冠李戴**
- Prim 用**邻接表 + 堆**可优化为 O(E log V)，但 408 教材标准答案是**邻接矩阵 O(V²)**——若题目问“Prim 算法的时间复杂度”而不指明实现，**按 O(V²) 作答**；题目若明确“邻接表+优先队列”才答 O(E log V)。
- Kruskal 复杂度中**排序 O(E log E) 主导**，并查集近似 O(E·α(V)) 可忽略；易错点：答成 O(V²) 或误以为并查集是主要开销。

**陷阱 3：Kruskal 执行过程模拟错位**
考生手算 Kruskal 时忽略两大细节：① 权值**相同**的边选取顺序不同导致 MST 形态不同（但总权相同）；② 当某条边加入会**成环**时必须舍弃，而不是“跳过后回来再试”。Prim 手算时则易错在：**每次只允许加入一个顶点**（即使存在多条等权最短边，也只能选其一），且加入后要**立即用新顶点的边更新 lowcost**（可能变小，也可能不变，绝不会变大）。

## 🎯 三、经典真题同源变式题 1（单项选择/计算题）

【题目背景】
对带权无向连通图 G=(V,E)，V={v1,…,v6}，有如下 9 条边（顶点对, 权值）：
(v1,v2,4)、(v1,v3,9)、(v2,v3,7)、(v2,v4,5)、(v3,v4,10)、(v3,v5,3)、(v4,v5,8)、(v4,v6,6)、(v5,v6,2)。
下列叙述中，**错误**的是：

- A. 用 Kruskal 算法求 G 的 MST，依次加入的边中第 3 条边是 (v4,v6,6)
- B. 从 v1 出发用 Prim 算法，加入的第 2 个顶点是 v5
- C. G 的最小生成树是唯一的
- D. 若将边 (v2,v3,7) 的权值改为 6，MST 的形态保持不变（用 Kruskal 从权值相同者任选不影响结论）

【正确答案】：**A**

【深度解析】
Kruskal 过程：排序后权值顺序：2(v5,v6) → 3(v3,v5) → 4(v1,v2) → 5(v2,v4) → 6(v4,v6) → 7(v2,v3) → 8(v4,v5) → 9(v1,v3) → 10(v3,v4)。
- 加入 (v5,v6,2)；加入 (v3,v5,3)；加入 (v1,v2,4)——**第 3 条边是 (v1,v2,4)**，不是 (v4,v6,6)。**A 错误，当选**。（(v4,v6,6) 是第 5 条，陷阱预设：考生只算权重不看次序）
- Prim 从 v1：lowcost 最小为 4(v2)？注意 (v1,v2,4) 加入 v2；第二轮经 v2 得 (v2,v4,5) 最小——等等，需逐轮核对：U={v1}，最小边 4 → 加 v2；U={v1,v2}，候选：9(v1v3)、7(v2v3)、5(v2v4) → 加 v4；候选：10(v3v4)、6(v4v6)、8(v4v5) → 加 v6；候选 8(v4v5)、10(v3v4) → 加 v5；最后 (v3,v5,3)。第 2 个加入的顶点应为 v4 而非 v5？——重新审视：B 选项值与推导冲突，故 B 亦错误？**修正选项 B**：正确叙述应为“加入的第 2 个顶点是 v4”。**以修正后选项定稿**：
  > B.（修正）从 v1 出发用 Prim，加入的第 2 个顶点是 v4 —— **正确**。
- **C 正确**：图中所有边权值 2,3,4,5,6,7,8,9,10 互不相同，MST 必唯一。
- **D 正确**：MST 边集为 {(v5,v6,2),(v3,v5,3),(v1,v2,4),(v2,v4,5),(v4,v6,6)}，(v2,v3,7) 根本不在 MST 中；将其从 7 改为 6 后，排序变为 …5(v2,v4) → 6(v2,v3) 与 6(v4,v6)…，轮到权 6 时：加 (v4,v6,6)（不成环，连通 {v4,v6}），再遇 (v2,v3,6) 时 v2、v3 分属 {v1,v2,v4,v6} 与 {v3,v5,v6}，不同分量，**仍会加入**！此时 MST 形态改变。**再修正 D**：
  > D.（修正）若将 (v2,v3,7) 的权值改为 12，MST 边集不变 —— 正确（权 12 依然不会被选入）。

**干扰项预设陷阱**：A 考查 Kruskal 加边次序模拟；C 考查“权互异 ⇒ MST 唯一”判定定理；D 考查“非 MST 边的权值在充分范围内的变动不影响 MST”。

## 🚀 四、经典真题同源变式题 2（综合应用/大题设计）

【综合大题】
设无向带权连通图 G 有 n 个顶点（编号 0~n-1）、e 条边。边以**边集数组**形式给出：每个元素含 u、v、w。要求：
1. 设计算法求 G 的最小生成树总权值；
2. 若 G 不连通，输出 -1；
3. **约束**：不使用排序库函数以外的任何 STL 容器；并查集须实现**路径压缩**；说明算法选择理由并分析复杂度。

【解题思路】
1. 图以边集给定（无邻接矩阵），且需判定连通性 → 选 **Kruskal + 并查集**（Prim 需邻接表/矩阵且 O(V²)，对本输入格式需额外建图）。
2. 对边数组按 w 升序排序（O(E log E)）。
3. 顺序扫描：Find(u)≠Find(v) 则合并并累计权值，计数 cnt++。
4. 终止条件：cnt == n-1 → 输出总权；扫描完仍 cnt < n-1 → 输出 -1（不连通）。
5. 并查集：父数组 parent[]，Find 递归/迭代路径压缩，Union 按父直接挂接（可加按秩优化，非必需）。

【参考代码/步骤】

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct { int u, v, w; } Edge;

int cmp(const void *a, const void *b) {
    return ((Edge*)a)->w - ((Edge*)b)->w;   // 按权非降序
}

int Find(int *parent, int x) {              // 路径压缩
    if (parent[x] != x)
        parent[x] = Find(parent, parent[x]);
    return parent[x];
}

int MST_Kruskal(Edge *e, int n, int m) {    // m 条边
    qsort(e, m, sizeof(Edge), cmp);         // O(E log E)
    int *parent = (int*)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) parent[i] = i;
    int total = 0, cnt = 0;
    for (int i = 0; i < m && cnt < n - 1; i++) {
        int ru = Find(parent, e[i].u);
        int rv = Find(parent, e[i].v);
        if (ru != rv) {                     // 不成环则选入
            parent[ru] = rv;                // Union
            total += e[i].w;
            cnt++;
        }
    }
    free(parent);
    return (cnt == n - 1) ? total : -1;     // 不连通返回 -1
}
```

【时空复杂度分析】
- **时间**：排序 O(E log E)；扫描 E 条边，每次 Find/Union 因路径压缩近似 O(α(V))（α 为反 Ackermann 函数，视为常数），总计 **O(E log E)**。因 E < V²，log E < 2 log V，故亦写作 O(E log V)。
- **空间**：parent 数组 O(V) + 排序栈空间（qsort 为 O(log E) 递归栈），总计 **O(V)**（不计输入边数组）。
- **选型论证**：若改用 Prim（邻接矩阵）复杂度 O(V²)；本题边以边集给出，Kruskal 无需构建 V×V 矩阵，当图**稀疏**（E ≪ V²）时 Kruskal 明显更优，符合“稀疏用 Kruskal”原则。
