# 📚 408 考点深度剖析与变式题库：线性表与链表

## ⚡ 一、核心考点秒懂精髓
- **顺序表**：物理连续存储，随机访问 O(1)，插入/删除平均移动 n/2 个元素 O(n)；**链表**：逻辑相邻、物理离散，插入/删除仅需改指针 O(1)（但定位仍 O(n)），不支持随机存取。
- **头节点**：统一了“在表头插入/删除”与“在表中插入/删除”的操作逻辑，**第一个数据结点的插入不再需要特殊处理**；头指针是链表的必要标识，头节点不是。
- **循环双链表判空**：`L->next == L && L->prior == L`（不是 NULL）。
- **快慢指针**：找中点（快2慢1）、判环（相遇后快回头，同速再遇即入口）、找倒数第k个（快先走k步）。

> **口诀**：「查改用顺序，插删频繁链；先连后断，先断必丢」「单链逆置：摘头插头（头插法重建）」。

## ⚠️ 二、考场高频杀手陷阱透析

1. **指针修改顺序错误（先断后连）**：删除结点 p 时若先执行 `free(p)` 或先改 `p->next`，会丢失后继指针。正向顺序永远是：**先接新边，再断旧边**。如插入 `s` 到 `p` 之后：`s->next = p->next; p->next = s;`（顺序不可颠倒）。双链表插入需改 4 个指针，删除改 2 个，顺序错一个即丢链。
2. **“时间复杂度 O(1)” 的偷换概念**：命题人常设“在单链表中删除结点 p”看似 O(1)，实际单链表**找不到前驱**，需遍历 O(n)；但可用**换值法**：`q = p->next; p->data = q->data; p->next = q->next; free(q)`，转化为删除后继，达到 O(1)——但此法对**删除尾结点失效**。选项常以“尾结点也可 O(1) 删除”设错。
3. **头指针 ≠ 头节点 ≠ 首元节点**：判空条件混淆是经典陷阱——不带头节点单链表判空 `L == NULL`，带头节点 `L->next == NULL`，循环单链表 `L->next == L`，循环双链表需判两个方向。另外：头节点**不计入表长**，且其数据域一般不存数据（可存表长，但408默认不计）。
4. **静态链表容量与游标边界**：静态链表用数组下标作“指针”，下标 0 通常作头节点，-1 表示空；越界判断与动态链表不同，且插入删除需维护空闲链（备用链表）。

## 🎯 三、经典真题同源变式题 1

**【题目】** 设某带头节点的非空循环双链表，头指针为 `L`，结点结构为 `prior | data | next`。现要删除 `p` 所指结点（p 为尾结点时同样成立），下列语句序列**正确且必要**的是：

- A. `p->prior->next = p->next; p->next->prior = p->prior; free(p);`
- B. `p->next->prior = p->prior; p->prior->next = p->next; free(p);`
- C. `p->prior->next = p->next; free(p);`
- D. `p->next->prior = p->next->prior; p->prior = p->prior; free(p);`

**【正确答案】**：A（B 亦逻辑正确，但若单选且考察“循环性下 p->next 始终非空”则 A、B 均对——命题变式设定：**题目限定循环双链表且 p 任意**，A 与 B 实质等价，故本题为考察辨析的"最严谨"版本，以下按真题风格重新表述）：实际考试中更优设问如下——

> **改设问**：在带头节点的**非空循环双链表**中，删除 p 所指结点后必须修改的指针共几个？并判断下列哪组语句在 p 为尾结点时**不成立**。
> - A. `p->prior->next = p->next; p->next->prior = p->prior; free(p);`（p 为尾结点时成立）
> - B. `p->next->prior = p->prior; p->prior->next = p->next; free(p);`（成立）
> - C. 仅执行 `p->prior->next = p->next; free(p);`（成立——尾结点删除只需一条）
> - D. 仅执行 `p->next->prior = p->prior; free(p);`（成立）
>
> 问：若改为**带头节点的非空单循环链表，删除尾结点 \*q**，正确操作是？

**【正确答案（最终版）】**：设问：在非空**单循环链表**（无 prior 域）中删除 q 所指**尾结点**，正确且最高效的语句序列是：
- A. `q->prior->next = q->next; free(q);` —— ❌ 单链表无 prior 域，无法直接访问前驱（陷阱：双链表操作惯性）
- B. 找到 q 的前驱 p（从 L->next 遍历至 `p->next == q`），执行 `p->next = q->next; free(q);` —— ✅ 正确，时间 O(n)
- C. `q->next = L->next; free(q);` —— ❌ 仅改后继，前驱悬空指向已释放结点，链断裂且内存错误
- D. `free(q); q->next = NULL;` —— ❌ 先 free 后访问为未定义行为（UAF），且方向颠倒

**【正确答案】：B**

**【深度解析】**：
- **A** 干扰源：考生刚做完双链表题，肌肉记忆写出 `q->prior`；单循环链表结点只有 data 和 next 两个域，直接编译/逻辑错误。
- **C** 干扰源：“循环链表尾结点 next 指回头节点”这一性质诱导考生只改 q 的出边；但删除结点必须修正**前驱的入边**，否则前驱的 next 成为悬垂指针，后续遍历进入已释放内存。考场上记住铁律：**删谁不重要，重要的是谁指向它**。
- **D** 干扰源：考察释放顺序——free 之后再读其成员是典型的未定义行为（对应真实 408 语义判断题），且赋值方向 `q->next = NULL` 对删除毫无意义。
- **B 正向推导**：设前驱为 p，删除只需 `p->next = q->next; free(q);`，由于循环性 `q->next == L`（头节点），前驱 p 一定是表中**数据倒数第二个可达结点**，必须从头遍历定位，时间 O(n)。

## 🚀 四、经典真题同源变式题 2

**【综合大题】**
已知一个带头节点的单链表 L（结点结构 `int data; struct Node *next;`），表长 n ≥ 1。设计一个**时间 O(n)、空间 O(1)** 的算法，将链表中所有奇数结点（data 为奇数）保持在原相对次序的前提下**全部移到偶数结点之前**，且**奇数之间、偶数之间的相对次序均保持不变**（稳定划分）。输出重排后的链表。

- 输入规格：第一行为 n（1 ≤ n ≤ 10⁵），第二行 n 个整数（|data| ≤ 10⁹）。
- 输出要求：依次输出重排后各结点 data，空格分隔。
- 约束：**必须原地修改指针，禁止申请新结点、禁止借助数组**，不得改变头节点。

**【解题思路】**（分层）：
1. 类比快排划分但不交换数据（交换 data 破坏稳定性）——采用**双尾插法**：遍历原链表，维护两个尾指针 `oddTail`（奇链尾）与 `evenTail`（偶链尾）。
2. 建立两个**辅助头节点**（仅指针，O(1) 空间），遍历时按奇偶将结点**摘下尾插**到对应链——尾插保证相对次序不变（稳定）。
3. 遍历结束后拼接：`oddTail->next = evenHead->next`，偶链尾置 `NULL`，接回头节点。注意负数奇偶判断用 `data % 2 != 0`（负奇数 C 语言中 `% 2` 得 -1，不可与 `== 1` 比较）。

**【参考代码】**
```c
typedef struct Node { int data; struct Node *next; } Node;

Node* partition(Node *L) {          // L 为带头节点单链表
    Node oddH, evenH;               // 栈上辅助头节点，O(1) 空间
    Node *ot = &oddH, *et = &evenH;
    oddH.next = evenH.next = NULL;
    for (Node *p = L->next; p; ) {
        Node *nxt = p->next;        // 先存后继，防止断链（核心防错点）
        if (p->data % 2 != 0) {     // 兼容负数奇偶
            ot->next = p; ot = p;
        } else {
            et->next = p; et = p;
        }
        p = nxt;
    }
    ot->next = evenH.next;          // 奇链尾接偶链头
    et->next = NULL;                // 偶链尾封口
    L->next = oddH.next;            // 接回头节点
    return L;
}
```

**【时空复杂度分析】**
- **时间**：单次遍历，每个结点常数次指针操作，T(n) = O(n)，满足 O(n) 约束。
- **空间**：仅用 2 个辅助头节点与常数个指针变量，S(n) = O(1)，未申请堆结点，未借助数组，满足原地约束。
- **易错扣分点**：① 摘结点前未保存 `p->next` 导致断链；② 用 `data % 2 == 1` 判断奇数，负奇数（如 -3）被误判为偶数；③ 偶链尾未置 `NULL`，若原尾结点为奇数则形成循环/野指针，输出死循环。此三点即评分细则中的分步给分点。
