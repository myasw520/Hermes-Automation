# 📚 408 考点深度剖析与变式题库：网络层IP编址与CIDR

## ⚡ 一、核心考点秒懂精髓
- **CIDR 本质**：摒弃 A/B/C 类地址概念，用“前缀/掩码”任意长度划分地址空间。路由聚合（超网）将多个连续前缀合并为更短前缀；**最长前缀匹配**保证转发时选择前缀最具体（掩码最长）的路由表项。
- **分片机制**：总长度字段 16 位、片偏移以 **8B 为单位**、MF=1 表示后面还有分片、DF=1 禁止分片。分片数据载荷长度（除最后一片）必须是 8 的整数倍。
- **口诀**：
  - 划分看掩码：`掩码取反+1=块大小`；聚合取前缀公共位，前缀变短必是公共前缀。
  - 分片计算：`每片载荷=⌊(MTU-首部)/8⌋×8`；`片偏移=前面所有片载荷总和÷8`；最后一片字节数=总载荷−已分载荷。

## ⚠️ 二、考场高频杀手陷阱透析
1. **聚合前缀非法**：误将 192.168.4.0/24 与 192.168.5.0/24 聚合成 /23 却不检查块边界（聚合前缀必须落在自身地址块对齐边界上，192.168.4.0/23 才合法，起始地址必须是块大小的整数倍）。
2. **分片三重坑**：① 片偏移忘除以 8 或误以首部为准（片偏移从数据部分算起，不含 20B 首部）；② 载荷未对齐 8B（每片数据除最后一片外须为 8 的倍数）；③ IP 首部可能含选项，首部长度 ≠ 20B（由首部长度字段×4 决定），有效载荷 = MTU − 实际首部长度。
3. **最长前缀匹配误判**：目的地址同时命中两条路由时，误选聚合后的短前缀路由（应选掩码最长的）；或默认路由 0.0.0.0/0 掩码最短仅作兜底。另有考生把“匹配”算成目的地址与网络前缀做普通按位与而忘了自己的 IP 也要先与掩码相与再和表项比较（应为：`dest AND 掩码 == 表项前缀`）。

## 🎯 三、经典真题同源变式题 1（单项选择题）

【题目背景】某路由器的路由表如下：

| 目的网络 | 掩码长度 | 下一跳 |
|---|---|---|
| 202.118.1.0 | /25 | R1 |
| 202.118.1.64 | /26 | R2 |
| 202.118.1.192 | /27 | R3 |
| 0.0.0.0 | /0 | R4 |

现收到目的 IP 为 **202.118.1.197** 的分组，且接口 MTU=576B，IP 首部长度 20B，DF=0，原分组总长 1500B。该分组转发到 R3 后需分片，问转发路由器及最后一片的载荷字节数为：

- A. R3，最后一片载荷 24B
- B. R3，最后一片载荷 8B
- C. R2，最后一片载荷 24B
- D. R3，最后一片载荷 88B

【正确答案】**A**

【深度解析】
- **路由匹配**：逐项验证 `dest AND 掩码 == 前缀`：
  - /25：202.118.1.197 AND /25 → 202.118.1.128 ≠ 202.118.1.0（197 第 8 位=1，落 128 块），不匹配；
  - /26：197 AND /26 → 202.118.1.192 ≠ 202.118.1.64，不匹配；
  - /27：197 AND /27 → 202.118.1.192 = 202.118.1.192 ✓（197=11000101₂，192 块 192~223），匹配 R3。
  - 陷阱：C 项诱导误判 197 落入 .64/26 块（实际 .64~.127）；A/B/D 均正确选 R3，区分点在分片。
- **分片计算**：总载荷 = 1500 − 20 = 1480B；每片最大载荷 = ⌊(576−20)/8⌋×8 = ⌊556/8⌋×8 = 69×8 = **552B**。
  - 1480 = 552 + 552 + 376 → 3 片，最后一片载荷 **376B**？
  - 等等，重新核算：552×2=1104，1480−1104=376。376 不是 8 的倍数？376 = 47×8 ✓ 是 8 的倍数。故最后一片载荷 376B。但选项中无 376B——需重新设计数据。
  
  **修正题目数据**：原分组总长 1200B（载荷 1180B）：1180 = 552+552+76，76 非 8 倍数倍数无关紧要（最后一片任意），76B。仍不匹配选项。
  
  **最终采用**：原分组总长 1500B、MTU=336B：每片载荷 = ⌊(336−20)/8⌋×8 = 39×8 = 312B；1480 = 312×4 + 232，最后一片 **232B**。仍需匹配选项。
  
  **正式题目数据**：MTU = 300B，每片载荷 = ⌊280/8⌋×8 = 35×8 = 280B；1480 = 280×5 + 80 → 最后一片载荷 **80B**。选项改为：A. R3，最后一片载荷 80B；B. R3，最后一片载荷 88B；C. R2，最后一片载荷 80B；D. R3，最后一片载荷 280B。
  
  **正确答案：A**。B 的 88B 陷阱在于误用 (576−20) 首轮数据或误把 1480−280×4=160 再加首部重复计算；D 陷阱是把“每片载荷”当“最后一片载荷”；C 陷阱是 /26 匹配错误。

## 🚀 四、经典真题同源变式题 2（综合应用题）

【综合大题】某 ISP 拥有地址块 **192.168.72.0/21**，需分配给 4 个部门：
- 部门 A：500 台主机；部门 B：240 台主机；部门 C：120 台主机；部门 D：60 台主机。
另外：
1. 按主机数从大到小依次分配，要求地址利用率尽可能高，写出每个部门的网络前缀、可用地址范围和广播地址；
2. 若路由表中存在 192.168.72.0/22 与 192.168.76.0/22 两条路由均指向该 ISP，现收到目的地址 192.168.78.100 的分组，判断匹配哪条；
3. 一台主机从部门 B 获得地址 192.168.74.5/24，发送总长 3820B、首部 20B、DF=0 的 IP 分组，出口 MTU=1420B，求各分片的片偏移与 MF 值。

【解题思路】
- 第 1 问：每个前缀需满足 2^(32−n) − 2 ≥ 主机数，从大到小分配避免碎片。
  - A：500 → /23（510）；
  - B：240 → /24（254）；
  - C：120 → /25（126）；
  - D：60 → /26（62）。
- 第 2 问：78.100 落在 72.0/21 的 76~79 段（76 块 /22 含 76~79），匹配 192.168.76.0/22。
- 第 3 问：载荷 = 3800B；每片载荷 = ⌊(1420−20)/8⌋×8 = 1400B；片数 = ⌈3800/1400⌉ = 3。

【参考步骤】
1. **分配结果**（自 /21 块起点顺序切分）：

| 部门 | 前缀 | 可用范围 | 广播地址 |
|---|---|---|---|
| A | 192.168.72.0/23 | 192.168.72.1 ~ 192.168.73.254 | 192.168.73.255 |
| B | 192.168.74.0/24 | 192.168.74.1 ~ 192.168.74.254 | 192.168.74.255 |
| C | 192.168.75.0/25 | 192.168.75.1 ~ 192.168.75.126 | 192.168.75.127 |
| D | 192.168.75.128/26 | 192.168.75.129 ~ 192.168.75.190 | 192.168.75.191 |

剩余 192.168.75.192/26 备用。

2. **路由匹配**：192.168.78.100 = 192.168.**0100**1110.01100100，前 22 位含 76.0 段（76=01001100，78=01001110，共享前 22 位 010011xx），故匹配 **192.168.76.0/22**；192.168.72.0/22 的第 3 字节前 2 位为 01（72~75），不匹配 78。体现最长前缀匹配下合法前缀不相交原则。

3. **分片表**（载荷 3800B，每片 1400B）：

| 分片 | 载荷 | 片偏移（÷8） | MF |
|---|---|---|---|
| 1 | 1400 | 0 | 1 |
| 2 | 1400 | 175 | 1 |
| 3 | 1000 | 350 | 0 |

验证：1400/8=175 ✓；2800/8=350 ✓；175+175+125=475=3800/8 ✓。每片总长分别为 1420、1420、1020B，均 ≤ MTU 且载荷为 8 的倍数（最后一片 1000B=125×8，恰好对齐）。

【时空复杂度分析】
- 第 1 问子网划分：对 k 个需求排序 O(k log k)，逐个取 ⌈log₂(n+2)⌉ 位，总时间 O(k log k)，空间 O(k)。
- 路由最长前缀匹配：线性表逐项 O(R)（R 为表项数）；用 Trie（ Patricia 树）可优化为 O(W)（W=32），空间 O(R·W)。
- 分片计算：纯算术 O(1) 时间、O(1) 空间；若程序化输出 m 片，时间 O(m)，m = ⌈载荷/每片上限⌉。
