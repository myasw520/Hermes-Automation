# 📚 408 考点深度剖析与变式题库：双指针与滑动窗口

## ⚡ 一、核心考点秒懂精髓

- **底层机制**：双指针本质是通过**两个同步/异步移动的索引（或指针）将一维扫描的冗余比较压缩为线性趟数**。快慢指针利用**相对速度差**（快指针每次走2步、慢指针走1步）将链表判环转化为“有限状态追及问题”——若存在环，快指针必在环内以每轮缩短1的距离追上慢指针；找倒数第k个结点利用**固定间距平移**（先导指针先行k步，随后同步走，先导指针到达NULL时后指针即目标）；链表中点利用**速度2:1差**，快指针到达尾部时慢指针恰在（偶数长度时为上中点或下中点，取决于循环终止条件）。三路Partition（荷兰国旗问题）用**lt/gt/cur 三指针**将数组划为 `<区 | ==区 | 待定 | >区` 四段，一次扫描完成三分类。
- **记忆口诀**：
  - “判环看追及，速度差为1；相遇后，头起慢指针再走到相会即入口”（Floyd 第二阶段：相遇点到环入口距离 = 头结点到环入口距离）。
  - “倒数第k先走k，中点快两慢一”。
  - “三路划分：小于扔左边，大于扔右边，等于不动 cur 自增”。

## ⚠️ 二、考场高频杀手陷阱透析

1. **判环法“重置起点”写错**：Floyd 相遇后，常见错误是将慢指针重置回**头结点后两指针继续同速走，却误判在头结点相遇**——正确做法是两指针均每次走 **1 步**，再次相遇点即环入口。另一陷阱：链表**无环时**快指针可能一次走2步跨过 NULL 再解引用 `fast->next->next`，必须先判 `fast && fast->next`，否则空指针崩溃（408 大题代码错误扣分点）。
2. **“原地 O(1) 空间”约束下误用辅助数组/栈**：如找倒数第k个结点，考生写出“先遍历求长度 n，再走 n-k 步”——该法正确但**需两趟扫描**，若题目限定“一趟扫描”则必须用先导指针法；三路 Partition 中考生常将 "== 区" 忽略导致退化为两路划分，或 `gt--` 后**忘记对换回的元素重新判定**（新换到 cur 位置的元素未处理就 `cur++`，产生漏划）。
3. **奇偶长度边界与“第几个”歧义**：求中点时，长度为 6 的链表，`while(fast->next->next)` 终止于**上中点**（第3个），`while(fast->next)` 终止于**下中点**（第4个）——题目问“中间结点”通常指 `⌈n/2⌉` 位置的**下中点**（如 LeetCode 876 约定），选错循环条件差一位即整题崩盘；倒数第 k 个结点中 k 的语义（k=1 是尾结点还是首结点）必须在代码注释/文字说明中显式声明，408 阅卷对“约定不清”扣分。

## 🎯 三、经典真题同源变式题 1（单项选择）

【题目背景】设单链表（无头结点）长度为 n（n≥2），可能存在环。head 指向首元结点。采用 Floyd 判圈算法：slow 每次走 1 步，fast 每次走 2 步，fast 每次连续执行 `fast=fast->next->next`。已知链表中**存在环**，环上有 m 个结点（m≥2），慢指针进入环后，设再经过 x 步两指针首次相遇。以下叙述**正确**的是：

A. 慢指针进入环后，快指针每走一轮环，与慢指针的间隔缩短 2 个结点，故最多 ⌈m/2⌉ 步内必相遇
B. x 一定小于 m，且 x 的值不仅与 m 有关，还与头结点到环入口的距离 d 有关
C. 若将快指针改为每次走 3 步，慢指针仍走 1 步，则因相对速度差为 2，快指针可能在环内“跳过”慢指针而永不相遇
D. 相遇后，将 slow 重置回 head，两指针每次各走 2 步，再次相遇处即环入口

【正确答案】：**B**

【深度解析】：
- **B 正确**：慢指针进入环的瞬间，设入口处快指针相对慢指针的领先量为 r = (快指针此时在环内位置偏移)，该偏移取决于 d（head 到入口距离）与 m 的奇偶配合，故 x = 依据初始相位差推导，与 d、m 均相关。严谨推导：设入环时快指针在环内偏移 s（0≤s<m），每走一步间隔缩小 1（mod m），相遇条件 s − x ≡ 0 (mod m)，首次相遇 x = m − s（若 s≠0；s=0 则 x=0），而 s = (2d − d) mod m = d mod m…… 实际上 s = (d) mod m 的具体值随 d 变化，故 x 依赖于 d。
- **A 错误**：陷阱在于“相对速度差是 1 不是 2”——快每步走 2、慢走 1，每步仅缩短 1 个位置；且慢指针尚未入环时快指针已在环内多绕，间隔缩短每步 1，最坏约需 m 步而非 ⌈m/2⌉。
- **C 错误**：相对速度差为 2（mod m），当 gcd(2, m)=2 且 m 为偶数时确实存在步进 2 的“跳过”可能；但 **m 为奇数时 gcd(2,m)=1 必相遇**。C 选项以偏概全断言“永不相遇”，错误。
- **D 错误**：Floyd 第二阶段两指针必须**每次各走 1 步**，走 2 步会跳过入口结点（除非 m、d 满足特殊整除关系），一般情形不成立于入口相遇。

## 🚀 四、经典真题同源变式题 2（综合应用/大题设计）

【综合大题】（13 分）
已知一个不带头结点的单链表，结点结构为：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```

链表中结点值均为整数。现要求设计算法：**一趟扫描**完成以下两件事：
1. 找出链表的**中间结点**（若长度为偶数，取第 n/2+1 个结点，即下中点）；
2. 判断链表是否存在环，若存在，返回环入口结点。

**输入规格**：head 为 LinkList 类型，结点数 0 ≤ n ≤ 10⁵。
**输出要求**：返回环入口结点指针（无环返回 NULL），并通过指针参数 `mid` 带回中间结点地址。
**算法约束**：时间复杂度 O(n)；空间复杂度 O(1)（不得使用哈希表、数组、栈等辅助结构）；**只允许对链表进行一趟完整遍历**（判环与找中点需在一次快慢指针扫描中同时完成）。

【解题思路】：
1. **快慢指针合二为一**：slow 每步走 1，fast 每步走 2。循环条件 `fast && fast->next` 保证无环时不越界。循环自然结束时 fast 已到达 NULL 或尾结点——**循环正常退出即无环**，此时 slow 恰为下中点（fast 走完/走到尾时 slow 走了 ⌈n/2⌉ 步，位于第 ⌊n/2⌋+1 个结点）。
2. **有环时**：fast 追上 slow，记录相遇点 meet。随后 slow 重置为 head，slow、fast（现指 meet）**每次各走 1 步**，再次相遇即环入口（Floyd 第二阶段数学等价：设头到入口 d，入口到相遇点 p，环长 c，相遇时 slow 在环内走了 p = c·k − d … 化简后 d ≡ p (mod c)，故从头和从相遇点同速出发必在入口会合）。
3. **中点语义**：有环时“中间结点”无良定义，题目默认在**无环时**返回 mid；有环时置 `*mid = NULL` 并说明（防歧义，408 阅卷重视约定声明）。

【参考代码】：

```c
LNode* FindMidAndEntry(LinkList head, LNode **mid) {
    *mid = NULL;
    if (head == NULL) return NULL;

    LNode *slow = head, *fast = head;
    while (fast && fast->next) {      // 无环时安全终止
        slow = slow->next;            // 慢走 1
        fast = fast->next->next;      // 快走 2
        if (slow == fast) {           // 相遇 => 有环
            slow = head;              // Floyd 第二阶段
            while (slow != fast) {    // 均每次走 1 步
                slow = slow->next;
                fast = fast->next;
            }
            return slow;              // 环入口（*mid 保持 NULL）
        }
    }
    *mid = slow;                      // 循环正常退出：slow 即下中点
    return NULL;                      // 无环
}
```

【时空复杂度分析】：
- **时间复杂度 O(n)**：第一阶段快指针每步前进 2，至多走 ⌈n/2⌉ 步即到链尾（无环）或在环内至多再绕 c 步追上慢指针（有环，c ≤ n），总步数 ≤ 2n，为线性；第二阶段慢指针从 head 走 d 步到入口，与 fast 从相遇点走 p 步到入口同步，d < n，仍是 O(n)。常数级附加判断不影响渐近。
- **空间复杂度 O(1)**：仅使用 slow、fast、mid 三个指针变量，无任何随 n 增长的辅助结构，满足原地约束。
- **正确性关键点**（阅卷给分点）：① 循环条件 `fast && fast->next` 防空指针；② 无环/有环的判别隐含于循环退出方式；③ Floyd 第二阶段两指针必须同速（每步 1 步）；④ 中点定义（下中点）已显式声明。
