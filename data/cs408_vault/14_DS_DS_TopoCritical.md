# 📚 408 考点深度剖析与变式题库：拓扑排序与关键路径

## ⚡ 一、核心考点秒懂精髓

**底层机制：**
- **AOV网拓扑排序**：不断输出入度为 0 的顶点并删除其所有出边（邻接点入度 −1），若输出顶点数 < n 则存在有向环。用栈/队列存零入度点，复杂度 O(|V|+|E|)。
- **AOE网关键路径**：正向推 ve（取 max，源点 ve=0），逆向推 vl（取 min，汇点 vl=ve），活动 <i,j>：e = ve(i)，l = vl(j) − w(i,j)，**l − e = 0 的活动为关键活动**，关键路径 = 源点到汇点最长路径，其长度 = 工程最短完工时间。

**口诀：**
> “顺推取大 ve，逆推取小 vl；早始借头，迟始借尾减权；余量为零即关键。”
> 捷径：**关键活动必在所有最长路径上；ve 相等且 vl 相等的相邻关键活动方可交换/缩短才有效。**

## ⚠️ 二、考场高频杀手陷阱透析

**陷阱 1：汇点 vl 初始化错误 / 忘记多汇点**
vl 全部初始化为 ve(汇点)（而非 ∞ 或 0）；若图有多个汇点，须设虚拟汇点或取所有汇点中 ve 最大值统一。多源点多汇点时关键路径需加虚拟源/汇，长度不变但关键活动归属易算错。

**陷阱 2：误以为缩短任一关键活动必缩短工期 / 关键路径唯一**
只有当该活动是**所有**关键路径的公共活动，且缩短量不超过其他路径余量时，工期才缩短。缩短过度，关键路径会转移，甚至次关键路径变关键，工期不变。判断“关键路径是否唯一”看 ve=vl 的顶点序列是否分叉。

**陷阱 3：拓扑序列不唯一 ≠ 关键路径不唯一；判断环的方法用错**
- 拓扑排序用 DFS 得到的是**逆拓扑**序（需逆置才能用于求 vl），且不能像 BFS 拓扑那样直接检测环——环检测必须用入度法（Kahn）或 DFS 染色。
- 求 vl 时必须按**逆拓扑序**；用邻接表存图时，逆拓扑序求 vl 需沿边表反向，若误用正向边表 vl(j) = min{vl(i) − w} 方向即错。

## 🎯 三、经典真题同源变式题 1

【题目背景】某工程 AOE 网有 6 个事件 v1~v6，9 个活动及历时如下：v1→v2 (3)、v1→v3 (2)、v2→v4 (4)、v3→v4 (5)、v2→v5 (6)、v4→v5 (2)、v4→v6 (7)、v5→v6 (4)、v3→v6 (9)。v1 为源点，v6 为汇点。则工程最短工期及“缩短后不能缩短总工期”的活动是：

A. 工期 18；活动 v3→v6
B. 工期 17；活动 v4→v6
C. 工期 17；活动 v2→v4
D. 工期 18；活动 v1→v3

【正确答案】**C**

【深度解析】
逐点求 ve：ve(1)=0；ve(2)=3；ve(3)=2；ve(4)=max(3+4, 2+5)=7；ve(5)=max(3+6, 7+2)=9；ve(6)=max(9+4, 7+7, 2+9)=14。**工期 = 14**（先排除 A、D）。

逆推 vl：vl(6)=14；vl(5)=10；vl(4)=min(14−7, 10−2)=7；vl(3)=min(7−5, 14−9)=2；vl(2)=min(7−4, 10−6)=3；vl(1)=0。

关键活动（l−e=0）：v1→v2 (0+3=3=vl2✓)、v1→v3、v3→v4、v4→v6 (7+7=14✓)、v2→v4 (3+4=7✓)、v4→v5 (7+2=9=vl5✓)、v5→v6 (10+4=14✓)。

两条关键路径：v1→v2→v4→v6（长 14）与 v1→v2→v4→v5→v6（长 14）。公共活动：v1→v2、v2→v4、v4→v6。v4→v6 缩短会使另一条路径成为新关键路径（其上无 v4→v6），总工期不变——但 B 选项工期 17 错误。v3→v6 根本不是关键活动。**只有 v2→v4 属于所有关键路径的公共活动，缩短它才能缩短工期，故选 C。**

陷阱预设：A/D 用错误工期干扰；B 中 v4→v6 虽是关键活动但不在所有关键路径上。

## 🚀 四、经典真题同源变式题 2

【综合大题】设 AOE 网以邻接表存储，顶点编号 1..n（1 为源点，n 为唯一汇点），活动耗时为正整数。要求：

(1) 编写算法判断网中是否存在环，若有环输出 −1；
(2) 若无环，输出关键路径长度及所有关键活动 `<u, v>`（按 u 升序输出）。
要求时间复杂度 O(|V|+|E|)，空间复杂度 O(|V|+|E|)。

【解题思路】
1. **Kahn 拓扑排序**：统计入度，零入度顶点入队，每出队一个 cnt++，并递减后继入度；cnt < n 则有环，返回 −1。
2. 出队过程中按拓扑序**正向递推 ve**：ve[v] = max(ve[v], ve[u] + w)。
3. 逆拓扑序求 vl：vl 全部初始化为 ve[n]（唯一汇点），按拓扑序的**逆序**枚举边，vl[u] = min(vl[u], vl[v] − w)。
4. 扫描所有边：e = ve[u]，l = vl[v] − w，若 l == e 输出 `<u, v>`。关键路径长度 = ve[n]。

**实现技巧**：拓扑序存入数组 topo[]，逆序遍历该数组并枚举其邻接边即得逆拓扑递推。

【参考代码】

```c
#define MAXV 1005
typedef struct ArcNode { int v, w; struct ArcNode *next; } ArcNode;
typedef struct { ArcNode *first; } VNode;
VNode G[MAXV];
int indeg[MAXV], ve[MAXV], vl[MAXV], topo[MAXV];

int CriticalPath(int n) {                 /* 顶点编号 1..n */
    int q[MAXV], head = 0, tail = 0, cnt = 0, i;
    for (i = 1; i <= n; i++) { ve[i] = 0; if (!indeg[i]) q[tail++] = i; }
    while (head < tail) {
        int u = q[head++]; topo[cnt++] = u;
        for (ArcNode *p = G[u].first; p; p = p->next)
            if (--indeg[p->v] == 0) q[tail++] = p->v;
    }
    if (cnt < n) return -1;               /* 有环 */
    for (i = 1; i <= n; i++) vl[i] = ve[n];
    for (i = cnt - 1; i >= 0; i--) {      /* 逆拓扑序求 vl */
        int u = topo[i];
        for (ArcNode *p = G[u].first; p; p = p->next)
            if (vl[p->v] - p->w < vl[u]) vl[u] = vl[p->v] - p->w;
    }
    printf("%d\n", ve[n]);                /* 关键路径长度 */
    for (i = 1; i <= n; i++)              /* 按 u 升序输出关键活动 */
        for (ArcNode *p = G[i].first; p; p = p->next)
            if (ve[i] == vl[p->v] - p->w)
                printf("<%d,%d>\n", i, p->v);
    return 0;
}
```

【时空复杂度分析】
- **时间**：拓扑排序每顶点入队出队一次、每边扫描一次；求 ve 复用同一轮出队遍历；逆推 vl 与输出关键活动各扫一遍边表。总计 O(|V|+|E|)，满足要求。
- **空间**：indeg、ve、vl、topo、队列均为 O(|V|)，邻接表 O(|V|+|E|)，总计 O(|V|+|E|)，满足要求。
- **易错点**：vl 必须按逆拓扑序递推（代码中倒序遍历 topo）；唯一汇点下 vl 一律初始化为 ve[n]；判断 l−e 是否为 0 时用 `ve[u] == vl[v]-w` 避免引入冗余数组。
