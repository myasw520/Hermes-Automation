# 📚 408 考点深度剖析与变式题库：红黑树与并查集

## ⚡ 一、核心考点秒懂精髓

**红黑树本质**：一种“弱平衡”的 BST，通过 5 条性质将最长路径控制在最短路径的 2 倍以内，保证 h ≤ 2·log₂(n+1)。
- 性质1：节点红或黑；性质2：根为黑；性质3：叶（NIL）为黑；性质4：红节点之子必为黑（不存在相邻红）；性质5：任一节点到其所有叶的路径含相同数目黑节点（黑高相等）。
- 插入：新节点**先染红**（不破坏黑高），若父为红则产生“双红冲突”，通过**变色 + 旋转（LL/RR 单旋、LR/RL 双旋）**向上修复；最多 O(log n) 次调整。
- 关键推论：**含 n 个内部节点的红黑树高度 ≤ 2log₂(n+1)**；黑高为 bh 的树至少有 2^bh − 1 个内部节点。

**并查集本质**：用双亲表示法数组 `parent[]` 实现不相交集合，Union 按秩/按大小合并 + Find 路径压缩，单次操作均摊 **O(α(n))** ≈ O(1)，m 次操作总时间 O(m·α(n))。

**记忆口诀**：
> 红黑树：“插红不黑，双红才改；叔红变色，叔黑旋转”；高度上界 2log(n+1)。
> 并查集：“查时压路径，并时按秩挂小”，负数存秩（大小），正数存父。

## ⚠️ 二、考场高频杀手陷阱透析

**陷阱 1：把“叶节点”当成真实数据节点**
红黑树性质 3 中的“叶”指 **NIL 空叶节点（黑色）**，而非度为 0 的关键字节点。选项常以“所有叶子都是黑的”混淆内部叶与外部 NIL。若按内部叶理解，判断性质时极易误判。408 已多次在“下列属于红黑树性质的是”中埋此雷。

**陷阱 2：混淆“新插入节点颜色”与“根变色规则”**
插入的新节点**必为红色**（否则破坏黑高性质 5）；但若插入后树中只有这一个节点（或调整至根），根需**强制变黑**（仅此一次变色，黑高整体 +1）。考生误答“新节点为黑”或“调整时根永远不变色”均丢分。

**陷阱 3：双红冲突中“叔叔颜色”判断与旋转方向错配**
- 叔红 → 只变色（父、叔变黑，爷变红，问题上浮两层，**不旋转**）；
- 叔黑 → 必旋转：LL/RR 单旋 + 换色，LR/RL 先旋成 LL/RR 再单旋。
考生最常犯：叔黑时只变色不旋转（破坏性质 5），或 LR 型直接单旋。另外注意并查集陷阱：**路径压缩与按秩合并同时使用时，rank 只是估计值不再严格准确**——若考题问“合并后 rank 一定较大吗”，答案是否定的。

## 🎯 三、经典真题同源变式题 1（单项选择）

【题目背景】（仿 408 真题风格：给定 n 求高度上界 / 判断性质 / 插入调整）

某红黑树中含有 n 个内部节点（不含 NIL 外部叶节点），树高 h（根到最远叶节点路径的边数）。关于该红黑树，下列叙述**正确**的是：

A. 若 n = 10，则 h 最大可能为 5
B. 该红黑树中最长路径的长度（边数）不超过最短路径长度的 2 倍
C. 插入一个新节点后，若其父节点为黑色，则最多需要旋转 2 次即可恢复红黑性质
D. 树中所有红色节点的孩子必为红色节点

【正确答案】：**B**

【深度解析】：
- **B 正确**：由性质 4、5，从根到叶任一路径上，红节点不能相邻且黑节点数相同。设黑高为 bh，最短路径全黑长 = bh，最长路径黑红交替，长 ≤ 2bh。故最长 ≤ 2×最短。
- **A 错误**：n 个内部节点的红黑树高度 h ≤ 2log₂(n+1)。n=10 时 h ≤ 2log₂11 ≈ 6.9，即 h 可达 6（如黑高为 2、构造红黑交替的极端树实际可到 5~6 层量级，但"h 最大为 5"并非由性质保证的准确界；用 n≥2^bh−1 反推：h=6 需 bh≥3，10 ≥ 2³−1=7 不满足，故 h 最大为 5——**注意此处需精确计算**：bh=2 时最多节点 2²−1 不足以……实际上 h=5 对应 bh=3，最少需 n≥7，10 个节点可构造 h=5；但题目陷阱在于若考生用边数/点数口径混淆，1+2log₂11≈7.9 会得出 7）。严格说：h=5 可达（构造 bh=3、红黑交替的路径），h=6 需 bh≥3 且路径 7 个节点黑 4 红 3 交替，需 n≥2⁴−1=15？不——bh=3 最少节点 7，h=5 可行。A 的迷惑在于口径混乱，许多资料按点数得 h≤2log₂(n+1)≈6.9 → h≤6，但 10 个节点构造不出 h=6（h=6 需至少 bh=3 且一层额外红，需验证，10 个节点无法构造成 h=6 的合法红黑树），故 A 数字上看似接近实为**口径陷阱**——这正是本题鉴别度所在。B 的结论与 n 无关，无条件成立，为唯一严谨正确项。
- **C 错误**：插入后父为黑时**无需任何调整**（0 次旋转），红黑性质天然满足。“最多 2 次”针对的是双红冲突的 LR/RL 情形。干扰项偷换前提。
- **D 错误**：红节点的孩子必为**黑**（性质 4 的逆否表述），选项将“必为黑”篡改为“必为红”，属于性质反向陷阱。

## 🚀 四、经典真题同源变式题 2（综合应用大题）

【综合大题】
给定 n 个元素（编号 0 ~ n−1）和 m 条操作，操作格式如下：
- `1 a b`：将 a、b 所在集合合并（若已属同一集合则忽略）；
- `2 a b`：查询 a、b 是否属于同一集合，是则输出 `Y`，否则输出 `N`。

**约束**：必须实现**路径压缩 + 按大小合并**（合并时将元素个数少的树的根挂到多的树的根下）；n ≤ 10⁴，m ≤ 10⁵，要求近似 O(m·α(n)) 完成全部操作。另请回答：
(1) 若只使用路径压缩、不按大小合并，最坏单次 Find 的时间复杂度是多少？
(2) 若只按大小合并、不路径压缩，m 次操作总时间复杂度是多少？

【解题思路】：
1. 数组 `parent[]`：`parent[i] ≥ 0` 表示父节点下标；`parent[i] < 0` 表示 i 是根，其绝对值为集合大小。
2. **Find 递归路径压缩**：找到根后回溯将路径上所有节点直接挂到根。
3. **Union 按大小**：比较两根的 −parent 值，小者挂大者，并累加大小。
4. 理论问答：
 (1) 只路径压缩：单次 Find 最坏 O(n)（压缩是惰性的，一次操作中仍可能遇到长链），均摊 O(log n)。
 (2) 只按大小合并：树高 ≤ log₂n + 1，单次 Find O(log n)，m 次操作共 **O(m log n)**。

【参考代码】：

```c
#include <stdio.h>
#define MAXN 10004
int parent[MAXN];

void Init(int n) {
    for (int i = 0; i < n; i++) parent[i] = -1; /* 负值=根, 绝对值=集合大小 */
}

int Find(int x) {                    /* 递归路径压缩 */
    if (parent[x] < 0) return x;
    return parent[x] = Find(parent[x]);
}

void Union(int a, int b) {           /* 按大小合并 */
    int ra = Find(a), rb = Find(b);
    if (ra == rb) return;            /* 已同集合, 忽略 */
    if (parent[ra] > parent[rb]) {   /* parent更负者更大; 小树挂大树 */
        parent[ra] += parent[rb];
        parent[rb] = ra;
    } else {
        parent[rb] += parent[ra];
        parent[ra] = rb;
    }
}

int main(void) {
    int n, m, op, a, b;
    scanf("%d %d", &n, &m);
    Init(n);
    while (m--) {
        scanf("%d %d %d", &op, &a, &b);
        if (op == 1) Union(a, b);
        else putchar(Find(a) == Find(b) ? 'Y' : 'N');
    }
    return 0;
}
```

【时空复杂度分析】：
- **时间**：路径压缩 + 按大小合并下，单次操作均摊 O(α(n))（α 为阿克曼反函数，n ≤ 10⁴ 时 α ≤ 4，可视为常数），m 次操作总计 **O(m·α(n)) ≈ O(m)**。Find 递归虽写为递归，路径长度均摊常数级，无栈溢出风险。
- **空间**：parent 数组 O(n)，无额外辅助空间（原地、非递归主导），空间复杂度 **O(n)**。
- 理论对比记忆：只压缩 O(m log n)（均摊）；只按大小 O(m log n)（最坏）；两者同用才达 O(m·α(n))——408 常以此三档复杂度设置填空/选择题。
