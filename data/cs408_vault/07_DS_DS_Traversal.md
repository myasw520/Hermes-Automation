# 📚 408 考点深度剖析与变式题库：二叉树遍历与线索化

## ⚡ 一、核心考点秒懂精髓

**底层运行机制：**
- 递归遍历本质是**系统栈隐式模拟**；迭代遍历是**显式栈模拟**，其中后序迭代需记录最近访问指针或“双次压栈”判断（先序：先右后左压栈；中序：沿左链下钻；后序：lastVisited 判断右子树是否已访问）。
- 层次遍历借助**队列**，先进先出保证同层从左到右、逐层向下。
- 线索二叉树利用 n+1 个空闲指针（n 个结点共 2n 指针域，用到 n-1 个），**ltag=0 指左孩子，ltag=1 指前驱；rtag=0 指右孩子，rtag=1 指后继**。中序线索树中：结点前驱 = 左子树最右下结点（或左线索）；后继 = 右子树最左下结点（或右线索）。

**考场口诀：**
- 「先序根左右，中序左根右，后序左右根，层序队列走」；迭代统一技巧：**访问与压栈顺序反着来**（先序访问后压右再压左）。
- 线索找后继：「rtag 为 1 直接跳，rtag 为 0 右子树里找最左角」。

## ⚠️ 二、考场高频杀手陷阱透析

1. **线索树判定先序/后继的思维错位**：考生常把中序线索树的规则套到先序线索树上。致命点：**先序线索二叉树中找先序后继时，若 rtag=0 且结点有左孩子，后继是左孩子**——但在中序线索树中这是错误的（中序后继须看右子树）。另有经典陷阱：**先序线索树无法在不 parent 指针下高效找先序前驱**（前驱可能是父亲，需回溯）。
2. **后序迭代遍历的“回头访问”**：考生用中序迭代框架改后序时，忘记判断右子树是否已访问，导致栈中结点重复弹出、输出顺序混乱（左右根变成根右左或死循环）。必须引入 lastVisited 或“结点二次入栈”标志。
3. **中序线索化时破坏原树结构 / 前驱丢失**：手写线索化代码时，递归进入右子树前若不保存 pre 指针更新顺序，或线索化过程中先将 pre->rtag 改为线索导致后续遍历走到前驱，会造成结构破坏。考试判断题/选择题常考：**线索化后不能再使用普通遍历，且悬空指针处理**（最后一个结点 rtag=1, rchild 可置 NULL 或指向头结点）。

## 🎯 三、经典真题同源变式题 1（单项选择）

【题目背景】已知一棵二叉树的中序序列为 **D B E A F C G**，后序序列为 **D E B F G C A**，现将其所有 n+1 个空指针域线索化（中序线索，悬挂处理为 NULL）。请回答：

(1) 结点 F 的中序后继是？
(2) 结点 E 的中序前驱是？
(3) 该树中度为 1 的结点个数是？

- A. (1)G (2)B (3)0
- B. (1)C (2)B (3)2
- C. (1)G (2)D (3)1
- D. (1)C (2)D (3)3

【正确答案】：**B**

【深度解析】：
- 由后序末元素 A 定根，中序切分：左子树 {D,B,E}，右子树 {F,C,G}。左子树后序 {D,E,B} → B 为根，D 为左孩子、E 为右孩子（D 无右、E 无孩子，可验证唯一）。右子树后序 {F,G,C} → C 为根，F 为左孩子、G 为右孩子。
- **F 的中序后继**：F 有右孩子？无 → F 的 rtag=1 线索，指向中序下一个。F 中序位置后为 C？中序：D B E **A F** C G → F 后继是 **C**。陷阱：选 G 的考生误以为后继是右子树最左（但 F 无右子树，走线索）；或误按先序。
- **E 的中序前驱**：E 无左孩子 → 左线索指向前驱，即中序 E 前面的 **B**。选 D 的考生混淆了“无左孩子时前驱是父结点的左线索指向”与后序关系。
- **度为 1 结点**：B（左 D 右 E，度 2）、A（度 2）、C（度 2）、D/E/F/G 叶子 → 度 1 结点 = **0 个**。选 C/D 的考生误把只有线索指向的叶子 D 当成度为 1——**线索指针不改变结点度数**，这是最大陷阱。

综合 (1)C (2)B (3)0 → 答案 **B**。

## 🚀 四、经典真题同源变式题 2（综合应用大题）

【综合大题】设二叉树采用二叉链表存储，结点定义：

```c
typedef struct TNode {
    int data;
    struct TNode *lchild, *rchild;
} TNode;
```

(1) 设计算法：**非递归后序遍历**该二叉树，输出后序序列。（要求：不允许递归，不得修改结点结构。）

(2) 基于上述后序遍历思想，进一步设计算法：输出**结点 x 的所有祖先结点值**（从直接父结点到根），要求利用栈中现存信息，时间 O(h)，不得二次遍历整棵树。

【解题思路】：
- (1) 双标记法：指针 p 从根出发，辅助栈保存结点；用 lastVisited 记录上一个被访问（输出）的结点。当栈顶结点的右孩子为空，或右孩子恰好是 lastVisited，说明其左右子树均已处理，弹出并访问；否则转去处理右子树。
- (2) 关键洞察：**当后序遍历到达 x 时，栈中自底向上恰为 x 的全部祖先**（x 被访问前其祖先均在栈中等待右子树完成）。因此找到 x 输出的时刻直接弹出栈即可。

【参考代码】：

```c
#define MAXSIZE 100
TNode* s[MAXSIZE]; int top = -1;      // 辅助栈

void PostOrder(TNode *T) {            // (1) 非递归后序遍历
    TNode *p = T, *lastVisited = NULL;
    while (p || top != -1) {
        if (p) {                       // 沿左链下钻
            s[++top] = p;
            p = p->lchild;
        } else {
            TNode *t = s[top];         // 看栈顶，不弹
            if (t->rchild && t->rchild != lastVisited)
                p = t->rchild;         // 右子树未访问，转向
            else {
                printf("%d ", t->data);// 左右均完成，访问
                lastVisited = t;
                top--;
            }
        }
    }
}

void PrintAncestors(TNode *T, int x) {// (2) 输出 x 的全部祖先
    TNode *p = T, *lastVisited = NULL;
    while (p || top != -1) {
        if (p) {
            s[++top] = p;
            if (p->data == x) {        // 找到 x：栈内即祖先
                while (top >= 0)       // 栈顶是 x 本身，弹出
                    printf("%d ", s[top--]->data);
                top = -1;              // 清栈防止误用
                return;
            }
            p = p->lchild;
        } else {
            TNode *t = s[top];
            if (t->rchild && t->rchild != lastVisited)
                p = t->rchild;
            else {
                lastVisited = t;
                top--;
            }
        }
    }
}
```

【时空复杂度分析】：
- **时间复杂度**：两算法中每个结点至多入栈一次、出栈一次，且每个结点被“察看”次数常数次（作为左钻点/栈顶/右转来源），故均为 **O(n)**；PrintAncestors 在找到 x 后立即返回，最坏 O(n)（树退化为链且 x 为最深层叶子），平均 O(h)。
- **空间复杂度**：栈深最大为树高，最好 O(log n)（平衡），最坏 O(n)（单支树），均为 **O(h) ≤ O(n)**；lastVisited 等辅助变量 O(1)。第 (2) 问无需二次遍历，满足 O(h) 栈空间附加约束（祖先信息即栈内容，输出代价不计入算法空间）。
