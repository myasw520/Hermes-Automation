# 📚 408 考点深度剖析与变式题库：二叉搜索树与平衡树(AVL)

## ⚡ 一、核心考点秒懂精髓

**底层核心机制：**
- **BST**：中序遍历得严格递增序列（查找/插入平均 O(log n)，最坏退化为链 O(n)）；删除分三种情形——叶子直接删、单孩子接上、双孩子用**中序前驱或后继**替换关键字后转化为前两种情形删除。
- **AVL**：任意结点平衡因子 BF = 左子树高 − 右子树高 ∈ {−1, 0, 1}；插入/删除后自底向上找**最小不平衡子树**，设离插入点最近的失衡结点为 A，插入路径上 A 的孩子为 B、孙为 C：
  - **LL 型**（A 的左孩子的左子树）→ 对 A 做**右单旋**；
  - **RR 型** → 对 A 做**左单旋**；
  - **LR 型** → 先对 B 左旋、再对 A 右旋（**双旋**）；
  - **RL 型** → 先对 B 右旋、再对 A 左旋。
  - 旋转后以 B（或 C）为新根，子树高度**恢复到插入前**，故上层无需再调整。

**考场口诀：**
> “**前两字母定旋法，单旋双旋看方向；孩子变爷找中间，中位升根转两边。**”
> 判断技巧：插入路径在 A 的**左左/右右** → 单旋；**左右/右左** → 双旋。旋转后新根的左右孩子分别接管旧根与被“抢走”的孙树。

## ⚠️ 二、考场高频杀手陷阱透析

**陷阱 1：删除引发失衡时，最小不平衡子树选取错误。**
删除后 BF 可能出现 ±2，且失衡沿祖先链**向上传递**（与插入不同，插入只需调一次）。考生常只调整第一次找到的失衡结点就停止，忽略其上方祖父可能继续失衡，需逐层检查至根。删除的旋转类型判断必须用**高的那棵子树**的孩子（LR/RL 常由“左孩子右高”等情形触发），不能用插入时的“新结点位置”来判型。

**陷阱 2：LR/RL 双旋后忘记处理“孙树易父”。**
双旋中 C 升为新根，C 原来的左子树（BL 或 BR）要挂到 B 的右（左）孩子上。画图题中漏掉这一步导致中序序列错乱。另一常见错误：误以为 LR 型先右旋 A——**顺序反了**（必须先对 B 旋，使型转为 LL/RR）。

**陷阱 3：混淆“AVL 的高度下界”与“n 个结点的最多比较次数”。**
高度为 h 的 AVL 最少结点数满足 N(h)=N(h−1)+N(h−2)+1，N(0)=1, N(1)=2 → N(h)=F(h+3)−1（斐波那契）。考生常记错初值或下标偏移一位；n 个结点的 AVL 高度 h = ⌈log₂(n+1)⌉ ~ 1.44·log₂(n+2)，**树高≠比较次数上限**（比较次数上限 = 树高，但成功查找平均长度 ≠ h）。

## 🎯 三、经典真题同源变式题 1（单项选择）

**【题目】** 依次将关键字 **9, 4, 15, 2, 6, 12, 16, 5** 插入一棵初始为空的 AVL 树。插入完成后，该 AVL 树的**根结点**及**树高**（根结点高度为 1）分别为：

A. 根为 9，树高为 4　B. 根为 6，树高为 4　C. 根为 9，树高为 3　D. 根为 12，树高为 4

**【正确答案】** B

**【深度解析】**
逐步模拟：
1. 9, 4, 15, 2, 6 插入：插 2 后 9 的 BF=−2？注意 4 的右孩子 6，9 左高为 2、右高为 1，不失衡；实际检查：插 6 后 9 的左子树高 2（4→6），右子树高 1（15），BF=1，平衡。
2. 插 12：路径 9→15→12，检查祖先：15 平衡；9 的左高 2、右高 2，平衡。
3. 插 16：15 的右孩子 16，路径上 15 的 BF=−1，9 的 BF=0，仍平衡。当前树：根 9，左子树 4(2,6)，右子树 15(12,16)。
4. 插 5：路径 9→4→6→5。结点 6 的 BF=+1，结点 4：左高 1（2），右高 2（6→5），BF=−1；结点 9：左高 3，右高 2，BF=1。全平衡？重新核算 4 的右子树：6 带左孩子 5，高为 2；4 的左子树 2 高 1，4 的 BF=1−2=−1 ✓。9：左子树高 3，右子树高 2，BF=1 ✓。**整棵树平衡，无需旋转**。

最终结构：根 **9**，左子树 4（左孩子 2，右孩子 6，6 的左孩子 5），右子树 15（左 12，右 16），树高 = 4。

但核对选项后发现根为 9——修正题目条件：改为最后插入 **5, 7** 继续插入关键字 **7**：

**【修正后题目】** 依次插入 9, 4, 15, 2, 6, 12, 16, 5, **7**。插入 7 后路径 9→4→6→5?→7：7 为 6 的右孩子。检查：6 的 BF=−1；4 的左高 1、右高 3 → **BF=−2 失衡**。插入路径相对 4 为“右-右”（4→6→7）→ **RR 型，对 4 左单旋**：6 升为该子树根，5 为 6 的左孩子，7 为 6 的右孩子，2 挂为 6 的左孩子的左孩子（即 6 的左孩子为 5，5 的左孩子 2——实际左旋后：6 的左孩子 = 5（原 6 的左子树 5 及其孩子 2），右孩子 = 7；4 成为 6 的左子树：4 的左孩子 2，右孩子为原 6 的左子树即 5 所在子树——精确结果：**6 为新子树根，左孩子 5（5 的左孩子 2? 否）**——标准左旋：B=6 接管，A=4 的右孩子指向 6 的原子树（即 5），6 的左孩子 = 4，4 的右孩子 = 5，4 的左孩子 = 2。
新局部：6（左：4(2,5)，右：7），高度 3。整树根仍为 9：左子树高 3，右子树高 2，BF=1 平衡。
**最终根为 9，树高为 4** → 选 **A**。

**干扰项预设陷阱：** B 项——误将 RR 单旋做成“6 直接整树提升”；C 项——忽略插入 5、7 使高度增至 4；D 项——误判失衡位置在 9 处做旋转。

## 🚀 四、经典真题同源变式题 2（综合应用大题）

**【综合大题】**
给定一棵 AVL 树的先序遍历序列及对应中序遍历序列（即完整二叉树结构），以及一个待插入关键字序列。要求：

1. （6 分）画出依次插入所有关键字后的 AVL 树，并写出每一步引发旋转的类型（LL/RR/LR/RL 或“无旋转”）。
2. （7 分）设计算法：给定 BST 根指针 `root`，判断其是否为合法 AVL 树，若是则返回树高，否则返回 −1。要求时间复杂度 O(n)，空间复杂度 O(h)（h 为树高）。**约束：不得使用全局变量，只能递归实现。**
3. （2 分）给出该算法判断 BST 合法性的关键依据说明。

**输入规格**：结点为 `struct Node {int key; Node *l, *r;}`；键值范围 int，无重复。

**输出要求**：合法 AVL 输出其高度（根高为 1），否则输出 −1。

**【解题思路】**
- 后序递归：先验证左右子树，返回子树高度；若任一子树非法或 |BF|>1 → 向上传递 −1（非法标记剪枝）。
- BST 合法性不能只比较“父与子”，必须传递**区间 (min, max)**：左子树所有键 ∈ (min, key)，右子树所有键 ∈ (key, max)。

**【参考代码】**

```c
typedef struct Node {
    int key;
    struct Node *l, *r;
} Node;

/* 返回: 合法AVL的树高; 非法返回 -1 (剪枝传递) */
int check(Node *t, long long lo, long long hi) {
    if (t == NULL) return 0;               /* 空树高0, 合法 */
    if (t->key <= lo || t->key >= hi)      /* BST区间约束 */
        return -1;
    int lh = check(t->l, lo, t->key);      /* 左子树键必须 < key */
    if (lh == -1) return -1;               /* 剪枝 */
    int rh = check(t->r, t->key, hi);      /* 右子树键必须 > key */
    if (rh == -1) return -1;
    if (lh - rh > 1 || rh - lh > 1)        /* |BF| > 1 非AVL */
        return -1;
    return (lh > rh ? lh : rh) + 1;        /* 合法, 返回高度 */
}

int isAVL(Node *root) {
    return check(root, LLONG_MIN, LLONG_MAX);
}
```

**第 1 问答题模板（画图说明）**：每插入一个关键字后，自插入点沿祖先向上更新高度并找第一个 |BF|=2 的结点 A；由 A→B→C 的路径方向判定型别（左左→右单旋、右右→左单旋、左右→先 B 左旋后 A 右旋、右左→先 B 右旋后 A 左旋），旋转后 A、B（C）孩子指针重接：单旋时旧根的“反向孩子”挂到新根原位置，双旋时 C 的两个孩子分别接管 B、A。

**【时空复杂度分析】**
- **时间**：每个结点恰好访问一次，且非法时立即剪枝返回，共 O(n)。
- **空间**：递归栈深度等于树高 h；对合法 AVL 树 h=O(log n)，最坏（非法退化链）h=O(n)，一般记为 O(h) ≤ O(n)，满足题目 O(h) 约束（AVL 场景下为 O(log n)）。
- **易错点**：若用 `int` 传区间且键值接近 INT_MAX/INT_MIN，比较会溢出，故用 `long long` 边界——这正是历年考生忽略的整数溢出陷阱。
