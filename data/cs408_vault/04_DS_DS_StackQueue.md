# 📚 408 考点深度剖析与变式题库：栈与队列及应用

## ⚡ 一、核心考点秒懂精髓

- **卡特兰数**：n 个不同元素依次入栈，合法出栈序列数为 C(2n, n)/(n+1)。合法性判定：任意前缀中，出栈次数 ≤ 入栈次数；且序列中任意元素之后入栈的元素若先出栈，必须按逆序出栈。
- **循环队列判空判满**：
  - **牺牲单元法**：`(rear+1) % MaxSize == front` 为满，`rear == front` 为空，元素数 `(rear - front + MaxSize) % MaxSize`。
  - **tag 法**：仅当入队导致 `front==rear` 时 tag=1（满），出队导致 `front==rear` 时 tag=0（空）。
- **中缀转后缀**：操作数直接输出；运算符与栈顶比较优先级，栈顶优先级 ≥ 当前则弹栈输出（左括号除外）；左括号直接入栈，右括号弹至左括号为止。
- **递归工作栈**：每次函数调用压入活动记录（参数、局部变量、返回地址），栈深 = 最大递归深度，决定空间复杂度。

**记忆口诀**：
> 出栈序列数 = "卡塔兰" C(2n,n)/(n+1)；n=3 时为 5，n=4 时为 14。
> 队满牺牲一格，队空两指针重合；tag 标记“进 1 出 0”。
> 中缀转后缀：“数直接走，符比优先，括号护身”。

## ⚠️ 二、考场高频杀手陷阱透析

1. **卡特兰数误用/混排问题**：考生常将"n 个元素入栈，求出栈序列数”与“判断某具体序列是否合法”混淆；更有考生忘记除以 (n+1)，直接答 C(2n,n)（如 n=3 时误答 20）。陷阱：题目若说“入栈顺序可交叉/允许边进边出”，必须检验每个前缀出栈数 ≤ 入栈数，而不是背数列。**3、1、2、4 这类序列合法，3、1、4、2 也合法，但 3、1、2 时若下一个出的是 5 之后……必须用模拟法验证**。

2. **循环队列取模方向与牺牲单元丢失**：
   - 误写 `rear % MaxSize == front` 为满（漏 +1）；
   - 求“队列中最多容纳元素数”时答 MaxSize，实际牺牲单元法只能存 MaxSize−1 个；
   - tag 法中：若初始 tag=0 且 front==rear，考生误判为满——tag 的语义绑定于“最后一次操作是入队还是出队”，判满条件是 `front==rear && tag==1`。

3. **中缀转后缀优先级/结合性处理错误**：同级运算符不弹栈（右结合误当左结合）；忽略 `^`（幂）是右结合需 `>` 才弹；负号（一元）未处理。大题中求值时后缀序列遇减法/除法必须**栈顶第二操作数 op 栈顶操作数**（a 先 b 后：先弹的是 b），顺序颠倒是最常见丢分点。

## 🎯 三、经典真题同源变式题 1（单项选择）

【题目背景】设循环队列采用牺牲一个存储单元法区分队空与队满，数组下标 0～m−1（共 m 个单元），front 指向队头元素，rear 指向队尾元素的**下一位置**。初始 front=rear=0。现有元素 a₁~a₄ 依次入队……后经若干出队入队操作。

**题目**：在该队列结构下，若 front=15，rear=23，m=32，则队列中当前元素个数为（ ）；该队列最多能容纳的元素个数为（ ）。

- A. 8；32
- B. 8；31
- C. 24；31
- D. 8；30

**【正确答案】：B**

【深度解析】：
- 元素个数公式：`(rear − front + m) % m = (23 − 15 + 32) % 32 = 8`。排除 C（未取模直接做减法反转，典型方向错误陷阱）。
- 牺牲单元法下，队满条件为 `(rear+1)%m == front`，即队头队尾之间空一个单元，故最多容纳 m−1 = 31 个元素。排除 A（误认为全部单元可用）、D（误以为牺牲两个单元）。
- **陷阱预设**：A 项考查“是否知道牺牲单元损失容量”；C 项考查取模运算方向；D 项是“偷概念”干扰——牺牲单元法只空 1 格不是 2 格。

## 🚀 四、经典真题同源变式题 2（综合应用大题）

【综合大题】已知一个中缀表达式字符串（仅含非负整数、`+` `-` `*` `/`、左右括号，单字符运算符，无空格，表达式合法），要求：

1. 将其转换为后缀表达式并输出；
2. 利用栈对后缀表达式求值并输出结果。

**约束**：辅助栈空间 O(n)，时间 O(n)；不使用系统 `eval` 类函数。

**输入示例**：`5+3*(4-2)/2`　　**输出示例**：`5342-*2/+`，结果 `8`

【解题思路】：
- **第一层（转换）**：扫描中缀串——操作数直接追加输出；`(` 入栈；`)` 弹栈输出直到 `(`；运算符 s：当栈顶为优先级 ≥ s 的运算符（左结合）时反复弹栈输出，再将 s 入栈。扫描完后清空栈。
- **第二层（求值）**：扫描后缀串——操作数入栈；遇运算符 op 时弹出栈顶 b、再弹 a，计算 `a op b`，结果压栈。最后栈中唯一元素即答案。
- 优先级：`*` `/` = 2 > `+` `-` = 1。

【参考代码】：

```c
#include <stdio.h>
#include <string.h>
#define MAXN 1005
char opstk[MAXN]; int top1 = -1;   // 转换用运算符栈
int  numstk[MAXN]; int top2 = -1;  // 求值用操作数栈

int pri(char c){ return (c=='*'||c=='/') ? 2 : 1; }

void toPostfix(const char *s, char *post) {
    int k = 0;
    for (int i = 0; s[i]; i++) {
        char c = s[i];
        if (c >= '0' && c <= '9') post[k++] = c;          // 操作数直接输出
        else if (c == '(') opstk[++top1] = c;
        else if (c == ')') {
            while (top1 >= 0 && opstk[top1] != '(') post[k++] = opstk[top1--];
            top1--;                                        // 弹出 '('
        } else {                                           // 运算符
            while (top1 >= 0 && opstk[top1] != '(' &&
                   pri(opstk[top1]) >= pri(c))             // 左结合: >= 弹
                post[k++] = opstk[top1--];
            opstk[++top1] = c;
        }
    }
    while (top1 >= 0) post[k++] = opstk[top1--];
    post[k] = '\0';
}

int evalPostfix(const char *post) {
    for (int i = 0; post[i]; i++) {
        char c = post[i];
        if (c >= '0' && c <= '9') numstk[++top2] = c - '0';
        else {
            int b = numstk[top2--];      // 先弹为右操作数!
            int a = numstk[top2--];
            int r;
            switch (c) {
                case '+': r = a + b; break;
                case '-': r = a - b; break;
                case '*': r = a * b; break;
                case '/': r = a / b; break;
            }
            numstk[++top2] = r;
        }
    }
    return numstk[top2];
}

int main(void) {
    char s[MAXN] = "5+3*(4-2)/2", post[MAXN];
    toPostfix(s, post);
    printf("%s\n", post);        // 5342-*2/+
    printf("%d\n", evalPostfix(post)); // 8
    return 0;
}
```

【时空复杂度分析】：
- **时间复杂度 O(n)**：中缀转后缀中每个字符至多入栈、出栈各一次（均摊 O(1)），求值同理；两次线性扫描，总时间 2O(n) = O(n)。
- **空间复杂度 O(n)**：运算符栈最坏深度（如 `((((…` 全括号嵌套）为 n/2，操作数栈最坏 O(n)，后缀串输出 O(n)，总计 O(n)，满足题目约束。
- **关键正确性论证**：转换阶段 `pri(top) >= pri(c)` 的 "≥" 保证同级左结合运算符按从左到右顺序输出（若遇 `^` 等右结合运算符须改为 `>`，此为易错变式点）；求值阶段先弹 b 后弹 a 保证减法/除法方向正确。
