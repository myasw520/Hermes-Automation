# 📚 408 考点深度剖析与变式题库：Cache 映射与替换策略

## ⚡ 一、核心考点秒懂精髓

**底层机制**：主存地址按位从**低位到高位**依次切分为 `Offset | Index | Tag` 三段。Offset 位数 = log₂块大小；Index 位数 = log₂组数（直接映射时组数=Cache行数，全相联时 Index 为 0 位）；剩余高位全部为 Tag。CPU 访存时用 Index 定位组 → 组内比较所有 Tag → 命中则按 Offset 取数，缺失则按映射规则装入并按替换算法淘汰。

- **映射规则口诀**：直接映射“对号入座”（主存块号 mod 行数）；全相联“随便坐”；组相联“先定组，组内随便坐”（组号 = 主存块号 mod 组数）。
- **拆分公式捷径**：从右往左切——先切 Offset（块大小决定），再切组号（组数决定），剩下的全给 Tag。总地址位数固定，**Tag = 地址总位数 − Index位数 − Offset位数**。
- **写策略配对口诀**：“写回配写分配（只写Cache，缺了才调块）”；“全写配非写分配（直通内存，缺了不调块直接写内存）”。

## ⚠️ 二、考场高频杀手陷阱透析

**陷阱 1：地址拆分单位混淆——按“字节”还是按“块/字”编址？**
真题常给“按字节编址”或“按字编址（每块 4 个字）"。考生误用字节地址拆位。若按字编址且块含 4 字，则 Offset 占 2 位是**字地址**的低 2 位，Tag 划分完全不同。解题第一步必须确认编址单位与主存地址总位数（若主存 2ⁿ 单元，地址就是 n 位）。

**陷阱 2：组相联中“路数”与“组数”颠倒。**
"2 路组相联、Cache 共 8 行"→ 组数 = 8/2 = **4**，Index 占 log₂4 = 3 位，**不是** log₂8。反着算的考生 Index 算 3 位、Tag 短 1 位，全题崩盘。公式：组数 = 总行数 ÷ 相联度。

**陷阱 3：LRU 计数与命中后的状态更新遗漏。**
手算 LRU 时考生常犯：① 命中后忘记把命中块的“年龄”刷新为最新；② 初始装入过程本身也消耗替换机会（空行不算替换，直接装入）；③ 把“缺失但不用替换（有空行）”误当作一次淘汰。另外写回法缺失且被淘汰块为**脏块**时，必须先写回主存再调块——漏掉这次主存写访问会使访存次数统计出错。

**陷阱 4（附加）：写策略与缺失处理错误配对。**
“全写法 + 写分配”这类非标准组合，以及误认为写回法下每次写命中都要访问主存（其实不访问，只置脏位）。命中率/访存开销计算题中，写命中在写回法下不产生主存流量，在全写法下每次都产生。

## 🎯 三、经典真题同源变式题 1（单项选择/计算题）

【题目背景】某计算机主存按**字节编址**，主存地址空间为 4GB（地址 32 位），Cache 数据区容量为 **16KB**，块大小为 **64B**，采用 **4 路组相联映射**，LRU 替换。则：

（1）主存地址中 Tag 字段位数为？
（2）若 CPU 依次访问字节地址 `0x00A0_123F`，该地址映射到 Cache 的组号是？（从 0 开始编号）

- A. Tag = 19 位，组号 4
- B. Tag = 20 位，组号 17
- C. Tag = 20 位，组号 4
- D. Tag = 18 位，组号 17

【正确答案】：**C**

【深度解析】：
- Offset：块 64B = 2⁶ → Offset 占 **6 位**。
- 行数：16KB ÷ 64B = 256 行；组数 = 256 ÷ 4 = 64 = 2⁶ → Index 占 **6 位**。
- Tag = 32 − 6 − 6 = **20 位**。→ 排除 A（19 位，误按组数 128 算）、D（18 位，误把行数当组数 Index 占 8 位）。
- 地址 `0x00A0123F` = 二进制低 12 位 `0001 0010 0011 1111`；组号取第 6~11 位 = `010010`₂ = **18**？——验证：低 6 位 Offset = 111111；接下来 6 位 = `0001 00`？精确拆分：低 6 位为 `101111`（Offset），第 6~11 位为地址第 6 位到第 11 位：0x123F = 0001 0010 0011 1111，其低 12 位中第 6~11 位 = `010010` = 18？注意重新精确计算：0x123F = 0001_0010_0011_1111（12 位，从高位到低位 b11…b0 = 0001 0010 0011 1111）。低 6 位 b5…b0 = 111111（Offset）；b11…b6 = 0001 00 = 0b000100 = **4**。
- 故组号为 **4** → 排除 B（17 来自误取 b12…b6 错位的常见拆位偏移错误）。

**预设陷阱**：A 针对混淆相联度；B 针对拆位偏移一位；D 针对组数/行数不分。答案 C 正确。

## 🚀 四、经典真题同源变式题 2（综合应用/大题设计）

【综合大题】某机主存按**字编址**，共 2²⁴ 个字。Cache 数据容量 4K 字，**块大小 8 字**，采用 **2 路组相联**，初始为空，采用 LRU 替换，**写回法 + 写分配**。

现有如下访问序列（均为字地址，十进制）：

```
0, 8, 1024, 16, 0, 1032, 8, 2048, 1024, 4096, 0, 16
```

要求：
（1）给出主存地址的字段划分（各字段位数及含义）；
（2）逐一判断每次访问命中/缺失，给出最终命中率；
（3）统计此序列执行期间 Cache→主存 的写回次数与主存→Cache 的调块次数。

【解题思路】：
1. 拆地址：块 8 字 → Offset 3 位；行数 = 4096/8 = 512 行，2 路 → 组数 256 → Index 8 位；Tag = 24 − 8 − 3 = 13 位。
2. 每个字地址 → 组号 = (地址 ÷ 8) mod 256；块号 = 地址 ÷ 8。
3. 逐地址模拟：空行直接装入（不算替换）；LRU 每次访问刷新时间戳；写回法下所有访问均视为“读处理”，本题未给写操作，脏块为 0，故写回次数为 0。

【参考步骤】：

块号 = 地址>>3，组号 = 块号 mod 256：

| 序号 | 地址 | 块号 | 组号 | 结果 | 说明 |
|---|---|---|---|---|---|
|1|0|0|0|缺失|装入|
|2|8|1|1|缺失|装入|
|3|1024|128|128|缺失|装入|
|4|16|2|2|缺失|装入|
|5|0|0|0|**命中**||
|6|1032|129|129|缺失|装入|
|7|8|1|1|**命中**||
|8|2048|256|0|缺失|组0满，LRU淘汰块0（上访时间最旧）→**调块**|
|9|1024|128|128|**命中**||
|10|4096|512|0|缺失|组0淘汰块1（序2后未再访问，比块256旧）→**调块**|
|11|0|0|0|缺失|组0淘汰块256 →**调块**|
|12|16|2|2|**命中**||

- 命中 4 次 / 总 12 次 → **命中率 = 4/12 ≈ 33.3%**。
- 主存→Cache 调块次数 = 缺失次数 = **8 次**。
- 写回次数：全为读操作，无脏块 → **0 次**（若序列含写命中则缺失淘汰脏块时 +1）。

【时空复杂度分析】：
模拟算法对 n 次访问逐次处理，每次访问在固定相联度（2 路）内用 O(1) 比较 Tag 并更新 LRU 时间戳（可用计数器实现），故时间复杂度 **O(n)**；Cache 状态表占 512 行 ×（Tag13 位 + LRU 信息 + 脏位），空间复杂度 **O(Cache 行数) = O(512)**，与访问序列长度无关。若相联度为 k 且用数组线性查找，单次 O(k)，总体 O(nk)。

---

**命题人提示**：本大题的鉴别点在于——① 组号需做除法再取模（不能直接取地址低 8 位+1）；② 组 0 三次淘汰的 LRU 顺序判断（序 5 命中刷新了块 0，故序 8 先淘汰块 0 而非块 1）；③ 写回次数为 0 的隐蔽性——多数考生会惯性填 8。这三处正是区分机械刷题与真正理解的分水岭。
