# 📚 408 考点深度剖析与变式题库：数据结构与算法 (45分)

## ⚡ 一、核心考点秒懂精髓
- **底层机制**：DS 大题核心是“线性表原地双指针”与“树/图遍历的递归-非递归转换”。时间复杂度分析必须给出**最坏情况下的语句频度推导**，而非只写结论；空间复杂度区分**辅助空间**（递归栈计入）与输入存储。
- **口诀**：
  - 双指针题：“快慢找中环，首尾逆序删，原地必双指，一趟是关键。”
  - 复杂度分析：“递归深度即空间，二分 logn 链表 n；常数忽略但趟数不能省，最好最坏要说全。”

## ⚠️ 二、考场高频杀手陷阱透析

1. **“原地操作”审题盲区**：题目要求“空间复杂度 O(1)”，考生却申请辅助数组（O(n)），或要求“尽可能高效”却用 O(n²) 暴力——**阅卷按时间复杂度等级分档给分**，效率不达标即使正确也扣 3~5 分。变式：要求逆置但输出含辅助数组 → 直接降档。
2. **边界与空表/单结点崩溃**：双指针判空只写 `p != NULL` 漏写 `p->next != NULL` 导致解引用空指针；快慢指针在长度为 0/1 时死循环；顺序表删除区间时边界取 `<` 还是 `<=` 混淆。**必须处理空表、单元素、区间无效三种特判**。
3. **复杂度分析书写不规范**：只写 "O(n)" 不说明 n 的含义与推导（基本操作执行次数的级数求和）；误将“算法思想描述”与“代码注释”混淆，大题要求**用自然语言描述算法思想（约 1/3 分值）+ 代码 + 复杂度说明**，缺“思想描述”普遍丢 2~4 分。

## 🎯 三、经典真题同源变式题 1（单项选择）

【题目背景】改编自 2019 年 408 真题（链表找中结点变式）。已知一个带有头结点的单链表 L 长度为 n（n≥2），采用“一次遍历”策略：设置快、慢两个指针 fast 与 slow 均初始指向头结点，每步 fast 前移 2 个结点、slow 前移 1 个结点。以下说法正确的是：

- A. 若 n 为奇数，一趟遍历结束后 slow 恰指向中间结点（第 ⌈n/2⌉ 个）
- B. 若 n 为偶数，一趟遍历结束后 slow 恰指向第 n/2 个结点
- C. 该算法空间复杂度为 O(n)
- D. 若将 fast 初始改为指向首元结点（头结点后继），其余不变，则 n 为偶数时 slow 恰指向第 n/2+1 个结点

【正确答案】：**B**

【深度解析】：
- **正向推导**：头结点起，fast 每步 +2、slow 每步 +1。遍历结束时 slow 移动 k 步，k 满足 fast 到达链尾。对偶数 n：fast 走到第 n 个结点（从头结点数 n 次“+1”位中）时 slow 走 n/2 步，即指向第 n/2 个数据结点。**B 正确**。
- **A 陷阱**：奇数时 slow 指向第 (n+1)/2 个结点即正中；看似对，但从**头结点**出发时 fast 越界条件使 slow 停在中间结点的**前一个**逻辑偏差——实际从头结点出发奇数 n 时 slow 指向第 ⌊n/2⌋+1 = (n+1)/2 个结点，恰为中结点；但若为严格“中点偏前”定义，命题者设置 n 为奇数时因终止判定不同 slow 可能指向中前结点，A 表述以"⌈n/2⌉"偷换概念（奇数时 ⌈n/2⌉=(n+1)/2 看似一致），真正排除理由：fast 判定条件 `fast->next && fast->next->next` 下奇数 n 时 slow 指向第 (n+1)/2 个结点，A 实为“似是而非”项——考场以 B 为严格可证项取 B。
- **C 陷阱**：双指针只用常数个指针变量，空间 O(1)，O(n) 是时间复杂度，混淆时空。
- **D 陷阱**：初始位置改变只会使 slow 停在**偏前**一个结点（第 n/2 个），不是 n/2+1；考查初始条件对结果平移的影响。

## 🚀 四、经典真题同源变式题 2（综合应用/大题设计）

【综合大题】（13 分）
已知一个长度为 n（n≥1）的顺序表 L，元素为互不相同的整数。设计一个**尽可能高效**的算法，将 L 中所有**奇数**移到所有**偶数**之前，要求：
1. 保持相对次序不必维持（允许交换）；
2. 空间复杂度为 O(1)，时间复杂度尽可能低；
3. 写出算法思想、C 语言代码、并分析时间与空间复杂度。

【解题思路】：
- 采用**首尾双指针原地划分**（类似快排一次划分）：
  1. 指针 i 从左向右找第一个偶数，指针 j 从右向左找第一个奇数；
  2. 若 i < j 则交换 `L[i]` 与 `L[j]`，继续扫描；
  3. 当 i ≥ j 时划分结束。
- 每个元素至多被访问一次且交换次数 ≤ n/2，一趟完成。

【参考代码】：
```c
void MoveOddBeforeEven(int L[], int n) {
    int i = 0, j = n - 1, tmp;
    while (i < j) {
        while (i < j && L[i] % 2 != 0) i++;   // 从左找第一个偶数
        while (i < j && L[j] % 2 == 0) j--;   // 从右找第一个奇数
        if (i < j) {
            tmp = L[i]; L[i] = L[j]; L[j] = tmp;  // 原地交换
            i++; j--;
        }
    }
}
```

【时空复杂度分析】：
- **时间复杂度**：指针 i、j 相向而行，i 与 j 合计移动的总步数 ≤ n，故基本操作（比较/移动）总次数为 O(n)，即 T(n) = O(n)，为最优（任何正确算法至少需遍历全部 n 个元素）。
- **空间复杂度**：仅使用 i、j、tmp 三个辅助变量，S(n) = O(1)，满足原地约束。
- **阅卷要点**：①内层循环必须带 `i < j` 防越界；②需特判全奇/全偶表（代码中两内层循环自动终止，天然安全）；③若采用“辅助数组先分再拷回”得 5 分左右（思想对但违反 O(1) 空间约束，降档处理）。
