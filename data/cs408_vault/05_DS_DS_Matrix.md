# 📚 408 考点深度剖析与变式题库：特殊矩阵压缩存储

## ⚡ 一、核心考点秒懂精髓
- **底层机制**：将 n 阶特殊矩阵的元素按行（或列）优先映射到一维数组 B[0..m-1]，核心是**建立“矩阵下标 (i,j) → 一维下标 k"的线性映射**。统考默认**下标从 1 开始**。
  - 对称矩阵（下三角存储，a₁₁ 存于 B[0]）：i≥j 时，k = i(i-1)/2 + j - 1；
  - 上三角矩阵：k = (i-1)(2n-i+2)/2 + (j-i)；
  - 三对角矩阵：k = 2i + j - 3（i≥2 区域）。
- **稀疏矩阵**：三元组表 (行, 列, 值) 失去随机存取特性；十字链表便于非零元动态增删（行、列各成循环链表，结点含 right/down 指针）。
- **口诀**：“**对称存三角，半边元素数 i(i-1)/2，再加列标减个一**”；三对角记住“**前面 i-2 行满，2(i-2)+行内 3**”。

## ⚠️ 二、考场高频杀手陷阱透析
1. **下标起点陷阱（最高频）**：408 真题给的下标可能从 0 开始或从 1 开始！必须先审题。若从 0 开始，k = i(i+1)/2 + j（i≥j）。很多考生背死 1 起始公式直接代入 0 起始题目，错选相邻选项——出题人正是设置了 ±1 干扰项。
2. **上/下三角与存储方向组合混乱**：共 4 种组合（上三角按行、上三角按列、下三角按行、下三角按列），公式完全不同。务必现场推导：**数出第 i 行/列前面排了多少个元素**，切勿硬背。对称矩阵只存一个三角形，n(n+1)/2 个元素；若题目存“含多余元素”或“上、下三角均存”需另算。
3. **稀疏矩阵的转置算法辨析**：直接按三元组表扫描做“按列找序”，时间 O(n·t)（n 为列数，t 为非零元数）；**快速转置**借助 num[col] 与 cpot[col] 两个辅助数组，O(n + t)。大题中要求“高效转置”时必须用后者，且 cpot 初值 cpot[1]=0 后要累加修正。十字链表插入结点时须同时维护行链（按列序）与列链（按行序），漏掉一头即错。

## 🎯 三、经典真题同源变式题 1（单项选择）

【题目背景】：将 n（n>1）阶**下三角矩阵 A**（即当 i<j 时 aᵢⱼ=0，其余元素不全为 0）按**列优先**顺序压缩存入一维数组 B[0..n(n+1)/2 - 1]，其中 a₁₁ 存入 B[0]。若 A 中元素 aᵢⱼ（i≥j）存放在 B[k]，则 k =（ ）

A. i(i-1)/2 + j(j-1)/2  B. j(j-1)/2 + i - 1  C. i(i-1)/2 + j - 1  D. j(j-1)/2 + i

【正确答案】：**B**

【深度解析】：
- **正向推导**：列优先存储下三角，存第 j 列之前，前面已存完前 j-1 列。第 c 列（c≤j-1）有 c 个元素，故前 j-1 列共 1+2+…+(j-1) = j(j-1)/2 个元素。在第 j 列内，aᵢⱼ 上方有 a₁ⱼ…a_{i-1,j} 共 i-1 个元素（0 起始数组再减 1）。故 k = j(j-1)/2 + (i-1)。
- **验证**：a₁₁ → k = 0 + 0 = 0 ✔；a₂₁ → k = 0 + 1 = 1 ✔；a₂₂ → k = 1 + 1 = 2 ✔。
- **排除**：A 项把“按行数前面元素”和“按列数”混淆，量纲错乱；C 项是**行优先**存下三角的公式（真题原式），正是为背公式不看“列优先”条件的考生准备的陷阱；D 项是 0 起始下标与 1 起始公式混用的典型 ±1 错误（漏了 "-1"）。

## 🚀 四、经典真题同源变式题 2（综合应用/大题）

【综合大题】：设稀疏矩阵 A 为 m×n（m, n ≤ 100），非零元个数 t，以**行优先**顺序存储于三元组顺序表 data[0..t-1]（行、列下标均从 1 开始）。要求设计**快速转置**算法：输出 A 的转置矩阵的三元组表 B.data，仍按行优先（即按 A 的列号）有序，**时间复杂度须为 O(n + t)**，不得直接对三元组表排序。
（1）说明算法核心思想；（2）写出 C 代码；（3）分析时间与空间复杂度。

【解题思路】：
1. 直接转置需对每一列扫描全表，O(n·t)，不满足要求。
2. **统计**：扫描 A.data 一遍，num[col] 统计 A 中第 col 列非零元个数（即转置后第 col 行的元素个数）。
3. **定位**：cpot[col] 为 A 第 col 列第一个非零元在 B.data 中的位置：cpot[1]=0；cpot[col] = cpot[col-1] + num[col-1]。
4. **搬移**：按 A.data 原顺序（列号递增隐含其中）扫描，将每个元素 (i,j,v) 放入 B.data[cpot[j]]，并 cpot[j]++。因 A.data 按行优先有序，同列元素按行号递增出现，放入 B 后同列（即转置后同行）元素行号自然递增，故 B 恰为行优先有序。

【参考代码/步骤】：

```c
#define MAXSIZE 12500
typedef struct { int i, j; int e; } Triple;
typedef struct {
    Triple data[MAXSIZE + 1];  // data[1..t]，1 起始
    int mu, nu, tu;            // 行数、列数、非零元数
} TSMatrix;

void FastTranspose(TSMatrix *A, TSMatrix *B) {
    int num[105] = {0}, cpot[105];
    B->mu = A->nu; B->nu = A->mu; B->tu = A->tu;
    if (B->tu == 0) return;
    for (int p = 1; p <= A->tu; ++p)      // 第一步：统计各列非零元数
        ++num[A->data[p].j];
    cpot[1] = 1;                           // 第二步：求各列首位置（1 起始）
    for (int col = 2; col <= A->nu; ++col)
        cpot[col] = cpot[col-1] + num[col-1];
    for (int p = 1; p <= A->tu; ++p) {     // 第三步：一次扫描完成搬移
        int col = A->data[p].j, q = cpot[col];
        B->data[q].i = col;
        B->data[q].j = A->data[p].i;
        B->data[q].e = A->data[p].e;
        ++cpot[col];
    }
}
```

【时空复杂度分析】：
- **时间**：三个并列循环分别执行 t 次、n-1 次、t 次，故 T(n,t) = O(n + t)，满足题目要求（普通转置为 O(n·t)，t 接近 mn 时退化）。
- **空间**：辅助数组 num、cpot 共 O(n)（列数规模），转置结果表 B 本身为输出不计入额外空间；总额外空间 O(n)。
- **正确性关键点**（阅卷得分点）：① cpot 递推式正确；② 搬移时保持同列元素行号有序，从而 B 行优先有序；③ 边界 t=0 时提前返回避免 cpot 未初始化访问。
