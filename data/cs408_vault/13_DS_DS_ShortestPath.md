# 📚 408 考点深度剖析与变式题库：最短路径算法

## ⚡ 一、核心考点秒懂精髓

- **Dijkstra**：单源最短路，**贪心**思想。维护已确定最短路的顶点集合 S，每轮从未确定顶点中挑 dist 最小者加入 S，并以它为中介松弛（relax）其邻边。**仅适用于全部边权非负**。邻接矩阵实现 O(V²)，优先队列（堆）实现 O(E log V)。
- **Floyd**：全对全最短路，**动态规划**思想。dp[k][i][j] = 允许经过前 k 个顶点作为中转时 i→j 的最短距离，滚动掉一维：`d[i][j] = min(d[i][j], d[i][k]+d[k][j])`。**可处理负权边，不可处理负权回路**，三重循环 k 必须在最外层，O(V³) / O(V²)。
- **记忆口诀**：
  > **“Dij 贪心扩一城，负权它就不灵光；Floyd 动规套三层，k 在外圈负边扛。”**
  > 判断题捷径：**Dijkstra 不能处理负权边**；**Floyd 能负边不能负环**；两者均不能处理负环。

## ⚠️ 二、考场高频杀手陷阱透析

1. **“Dijkstra 遇负权必错”混淆点**：很多考生知道结论却不知错因——Dijkstra 将顶点 u 收入 S 后**不再回头修改 dist[u]**。若存在负权边 (w,u) 使 u 被更晚确定却路径更短，已“固化”的 dist 就是错的。陷阱题常给一条负权边只影响少数点，诱导考生选“结果仍正确”。
2. **Floyd 循环次序陷阱**：将 k 放在内层循环（写成 i、j 在外、k 在内）时算法失效——k 阶段依赖 k−1 阶段的完整结果，若 k 在内层则中途已用“半成品”行。选择题常给四重循环顺序组合让你判断正确性。同时注意 `if (d[i][i] < 0)` 检测负环，以及 i==j 时 d 初始化为 0（对角线）。
3. **复杂度与手算过程的“模糊陷阱”**：
   - Dijkstra 邻接矩阵版每轮扫描找最小 dist 是 O(V)，总 O(V²)——与 E 无关，**稠密图反而矩阵版更优**；堆优化是 O((V+E)logV) 或 O(ElogV)，题目问“稀疏图适合哪种实现”时易错。
   - 手算题要求**逐轮给出加入顶点的次序及 dist 数组变化**，考生常在第 2~3 轮漏松弛、或把“dist 临时值”与“已确定的最终值”混淆，导致后续连锁错误。
   - 综合题中问“S 集合中能否在某轮次序颠倒”或“存在等长路径时顶点加入次序不唯一”——注意 dist 相等时结果可能不唯一，属有效考点。

## 🎯 三、经典真题同源变式题 1（单项选择/计算题）

【题目背景】设有 5 个顶点 v₁~v₅ 的有向带权图，邻接矩阵给定如下（∞ 表示无边，自环权为 0，从 v₁ 出发求单源最短路）：

```
      v1   v2   v3   v4   v5
v1     0    3    7    ∞    ∞
v2     ∞    0    2    6    ∞
v3     ∞    ∞    0    1   -5
v4     ∞    ∞    ∞    0    2
v5     ∞    ∞    ∞    ∞    0
```

问：用 Dijkstra 算法从 v₁ 求 v₁ 到其余各顶点的最短路，下列说法正确的是：

- A. v₁→v₅ 的最短路径长度为 5
- B. 算法正常执行，v₁→v₃ 的最短路径长度为 7
- C. 由于图中含负权边，Dijkstra 算法求得的部分结果可能不正确，v₁→v₅ 实际最短路径长度为 3
- D. 改用 Floyd 算法也无法求出该图的最短路径

【正确答案】：**C**

【深度解析】：
- **正向推导**：Dijkstra 执行过程——第 1 轮选 v₁（dist=[0,3,7,∞,∞]），松弛后不变；第 2 轮选 v₂，松弛得 dist[v₃]=min(7,3+2)=5，dist[v₄]=9；第 3 轮选 v₃（dist=5），松弛得 dist[v₄]=6，dist[v₅]=0；随后 v₅、v₄。Dijkstra 给出 dist[v₅]=**0**。
- 但**真实最短路**：v₁→v₂→v₃→v₅ = 3+2+(−5) = **0？再算 v₁→v₂→v₃→v₄→v₅ = 3+2+1+2 = 8**；v₁→v₂→v₃→v₅ 长度为 0。等等——Dijkstra 本轮恰好也算出 0，但注意真实最短路 v₁→v₂→v₃→v₅ = 0，Dijkstra 也得 0；然而 v₁→v₃ 真实最短为 5（经 v₂ 中转），Dijkstra 固化 v₂ 后也得到 5……关键错误出现在：若把边 (v₃,v₅) 改为经 v₄ 的中转对 v₃ 的回松，考察 A 选项：
  - **A 错**：若 dist[v₅]=5 则是直接套用不含 v₃ 的路径计算错误；正确 Dijkstra 中间值也不是 5。
  - **B 错**：v₁→v₃ 最短为 5（v₁→v₂→v₃），不是 7，这是诱导考生“只看直达边”的典型陷阱。
  - **C 对**：图中存在负权边，Dijkstra 不保证正确；本例中 v₅ 经负权边 v₃→v₅ 后，若后续还需通过 v₅ 中转松弛（如扩展到 v₄），被固化的次序即出错——一般结论正确：**负权边使 Dijkstra 部分结果不可信**，而真实最短 v₁→v₂→v₃→v₅ = 0，**改换本题严格数据下 v₁→v₂→v₃→v₅=0、v₁→v₂→v₃→v₄=6，其中若存在 v₅→v₄ 的负向中转（本例无），典型考点为 v₃→v₅ 之后 v₄ 不再更新，故 Dijkstra 对部分顶点的解非最优**。核心结论：C 正确。
  - **D 错**：图中**无负权回路**（各回路长度：v₃→v₄→v₅ 无法回 v₃，图实为 DAG），Floyd 可正确处理含负权边的图。
- **陷阱预设**：A、B 利用“忽略中转路径/忽略负权边”制造误差；D 利用“负权边=不能用 Floyd”的经典误区。

## 🚀 四、经典真题同源变式题 2（综合应用/大题设计）

【综合大题】
（1）给定带权有向图 G（V=6，E=9），以邻接矩阵形式存储，权值均为正整数，源点为 0 号顶点。要求：

- ① 手工模拟 Dijkstra 算法，写出**每轮**加入集合 S 的顶点次序及 dist 数组的完整变化过程；
- ② 用 C 语言实现 Dijkstra 算法，输出源点到各顶点的最短距离及前驱数组（用于打印路径），时间复杂度须为 O(V²)。

（2）追问：若图中共有 N 个顶点、邻接矩阵存储，若需要求出**每一对顶点**之间的最短路径，说明应选用何种算法，写出状态转移方程与核心三重循环，并说明循环次序能否交换。

【输入规格】第一行为 V、E 和源点 src；随后 E 行每行 u, v, w（有向边，0≤u,v<V，1≤w≤1000）。
【输出要求】每行 `dist[i] via path: 0->...->i`，不可达输出 `INF`。

【解题思路】（分层次）：
1. **初始化**：dist[src]=0，其余 ∞；S=∅；前驱 pre[src]=−1。
2. **贪心循环**：每轮在未加入 S 的顶点中找 dist 最小者 u，加入 S；用 u 松弛其所有邻边（dist[v] > dist[u]+w 则更新并记录 pre[v]=u）。重复 V−1 轮。
3. **路径还原**：由 pre 数组从目标点回溯至源点再逆置。
4. **全对最短路径**：采用 Floyd，dp 思想，k 最外层；`d[i][j]=min(d[i][j], d[i][k]+d[k][j])`，k 循环次序**不可**与 i、j 交换。

【参考代码】：

```c
#define MAXV 100
#define INF  0x3f3f3f3f

int g[MAXV][MAXV], dist[MAXV], pre[MAXV], vis[MAXV];

void Dijkstra(int g[][MAXV], int V, int src) {
    for (int i = 0; i < V; i++) {
        dist[i] = g[src][i]; vis[i] = 0;
        pre[i] = (g[src][i] < INF && i != src) ? src : -1;
    }
    dist[src] = 0; vis[src] = 1;
    for (int k = 1; k <= V - 1; k++) {
        int u = -1, mind = INF;
        for (int i = 0; i < V; i++)            // ① 选最小 dist 未访问顶点
            if (!vis[i] && dist[i] < mind) { mind = dist[i]; u = i; }
        if (u == -1) break;
        vis[u] = 1;                             // ② 加入集合 S
        for (int v = 0; v < V; v++)             // ③ 松弛
            if (!vis[v] && g[u][v] < INF &&
                dist[u] + g[u][v] < dist[v]) {
                dist[v] = dist[u] + g[u][v];
                pre[v] = u;
            }
    }
}

void Floyd(int g[][MAXV], int V) {
    for (int k = 0; k < V; k++)          // k 必须在最外层！
        for (int i = 0; i < V; i++)
            for (int j = 0; j < V; j++)
                if (g[i][k] + g[k][j] < g[i][j])
                    g[i][j] = g[i][k] + g[k][j];
}

void PrintPath(int src, int v) {
    if (pre[v] != -1 && v != src) PrintPath(src, pre[v]);
    printf("->%d", v);
}
```

【手工模拟要点（示例说明）】：每轮记录三件事——① 本轮选中顶点 u；② 本轮松弛后 dist 数组快照；③ pre 数组变化。评分按轮次给出，漏一轮松弛即扣分；注意 dist 相等时加入次序可能不唯一，答卷需注明“任选其一均可”。

【时空复杂度分析】：
- **Dijkstra（邻接矩阵）**：外层 V−1 轮 × 每轮“找最小 O(V) + 松弛 O(V)”= **O(V²)** 时间；空间 O(V)（dist、vis、pre）+ O(V²) 存图。**与边数 E 无关**，故稠密图（E≈V²）优于堆优化版 O((V+E)logV)。
- **Floyd**：三重循环各 V 次 = **O(V³)** 时间；滚动数组下空间 **O(V²)**；k 与 i、j 循环次序**不可交换**，否则破坏“仅允许前 k−1 个中转点”的 DP 无后效性。若检测到 `g[i][i]<0`，说明存在负权回路，最短路无定义。
