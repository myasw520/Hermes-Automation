# 📚 408 考点深度剖析与变式题库：树与二叉树

## ⚡ 一、核心考点秒懂精髓

**底层机制**：
- 度数守恒：二叉树中每条边贡献 1 个“孩子度”，总度数 = n − 1 = n₁ + 2n₂，而 n = n₀ + n₁ + n₂，两式相减即得 **n₀ = n₂ + 1**（与 n₁ 无关）。
- 完全二叉树编号规则（1 起编号）：节点 i 的左孩子 = 2i，右孩子 = 2i+1，双亲 = ⌊i/2⌋；**编号 ≤ ⌊n/2⌋ 的节点为分支节点，编号 > ⌊n/2⌋ 的必为叶子**。
- 树/森林 → 二叉树（左孩子右兄弟）：树 T 的根无兄弟故转化后**根的右子树必空**；森林中各棵树依次作为“兄弟”链接，转化后二叉树根的右链上依次挂着其余树的根。

**记忆口诀**：
> “叶子等于零度加一差，n₀ = n₂ + 1 永不差；孩子双亲乘二除二，一半取整分叶枝。”

## ⚠️ 二、考场高频杀手陷阱透析

**陷阱 1：n₀ = n₂ + 1 滥用于非二叉树或带条件的树**
考生常把该公式套到“m 叉树”或“树的结点”上。注意：对 m 叉树应使用 n₀ = n₂ + 2n₃ + ... + (m−1)nₘ（通式：n₀ = 1 + Σ(i−1)·nᵢ）；对普通树（孩子数≥1）不存在此公式。另外公式对“空树/仅一个结点”也成立（n₀=1, n₂=0），但**对森林不直接成立**。

**陷阱 2：完全二叉树标号推导时“1 起编号 vs 0 起编号”混淆**
- 1 起编号：孩子 2i、2i+1；0 起编号：孩子 2i+1、2i+2。
- 求叶子数：n₀ = ⌈n/2⌉（1 起）；最后一个分支节点编号 = ⌊n/2⌋。
- 判断编号 i 与 j 是否同双亲、求某编号子树大小（子树范围 [i, ...] 需用区间二倍扩张法）时极易算错边界，尤其是“编号为 i 的结点为根的子树含有多少结点”这类题。

**陷阱 3：森林转二叉树后的结构误判**
- 误以为“树 T 有 k 棵子树，转换后根的右子树深度为 k−1”——实际根的**右链长度 = 原树中根的孩子数 − 1**（右链挂的是兄弟），原树的孩子变成左子树链。
- 森林 F = (T₁, T₂, ..., Tₘ) 转二叉树后，根的右子树是 T₂...Tₘ 转化的结果——逆向还原时先拆右链得各树，再对每棵树“左链还原为孩子”。
- 中序遍历：树的后根遍历序列 = 对应二叉树的**中序**序列；树的先根遍历 = 对应二叉树的**先序**序列。三者配对关系是选择题高频坑。

## 🎯 三、经典真题同源变式题 1（单项选择）

【题目背景】改编自“已知完全二叉树结点数求叶结点/编号”类真题。

**题目**：一棵完全二叉树共有 767 个结点，则下列说法**错误**的是（ ）（1 起编号）

A. 该树共有 384 个叶结点
B. 编号为 383 的结点必有两个孩子
C. 编号为 384 的结点必为叶结点且是其双亲的左孩子
D. 该树的高度为 9（根在第 1 层）

【正确答案】：**D**

【深度解析】：
- 高度：⌈log₂(767+1)⌉ = ⌈log₂768⌉ = **10**，D 错误（⌊log₂767⌋+1 = 9+1 = 10，陷阱：只算 ⌊log₂n⌋ 忘 +1）。选 D。
- 叶结点数：n₀ = ⌈767/2⌉ = 384，A 正确。验证：n₀=384, n₁=0（767 为奇数时完全二叉树无 1 度结点）, n₂=383，384 = 383+1 ✓。
- 最后一个分支结点编号 = ⌊767/2⌋ = 383；n 为奇数时该结点必有两个孩子 766 和 767，B 正确。
- 384 > 383，故为叶结点；其双亲为 ⌊384/2⌋ = 192，384 = 2×192 为偶数编号，是左孩子，C 正确。
- **干扰项设计**：B 考“奇数 n 无 n₁”冷知识；C 考奇偶编号判左右孩子；D 考高度公式边界（若 n=768 则高度同为 10，但部分考生会误算为 9）。

## 🚀 四、经典真题同源变式题 2（综合应用）

【综合大题】：
设二叉树采用二叉链表存储，结点定义为：

```c
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

（1）证明：对任意非空二叉树，若叶子结点数为 n₀，度为 2 的结点数为 n₂，则 n₀ = n₂ + 1。

（2）设计算法求二叉树中度为 1 的结点个数，要求：只允许一次遍历，时间复杂度 O(n)，辅助空间不超过 O(h)（h 为树高）。

（3）该二叉树是由某棵树 T 经“左孩子右兄弟”规则转换而来，且根的右子树为空。说明如何由该二叉树统计出原树 T 中每个结点的孩子数（说明方法即可，不需写完整代码）。

【解题思路】：

**（1）证明**：二叉树中除根外每个结点有且仅有一个双亲，故总边数 = n − 1（n 为总结点数）。边又由分支结点发出：度 1 结点发 1 条边，度 2 结点发 2 条边（叶子发 0 条）。故：
n − 1 = n₁ + 2n₂，即 n₀ + n₁ + n₂ − 1 = n₁ + 2n₂，化简得 n₀ = n₂ + 1。∎

**（2）**：递归后序遍历，返回时判断 `(lchild==NULL) != (rchild==NULL)` 即度为 1；递归天然满足一次遍历、空间为递归栈 O(h)。

**（3）**：在原二叉树上，结点 x 的**左链长度**（沿 lchild 连续走至 NULL 经过的结点数）即 x 在原树 T 中的孩子数。因为“左孩子右兄弟”转换中，原树的孩子们被串成 x 左子树根开始的右单链。遍历每个结点统计其左链长度即可；由于树根右子树为空，该二叉树确实对应一棵树而非森林。

【参考代码/步骤】：

```c
int countDegree1(BiTree T) {
    if (T == NULL) return 0;
    int left  = countDegree1(T->lchild);
    int right = countDegree1(T->rchild);
    int self  = ((T->lchild == NULL) != (T->rchild == NULL)) ? 1 : 0;
    return left + right + self;
}

// (3) 统计原树 T 中每个结点的孩子数：对二叉树每个结点 x，
// 沿 x->lchild 向右链计数：
int countChildren(BiTree x) {          // 返回原树中 x 的孩子数
    int c = 0;
    for (BiTree p = x->lchild; p; p = p->rchild) c++;
    return c;                          // 对每个结点调用一次即可
}
```

【时空复杂度分析】：
- （2）每个结点访问恰好一次，时间 O(n)；递归栈深度为树高，最坏（单支树）O(n)，平衡时 O(log n)，满足 ≤ O(h) 的约束。
- （3）若对每个结点调用一次 countChildren，最坏情况（整棵树为左单链）总代价 O(n²)；可优化为一次遍历中顺带完成：全局遍历时遇到“左链起点”才计长，总时间 O(n)。空间均为 O(h) 栈空间。
