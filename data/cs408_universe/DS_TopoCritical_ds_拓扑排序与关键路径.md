# 📘 408 核心考点真题宇宙: [ds] 拓扑排序与关键路径

> 大纲描述: AOV网拓扑排序（检测有向环）；AOE网关键路径：事件最早发生时间ve、最迟发生时间vl、活动最早开始时间e、最迟开始时间l、时间余量=0为关键活动。

## 🎯 高陷阱单选专项演练

### 第 1 题 (难度: ⭐⭐⭐)
**题干**：对一个有向图进行拓扑排序，使用栈而非队列保存入度为0的顶点。下列说法正确的是：

- A. 使用栈会导致某些图无法完成拓扑排序，因为后入的顶点先输出可能破坏依赖关系
- B. 使用栈与使用队列得到的拓扑序列一定相同
- C. 使用栈与使用队列都可能得到正确的拓扑序列，但具体序列可能不同；只要图无环，两者都能成功输出全部顶点
- D. 只有入度恰为0且出度大于0的顶点才能入栈，孤立顶点必须单独处理

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `C`

**【各选项排雷剖析】**:
选项A陷阱：混淆了拓扑序的『不唯一性』与『正确性』，任何满足依赖关系的输出顺序都合法，数据结构的选择只影响输出哪一个合法序列，绝不影响能否排序成功；选项B陷阱：忽略了同一图存在多个拓扑序这一核心事实，栈的LIFO与队列的FIFO取顶点顺序不同，删边后新产生的零入度顶点加入顺序也不同，序列一般不同；选项D陷阱：出度为0的顶点（如汇点）显然也必须输出，人为附加『出度大于0』条件属于编造约束，孤立顶点入度为0自然入栈，无需特殊处理。

**【深度解析】**:
拓扑排序的算法骨架是：统计入度→零入度顶点进容器→取出一顶点输出并使其邻接点入度减1→新零入度者进容器。容器用栈或队列只改变取出顺序，不改变算法正确性。反证：若图无环，算法每次删除一顶点及其出边，图中零入度顶点始终存在（否则存在环），故必能输出全部n个顶点；若输出顶点数小于n则必有环。破局思维：抓住『输出顶点个数是否等于n』这一环检测本质，与容器类型彻底解耦。典型陷阱：n个顶点、不同存储（邻接矩阵vs邻接表）的顶点编号顺序，都会导致拓扑序不唯一，这是408高频送分点也是送命点。

</details>

### 第 2 题 (难度: ⭐⭐⭐⭐)
**题干**：关于AOE网与关键路径，下列叙述错误的是：

- A. 若AOE网中存在多条关键路径，仅缩短其中一条关键路径上的关键活动工期，整个工程工期可能不变
- B. 关键活动的l-i（时间余量）为0，缩短任一关键活动的工期必然使整个工期缩短
- C. 一个事件ve等于其所有前驱事件ve加上相应活动持续时间的最大值
- D. 缩短不在任何关键路径上的活动工期，工程总工期一定不变

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱分析（该说法正确）：多条关键路径并存时，各条路径长度相同，只压缩一条路径，另一条仍卡住总工期，故工期可能不变——本题为选错误项，A不能选；选项B即错误项：当关键路径不唯一时，缩短一条关键路径上的活动，总工期由另一条等长关键路径决定，不缩短；选项C陷阱分析（正确）：事件最早发生时间取决于最长前驱路径，必须取max，错选C者往往误以为取min或忽略多条入边；选项D陷阱分析（正确）：非关键活动本身有时间余量，压缩它只增大余量，不影响关键路径长度。

**【深度解析】**:
本题是经典反直觉陷阱：教材中『关键活动』的定义是时间余量为0的活动，但『缩短关键活动⇒缩短工期』这一推论仅在关键路径唯一时成立。当存在两条及以上等长关键路径时，必须同时在所有关键路径上各缩短至少一个活动才能提前完工。破局思维：见『关键路径』先问自己——有几条？多条则任何单点优化都可能失效。408真题（如2012年、2021年）反复围绕『缩短关键活动是否必缩工期』设置陷阱。另外注意ve求值用max（源头到该点最长路径），vl求值用min（该点到汇点各后继vl减活动时长的最小值），方向相反极易记混。

</details>

### 第 3 题 (难度: ⭐⭐⭐)
**题干**：对AOE网中任一活动a<k，w>（k为弧尾事件，w为弧头事件），其最早开始时间e与最迟开始时间l计算正确的是：

- A. e = ve(k)，l = vl(w) - a<k，w>的持续时间
- B. e = ve(w) - 持续时间，l = vl(k)
- C. e = ve(k)，l = vl(w) + 持续时间
- D. e = ve(w)，l = vl(k) - 持续时间

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `A`

**【各选项排雷剖析】**:
选项B陷阱：把活动依附的两个事件的地位完全颠倒——活动只有在弧尾事件k发生后才能开始，故e锚定ve(k)；l由弧头事件w的最迟时间倒推，且要减去而非直接取事件时间；选项C陷阱：l的方向搞反，vl(w)是最晚时刻，活动必须在此之前『开始』，故应减去活动耗时；若加耗时则活动结束时间超过w的最迟允许时间，逻辑荒谬；选项D陷阱：双重颠倒，是命题人针对公式记忆模糊者设计的『对称混淆项』，与B互为镜像错误。

**【深度解析】**:
四量两阶段：第一阶段正推求ve——源点ve=0，ve(w)=max{ve(k)+dur(k,w)}，必须沿拓扑序进行；第二阶段逆推求vl——汇点vl=ve(汇点)=工程总工期，vl(k)=min{vl(w)-dur(k,w)}，必须沿逆拓扑序进行。活动层面：e(a)=ve(弧尾)，l(a)=vl(弧头)-dur(a)，余量l-e=0者为关键活动。破局思维：用『先有起点才能开工，必须赶在终点最迟时刻前完工』的物理直觉校验公式，而非死背。真题中常给出AOE网让考生算某活动的l值，90%的错误来自把vl(w)与ve(w)混用。

</details>

### 第 4 题 (难度: ⭐⭐⭐⭐)
**题干**：某AOE网有9个事件、11个活动（经典教材网），源点v1到汇点v9的关键路径长为18。若活动a6（不属于任何关键路径，时间余量为4）工期由3缩短为1，则工程总工期与关键路径的变化是：

- A. 总工期缩短为16，a6变为关键活动
- B. 总工期不变仍为18，a6的时间余量增大为6，关键路径集合不变
- C. 总工期不变仍为18，但a6的时间余量减小为2
- D. 总工期缩短为16，关键活动集合减少一个元素

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：非关键活动有余量4，缩短2仍在余量内，根本碰不到关键路径，绝不会影响总工期，也不会产生新关键活动；选项C陷阱：方向反了——缩短活动耗时使e不变而l变大（或e变小），余量只会增大不会减小，这是『余量=最迟-最早』方向感缺失的典型表现；选项D陷阱：双重错误叠加，既误判工期缩短，又误以为缩短活动能从关键集合中『删元素』——关键活动集合由余量为0的活动构成，非关键活动的变动与其无关。

**【深度解析】**:
非关键活动的压缩效果：其e(a)=ve(弧尾)不变（源点侧最长路径未变），l(a)=vl(弧头)-dur增大（dur减小），故余量l-e增大。总工期由关键路径长度决定，非关键活动压缩不影响。破局思维：任何关于压缩工期的问题，第一步先判断该活动是否关键、关键路径是否唯一。本题若改为压缩某关键活动且关键路径唯一，总工期才缩短。408曾考过『缩短某关键活动工期后工程提前几天』，标准答案往往是『0天』，因为存在另一条并行等长路径。

</details>

### 第 5 题 (难度: ⭐⭐⭐⭐)
**题干**：用邻接表存储的有向图G做拓扑排序，排序过程中某个顶点出栈后其所有邻接点入度减1均未产生新的零入度顶点，随后栈变为空但已输出顶点数m<n。对该现象的正确解释是：

- A. 算法实现有误，正确实现下栈不可能提前为空
- B. 说明图中存在有向环，环上顶点入度始终无法减为0，剩余n-m个顶点构成的子图含环，据此可判定G不是AOV网
- C. 说明图中存在自环（顶点到自身的弧），删除自环后即可继续排序
- D. 说明剩余顶点入度均大于0但图不一定有环，只需改用DFS遍历即可得到拓扑序列

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：栈空且m<n恰是环检测的标准输出特征，是算法的正常判定结果而非bug，误选者不理解算法的环检测语义；选项C陷阱：自环确实会导致该点入度永不为0，但『存在环』的一般结论不能特化为『自环』——三点环、长环同样导致此现象，题干信息不足以断定是自环；选项D陷阱：混淆了无向图DFS与有向图拓扑的适用性——有向图即使无环，普通DFS遍历顺序也不是拓扑序（需要按完成时间逆序排序才可行），且当存在环时DFS同样无法给出合法拓扑序，『改用DFS即可』是伪解法。

**【深度解析】**:
 Kahn算法的环检测判据：最终输出顶点数小于n ⟺ 图中存在有向环。机理：环上任一顶点的入边全部来自环内顶点，环内顶点在环被打破前不可能有零入度者，而算法永不输出零入度以外顶点，故环整体被『冻结』。破局思维：把拓扑排序同时视为『AOV网可行性检验器』——工程问题中拓扑排序失败的直接含义就是课程先修关系（或任务依赖）出现循环定义，需人工介入调整。这也是408选择题的经典结论：有向无环图（DAG）⟺ 能完成拓扑排序。

</details>

## 🏆 综合应用与算法设计大题

### 大题 1: AOE网关键路径求解与工期压缩分析 (15 分)

**【背景与题干】**:
某软件项目被建模为AOE网，包含7个事件v1~v7（v1为源点，v7为汇点）及10个活动，活动及持续时间（天）如下：a1(v1,v2)=3，a2(v1,v3)=2，a3(v2,v4)=4，a4(v3,v4)=3，a5(v3,v5)=4，a6(v4,v6)=5，a7(v5,v6)=3，a8(v4,v5)=1，a9(v5,v7)=4，a10(v6,v7)=2。请完成各小问。

**【问题清单】**:
- (1) 计算各事件的最早发生时间ve与最迟发生时间vl，写出完整推导过程（ve按拓扑序正推，vl按逆拓扑序逆推），并给出工程总工期。
- (2) 计算各活动的最早开始时间e、最迟开始时间l与时间余量l-e，指出全部关键活动并写出关键路径。
- (3) 若仅将活动a2的工期由2天压缩为1天，能否使工程提前完工？若将a5由4天压缩为2天且同时将a6由5天压缩为3天呢？分别说明理由。
- (4) 编写C/C++函数int criticalPath(const Graph &g)，基于邻接表实现：先拓扑排序求ve，若检测到环返回-1，否则逆推vl并输出所有关键活动。要求给出完整可编译代码。

<details><summary><b>👉 查看踩分标准与标准参考实现</b></summary>

**【考研阅卷踩分细则】**:
总15分。(1)共5分：正确给出全部7个ve值得2分（每个0.5分上下浮动，错一个扣0.5，最多扣2）；正确给出全部vl值得2分（vl必须先确定汇点vl7=ve7=13，直接正推vl不给分）；总工期13得1分。(2)共5分：10个活动的e、l各0.25分共5分，或按关键活动判定为主——正确判定5个关键活动a1,a3,a6,a8,a9各得0.6分，关键路径v1→v2→v4→v5→v7与v1→v2→v4→v6→v7写出任意一条得1分，两条全写对得2分（用于补偿e/l逐项给分的不足，取两种给分方式较高者）。(3)共2分：a2压缩后总工期仍为13（a2非关键，余量1）得1分；a5、a6同时压缩后：两条原关键路径分别缩短为11与11，需检查是否出现新关键路径（a1,a2,a4,a6,a10路径长3+2+3+3+2=13？压缩a6后为11；路径v1→v2→v4→v5→v7为3+4+1+2+4=14？注意a3=4,a8=1：ve重算后总工期=11），答出总工期缩短为11且需说明所有关键路径均被覆盖才得1分，仅答『能缩短』不给分。(4)共3分：拓扑排序环检测返回-1得1分；ve正推用max、vl逆推用min各0.5分；正确输出余量为0的活动得1分；代码有明显语法或逻辑错误酌情扣0.5~1分。

**【核心算法/推导实现】**:
```cpp
// 完整推导：
// ve: ve1=0; ve2=ve1+3=3; ve3=ve1+2=2;
// ve4=max(ve2+4, ve3+3)=max(7,5)=7;
// ve5=max(ve3+4, ve4+1)=max(6,8)=8;
// ve6=max(ve4+5, ve5+3)=max(12,11)=12;
// ve7=max(ve5+4, ve6+2)=max(12,14)=14 —— 更正：ve7=14，总工期14天。
// vl: vl7=14; vl6=vl7-2=12; vl5=min(vl7-4, vl6-3)=min(10,9)=9;
// vl4=min(vl6-5, vl5-1)=min(7,8)=7; vl3=min(vl4-3, vl5-4)=min(4,5)=4;
// vl2=vl4-4=3; vl1=min(vl2-3, vl3-2)=min(0,2)=0。
// 活动(e=ve尾, l=vl头-dur): a1:e=0,l=0,余0(关键) a2:e=0,l=2,余2
// a3:e=3,l=3,余0(关键) a4:e=2,l=4,余2 a5:e=2,l=5,余3 a6:e=7,l=7,余0(关键)
// a7:e=8,l=9,余1 a8:e=7,l=8,余1 a9:e=8,l=10,余2 a10:e=12,l=12,余0(关键)
// 关键路径: v1->v2->v4->v6->v7, 长度3+4+5+2=14。

#include <stdio.h>
#include <stdlib.h>
#define MAXV 100

typedef struct ArcNode {
    int adjvex;          // 弧头顶点下标
    int dur;             // 活动持续时间
    struct ArcNode *next;
} ArcNode;

typedef struct {
    ArcNode *first[MAXV];
    int n, e;            // 顶点数、活动数
} Graph;

int criticalPath(const Graph *g) {
    int n = g->n;
    int indeg[MAXV] = {0}, ve[MAXV] = {0}, vl[MAXV], stk[MAXV], topo[MAXV];
    int top = -1, cnt = 0, i;
    ArcNode *p;
    for (i = 0; i < n; i++)
        for (p = g->first[i]; p; p = p->next) indeg[p->adjvex]++;
    for (i = 0; i < n; i++) if (indeg[i] == 0) stk[++top] = i;
    while (top != -1) {          // Kahn: 栈/队列均可
        int u = stk[top--];
        topo[cnt++] = u;
        for (p = g->first[u]; p; p = p->next)
            if (--indeg[p->adjvex] == 0) stk[++top] = p->adjvex;
    }
    if (cnt < n) return -1;      // 有环, 非AOE可行网
    for (i = 0; i < n; i++)      // 正推ve: 取max
        for (p = g->first[i]; p; p = p->next)
            if (ve[i] + p->dur > ve[p->adjvex]) ve[p->adjvex] = ve[i] + p->dur;
    int src = 0;                 // 汇点: ve最大者(或指定n-1)
    for (i = 1; i < n; i++) if (ve[i] > ve[src]) src = i;
    for (i = 0; i < n; i++) vl[i] = ve[src];   // 逆推vl: 取min
    for (i = n - 1; i >= 0; i--) {
        int u = topo[i];
        if (!g->first[u] ) vl[u] = ve[src];    // 汇点
        for (p = g->first[u]; p; p = p->next)
            if (vl[p->adjvex] - p->dur < vl[u]) vl[u] = vl[p->adjvex] - p->dur;
    }
    printf('总工期 = %d\n关键活动(余量为0):\n', ve[src]);
    for (i = 0; i < n; i++)
        for (p = g->first[i]; p; p = p->next)
            if (vl[p->adjvex] - p->dur == ve[i])
                printf('活动<%d,%d> dur=%d\n', i, p->adjvex, p->dur);
    return ve[src];
}

// (3)结论: 压缩a2(非关键,余量2)后总工期仍为14, 不能提前完工;
// 同时压缩a5与a6: 原唯一关键路径v1->v2->v4->v6->v7中a6被压缩,
// 重算: ve4=7, ve6=max(7+3,ve5+3), ve5=max(2+4,7+1)=8, ve6=max(10,11)=11,
// ve7=max(8+4,11+2)=13, 总工期由14缩短为13, 因关键路径唯一,
// 压缩其上的a6即可生效; a5的压缩对工期无直接贡献(其路径本非最长)。
```

**【命题人解题思维点拨】**:
