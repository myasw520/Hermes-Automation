### 第 1 题 (难度: ⭐⭐⭐)
**题干**：将序列 {45, 24, 53, 12, 28, 90} 依次插入初始为空的二叉搜索树（BST），随后删除关键字 24（用其中序前驱替代法），删除后的 BST 中序序列为（ ）

- A. 12, 24, 28, 45, 53, 90
- B. 12, 28, 45, 53, 90
- C. 12, 28, 45, 90, 53
- D. 28, 12, 45, 53, 90

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：误认为删除 24 时节点仍保留在树中（只是替换关键字），混淆了「删除节点」与「被替代关键字」两种删除语义；实际上删除 24 后该节点已不存在，中序序列必不含 24。选项C陷阱：手工画树时把 90 插到了 53 的左子树或旋转了树（BST 插入不需要任何旋转），序列顺序错乱；90 大于 53 应为 53 的右孩子，中序必在 53 之后。选项D陷阱：把删除 24 后顶替上来的 28 的位置理解为根，或将中序误当成层序输出；中序序列必须严格递增，D 不递增可直接排除。

**【深度解析】**:
插入后树形：45 为根，左子 24（左孩子12，右孩子28），右子 53（右孩子90）。删除 24：其左右子树均存在，用中序前驱 12 替代关键字后删除原 12 节点（12 为叶子，直接删除）。故树中关键字为 {12,28,45,53,90}，中序遍历恒为递增序列：12, 28, 45, 53, 90。破局思维：BST 的中序序列就是元素排序结果，只需确定删除后剩下哪些元素即可，无需精确画树——这是快速排除法的关键。

### 第 2 题 (难度: ⭐⭐⭐⭐)
**题干**：在 AVL 树中插入一个新节点后，某个祖先节点的平衡因子由 1 变为 2（最小不平衡子树根为该节点）。下列关于调整的说法正确的是（ ）

- A. 需要对从新节点插入位置到根的所有不平衡祖先节点逐一旋转
- B. 仅需对最小不平衡子树旋转一次，旋转后整棵树恢复平衡且无需再调整其他祖先
- C. 插入导致失衡时必须先删除该新节点再重新插入
- D. 旋转后最小不平衡子树的根必为其原左孩子或右孩子

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：夸大调整范围。插入型失衡具有局部性：最小不平衡子树调整一次后，其高度恢复到插入前水平，所有祖先的平衡因子随之恢复，绝不需多次旋转——这与删除型失衡可能需向上逐级调整（O(log n) 次旋转）形成经典对照。选项C陷阱：程序性错误认知，AVL 的意义恰在于通过旋转在线性插入过程中保持平衡，回退重插既破坏算法语义也无必要。选项D陷阱：以偏概全，该结论仅对 LL/RR 型成立；LR 型（先左旋后右旋）调整后最小不平衡子树的新根是原左孩子的右孩子，RL 型同理——D 若改为「不一定」才正确。

**【深度解析】**:
插入后平衡因子绝对值首次超过 1 的最低祖先即为最小不平衡子树根。设其因子为 2，说明左子树比右子树高 2。分类：新节点插入在左孩子的左子树（LL，右旋）；插入在左孩子的右子树（LR，先对左孩子左旋再对根右旋）。关键性质：一次调整后子树高度回到插入前，向上所有祖先因子自动复原，故整树恢复平衡。破局思维：记住「插入一次旋转、删除可能多次旋转」这条对比性结论即可秒杀此类题。

</details>

### 第 3 题 (难度: ⭐⭐⭐⭐)
**题干**：一棵高度为 h（根节点高度记为 1，叶节点高度记为 1）的 AVL 树最少含有的节点数为（ ）

- A. 2^(h-1)
- B. N(h) = N(h-1) + N(h-2) + 1，其中 N(1)=1, N(2)=2
- C. 2^h - 1
- D. N(h) = 2*N(h-1) + 1，其中 N(1)=1

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：混淆「最少节点」与「最多节点」的思考方向，2^(h-1) 是满二叉树半高节点数，属于完全二叉树思维残留；AVL 最少节点数远小于此，其增长率是指数底约 1.44 的斐波那契型增长。选项C陷阱：2^h - 1 是满二叉树节点数，是 AVL 的节点数上界情形，把上界当成了下界。选项D陷阱：完全二叉树（满树）的递推，忽视了 AVL 允许一侧子树比另一侧矮 2 层（高度差为 1 意味着子树高度可相差一整层），正确递推中较矮一侧比 h-1 还要少 1 层。

**【深度解析】**:
构造节点最少的 AVL：高度为 h 的树的左右子树高度分别为 h-1 和 h-2（两者高度差恰为 1，且各自都取该高度下节点最少的形态）。故 N(h) = N(h-1) + N(h-2) + 1，N(1)=1, N(2)=2。由此得 N(3)=4, N(4)=7, N(5)=12, N(6)=20...。推论：含 n 个节点的 AVL 最大高度约为 log_φ(√5·n) ≈ 1.44·log₂n。破局思维：见到「最少节点」立即联想斐波那契递推，见到「最多高度」即用此递推反解。

</details>

### 第 4 题 (难度: ⭐⭐⭐⭐)
**题干**：在 AVL 树中删除某叶节点后引发失衡，对最小不平衡子树调整后，其双亲祖先节点可能再次失衡。下列说法正确的是（ ）

- A. 删除引发的失衡最多需要旋转 1 次
- B. 删除引发的失衡可能需要沿祖先链向上调整 O(log n) 次
- C. 删除叶节点不可能引发任何失衡
- D. 删除引发的失衡调整方式与插入完全相同，只调整一次即可

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：把插入型失衡的性质错误迁移到删除。删除使子树高度变矮，一次旋转后子树高度可能仍比删除前矮 1，导致更上方祖先因子越界，需继续向上调整——最坏 O(log n) 次。选项C陷阱：删除叶节点恰是最易引发失衡的操作：若叶节点位于其双亲的『较高』一侧，删除后双亲因子由 ±1 变为 ±2 即失衡；「叶子无关紧要」是直觉陷阱。选项D陷阱：与 A 同源且更隐蔽——旋转的分类（LL/LR/RR/RL 判定）确实相同，但调整次数与连锁效应不同，「方式相同」≠「次数相同」，命题人故意在措辞上模糊。

**【深度解析】**:
删除的关键差异：删除使子树高度可能减少，旋转后子树总高度不一定恢复原值，因此失衡会沿祖先向上传播，每次传播需再判定并旋转一次，最坏共 O(log n) 次旋转（每次 O(1)），删除总时间仍 O(log n)。破局思维：插入的旋转使子树变矮回原高度（止于一次）；删除的旋转使子树升高 1 层但删除已使它矮了 1 层（可能恰好恢复也可能继续向上传导），抓住『高度是否恢复』这一本质即可。

</details>

### 第 5 题 (难度: ⭐⭐⭐⭐⭐)
**题干**：在 AVL 树某节点 A 处发生 LR 型失衡（A 的左孩子 B 的右子树较高）。执行先对 B 左旋、再对 A 右旋的调整后，关于新子树根的平衡因子，下列说法正确的是（ ）

- A. 新根的平衡因子必为 0
- B. 新根的左右孩子分别为 B 和 A，且新根平衡因子可能为 -1、0 或 1，取决于 B 的右孩子 C 的左右子树高度
- C. 新根必为原 A 的左孩子 B
- D. 调整后 A 的左孩子必为空

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：将插入型与删除型 LR 失衡混为一谈。插入型 LR 中新节点必落在 C 的左或右一侧，调整后新根因子必为 0；但删除型 LR 中 C 的两棵子树可能等高，调整后新根因子可能为 -1（或 1），A 绝对化表述是高频失分点。选项C陷阱：把 B 当作新根，混淆了 LR 型（新根是 C，即 B 的右孩子）与 LL 型（新根才是左孩子 B）。选项D陷阱：忽略旋转中子树的『过继』规则——右旋后 A 的左孩子变为 C 的原右孩子 C_R，C_R 可为空也可能非空，『必为空』是错误断言。

**【深度解析】**:
LR 型调整后结构：C 为根，C 的左子树（原 C_L）挂为 B 的右孩子，C 的右子树（原 C_R）挂为 A 的左孩子；B、A 分别为新根的左右孩子。插入型时 C_L 与 C_R 一空一非空，旋转后 B、A 因子均为 0，新根因子为 0；删除型时 C_L、C_R 可能等高，此时 B、A 因子为 ±1，新根因子为 ∓1... 准确地说新根因子取值取决于 C_L、C_R 高度对比，可为 -1、0、1。破局思维：判型口诀『看新根』——LL/RR 新根是孩子本身，LR/RL 新根是孙子；再想『删除型旋转后新根因子未必归零』。

</details>

## 🏆 综合应用与算法设计大题

### 大题 1: AVL 树的插入、判型旋转与高度验证综合题 (15 分)

**【背景与题干】**:
将关键字序列 10, 20, 30, 40, 50, 25 依次插入一棵初始为空的 AVL 树。规定平衡因子 BF = 左子树高度 - 右子树高度，失衡即 |BF| > 1，每次调整最小不平衡子树。请完成下列各问。

**【问题清单】**:
- (1) 画出（或文字精确描述）插入 25 之后并完成平衡调整的最终 AVL 树结构，指出每次插入是否引发失衡、失衡类型及调整方法。
- (2) 写出最终树的先序遍历序列与中序遍历序列，并据此说明为什么中序序列与 BST 的中序序列性质一致。
- (3) 计算 6 个节点的 AVL 树可能达到的最大高度，并说明本题所得树的高度是否达到该最大值。
- (4) 编写完整 C/C++ 代码：实现 AVL 的插入（含 LL、RR、LR、RL 四种旋转）与中序遍历输出，对本题序列运行并给出输出结果。

<details><summary><b>👉 查看踩分标准与标准参考实现</b></summary>

**【考研阅卷踩分细则】**:
总 15 分。(1) 5 分：正确给出最终树形（根为 30，左子 20（左孩子10、右孩子25），右子 40（右孩子50））得 3 分；准确指出插入 30 时发生 LL 型失衡（最小不平衡子树根为 10... 实际根为 10 处不失衡，失衡点为 20 与 10 之间的判断错误不给分——正确为：插入 30 后最小不平衡子树根为 10，LL 型右旋得 20 为根，10、30 为孩子；插入 50 后 30 处 RR 型左旋得 40 为根；插入 25 后最小不平衡子树根为 30，LR 型先对 20 左旋再对 30 右旋）每处失衡判定与旋转各 1 分，判定错误但旋转正确的酌情给 0.5 分。(2) 3 分：先序 30, 20, 10, 25, 40, 50 得 1.5 分；中序 10, 20, 25, 30, 40, 50 得 1.5 分；说明『AVL 是 BST 的子类，中序仍严格递增』得剩余 0 分并入前两项，若只答中序未答先序扣 1.5 分。(3) 3 分：答出 N(h)=N(h-1)+N(h-2)+1 且 N(1)=1、N(2)=2 得 1.5 分；得 N(4)=7>6、N(3)=4≤6，故最大高度为 3 得 1.5 分；未给出递推只给结论扣 1.5 分。本题树高为 3，达到最大值（等价表述：6 节点 AVL 高度只能是 3）。(4) 4 分：节点结构与高度/平衡因子更新正确 1 分；四种旋转各 0.5 分共 2 分（缺一种扣 0.5 分）；插入主流程含失衡判型 1 分；主函数输出与(2)一致 0 分并入先序中序验证，若代码无法编译扣 2 分。

**【核心算法/推导实现】**:
```cpp
#include <cstdio>
#include <cstdlib>

typedef struct AVLNode {
    int key;
    int height;                 // 叶子高度为 1
    struct AVLNode *lchild, *rchild;
} AVLNode, *AVLTree;

int H(AVLNode* p) { return p ? p->height : 0; }
int max(int a, int b) { return a > b ? a : b; }
void update(AVLNode* p) { p->height = max(H(p->lchild), H(p->rchild)) + 1; }
int BF(AVLNode* p) { return H(p->lchild) - H(p->rchild); }

// 右旋（对应 LL 型）
AVLNode* rotateRight(AVLNode* A) {
    AVLNode* B = A->lchild;
    A->lchild = B->rchild;
    B->rchild = A;
    update(A); update(B);
    return B;
}

// 左旋（对应 RR 型）
AVLNode* rotateLeft(AVLNode* A) {
    AVLNode* B = A->rchild;
    A->rchild = B->lchild;
    B->lchild = A;
    update(A); update(B);
    return B;
}

AVLNode* insert(AVLNode* p, int key) {
    if (!p) {
        p = (AVLNode*)malloc(sizeof(AVLNode));
        p->key = key; p->height = 1; p->lchild = p->rchild = NULL;
        return p;
    }
    if (key < p->key) p->lchild = insert(p->lchild, key);
    else if (key > p->key) p->rchild = insert(p->rchild, key);
    else return p;              // 不插入重复关键字
    update(p);
    if (BF(p) == 2 && BF(p->lchild) == 1)        // LL
        return rotateRight(p);
    if (BF(p) == 2 && BF(p->lchild) == -1)       // LR
        { p->lchild = rotateLeft(p->lchild); return rotateRight(p); }
    if (BF(p) == -2 && BF(p->rchild) == -1)      // RR
        return rotateLeft(p);
    if (BF(p) == -2 && BF(p->rchild) == 1)       // RL
        { p->rchild = rotateRight(p->rchild); return rotateLeft(p); }
    return p;
}

void inorder(AVLNode* p) {
    if (!p) return;
    inorder(p->lchild);
    printf('%d ', p->key);
    inorder(p->rchild);
}
void preorder(AVLNode* p) {
    if (!p) return;
    printf('%d ', p->key);
    preorder(p->lchild);
    preorder(p->rchild);
}

int main() {
    int a[6] = {10, 20, 30, 40, 50, 25};
    AVLTree T = NULL;
    for (int i = 0; i < 6; i++) T = insert(T, a[i]);
    printf('pre:  '); preorder(T);  printf('\n');
    printf('in:   '); inorder(T);   printf('\n');
    return 0;
}
// 输出：pre: 30 20 10 25 40 50 / in: 10 20 25 30 40 50

推导要点：插入 10,20 无失衡；插入 30 使 10 处 BF=-2（RR 型），对 10 左旋，得根 20（孩子 10,30）；插入 50 使 30 处 BF=-2（RR 型），左旋得子树根 40（孩子 30,50）；此时树根 20，右子 40；插入 25 落在 30 左侧，使 20 处 BF=2 且 40 处 BF=-2，最小不平衡子树根为 30（BF=2）且其左孩子 20 的 BF=-1，判为 LR 型：先对 20 左旋（25 上移为 20 位置），再对 30 右旋，25 成为子树根，孩子为 20、30；最终根为 30，左孩子 20（孩子 10、25），右孩子 40（右孩子 50）。
```

**【命题人解题思维点拨】**:
本题综合考查插入过程中的动态失衡判定与四型旋转。命题陷阱有三：其一，插入 50 之后很多考生误以为 20 会失衡，实际上一次旋转后整树已平衡，体现『插入型失衡局部性』；其二，插入 25 后最小不平衡子树根是 30 而非 20，考生若从新节点沿途逐个检查节点而不理解『最低失衡祖先』概念就会判错；其三，LR 型双旋后新根是 25（孙子），若误选 20 为新根则后续先序序列全错——这正与选择题第 5 题形成呼应。第(3)问用最少节点递推 N(3)=4、N(4)=7 夹逼出 6 节点 AVL 高度只能为 3，考查从定义出发的推导能力而非死记公式。

</details>
