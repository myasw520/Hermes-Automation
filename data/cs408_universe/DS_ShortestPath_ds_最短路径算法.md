### 第 1 题 (难度: ⭐⭐⭐⭐)
**题干**：已知有向带权图 G 的边权均为正数。若对 G 运行 Dijkstra 算法时，以顶点 s 为源点，某次从优先队列中取出顶点 v 并对其邻接边进行松弛操作。下列关于该算法正确性的说法中，正确的是：

- A. 取出的 v 一旦已被标记为已确定最短路径，则其 dist 值绝不可能在后续被更新，这说明 Dijkstra 中每个顶点出队后仍可能再次入队
- B. v 出队时的 dist 值就是 s 到 v 的最短路径长度，即使图中存在边权为 0 的边该结论也必然成立
- C. 若 v 出队后通过某条边松弛了未出队的顶点 u，则 u 的 dist 值只可能减小或不变，且此后 u 一定不会再被 s 经其他路径以更短距离到达
- D. 算法结束时，某顶点 dist 值为无穷大，则说明图中存在负权边导致该点不可达

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `C`

**【各选项排雷剖析】**:
选项A陷阱：Dijkstra 出队即定型，顶点不会重复入队（区别于 SPFA），把『已确定点的 dist 不再变化』错误推导为『还会再入队』，混淆了 Dijkstra 与 Bellman-Ford 系算法的队列机制；选项B陷阱：『必然成立』过强——若允许权值为 0 的边，多数教材版本仍正确，但该选项的致命点在于把『正权』条件偷换为『非负权』后声称无条件成立，且未考虑实现中重复元素入堆的惰性删除写法会取到过期结点，此时出队值并非有效 dist；选项D陷阱：dist 为无穷只说明 s 不可达该点，与负权边毫无关系，强加因果。

**【深度解析】**:
Dijkstra 的贪心正确性依赖归纳法：每次从未确定集合中取 dist 最小者 v，因所有边权非负，任何绕经其他未确定点的路径都不可能更短，故 v 出队即定型。选项C 正是这一性质的准确表述——松弛只会让 dist 减小或不变，且 u 一旦在 v 之后被定型，其最短路已涵盖此前所有松弛信息。破局思维：抓住『出队即定型』与『贪心依赖非负权』两个核心即可秒杀。

</details>

### 第 2 题 (难度: ⭐⭐⭐⭐)
**题干**：对含有 n 个顶点、e 条边的有向带权图（权均为正），分别用邻接矩阵和二叉堆（优先队列）实现 Dijkstra 算法。下列时间复杂度分析正确的是：

- A. 邻接矩阵实现为 O(n^2)，堆实现为 O(e log n)；因此当图为稠密图（e 接近 n^2）时，堆实现一定严格快于矩阵实现
- B. 堆实现中若采用『允许重复入堆+出堆时惰性跳过已确定点』的写法，最坏时间复杂度为 O(e log e)，仍属于 O(e log n) 量级
- C. 邻接矩阵实现无论图多稀疏都是 O(n^2)，故其渐近复杂度恒优于堆实现的 O(e log n)
- D. 堆实现的 e 次松弛中每次都可能触发上滤调整，故总复杂度为 O(e·n)

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：『一定严格快于』错误——稠密时 e≈n^2，堆实现为 O(n^2 log n)，反而慢于矩阵实现的 O(n^2)，这是最常见的反直觉陷阱；选项C陷阱：方向说反了，稀疏图（e≪n^2）时 O(e log n) 远优于 O(n^2)，稠密图时矩阵实现反而占优，该选项恰好把适用场景颠倒；选项D陷阱：堆的调整是 log 级别而非线性级别，混淆了堆上滤 O(log n) 与遍历邻接表 O(n) 的代价。

**【深度解析】**:
矩阵实现：每轮扫描找最小 dist 需 O(n)，共 n 轮，O(n^2)。堆实现：每次松弛产生一个入堆 O(log n)，共 e 次松弛加 n 次出堆，O((e+n)log n)≈O(e log n)。惰性删除写法堆中最多 e 个元素，堆深 O(log e)=O(log n^2)=O(2log n)=O(log n)，故 O(e log e) 与 O(e log n) 同阶。破局思维：比较复杂度必须代入稠密/稀疏两种极端情形分别验证，切忌只背结论。

</details>

### 第 3 题 (难度: ⭐⭐⭐⭐)
**题干**：关于 Floyd 算法，下列说法正确的是：

- A. Floyd 算法中三重循环的次序可以任意交换，即外层 k 循环放到最内层结果不变
- B. Floyd 算法允许图中有负权边，也允许有负权回路，只要回路不经过所询问的源点即可
- C. Floyd 算法逐个顶点地试探中转点，k 循环必须位于最外层，其含义为『只允许经过编号不超过 k 的顶点作为中转』时的最短路矩阵
- D. Floyd 算法基于贪心策略，每轮选取当前中转收益最大的顶点优先处理可加速收敛

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `C`

**【各选项排雷剖析】**:
选项A陷阱：k 循环必须在最外层——若 k 在内层，第 i,j 的更新可能使用尚未完成第 k 轮迭代的中间结果，破坏动态规划的阶段性，结果是错误的，这是 Floyd 最经典的实现陷阱；选项B陷阱：有负权回路时最短路不存在（可无限绕回路使路径长趋于 -∞），与是否经过源点无关，Floyd 只能通过 d[i][i]<0 检测负回路，不能『绕开』；选项D陷阱：Floyd 是动态规划，转移顺序由阶段 k 唯一确定，不存在『贪心选取中转点』的加速方案，混淆了 Dijkstra 的贪心与 Floyd 的 DP。

**【深度解析】**:
Floyd 的状态定义为 d^(k)[i][j] 表示只允许以编号 1..k 的顶点为中转时 i 到 j 的最短路，转移 d^(k)[i][j]=min(d^(k-1)[i][j], d^(k-1)[i][k]+d^(k-1)[k][j])。k 作为阶段必须最外层；同层内的 i,j 更新使用的是 d^(k-1) 的值，但由于 d^(k)[i][k]=d^(k-1)[i][k]、d^(k)[k][j]=d^(k-1)[k][j]（经过 k 自己为中转不会更短，因为无负回路），所以原地滚动更新也正确——但前提正是 k 在最外层。破局思维：理解『阶段』概念即可一举排除 A、D。

</details>

### 第 4 题 (难度: ⭐⭐⭐⭐⭐)
**题干**：某有向图边权可正可负但无负权回路。以下关于最短路径算法适用性的判断，正确的是：

- A. Dijkstra 算法可能给出错误结果，且错误根源在于：已出队定型的顶点还可能被后续含负权边的路径以更短距离松弛
- B. 只要给所有边权统一加上一个足够大的正常数 C 使全部边权变正，Dijkstra 算法即可正确求出原图最短路径
- C. Floyd 算法在有负权边时结果必然全部错误，必须改用 Dijkstra 算法
- D. 对每条边权取绝对值后跑 Dijkstra，再按原符号还原即可处理负权图

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `A`

**【各选项排雷剖析】**:
选项B陷阱：平移边权改变了路径的边数结构——含 k 条边的路径增加 kC，最短路径可能因路径边数不同而改变，反例：s→a 权 1，s→b→a 权为 -5 和 7，原图 s 到 a 最短为 2（两步），平移后两步路径增量大于一步路径，结论反转；选项C陷阱：恰好说反，Floyd 允许负权边（不允许负回路），而 Dijkstra 不允许负权边，把两算法的容许条件张冠李戴；选项D陷阱：取绝对值完全改变图的拓扑度量，还原路径长度毫无意义，属于典型的伪算法干扰项。

**【深度解析】**:
Dijkstra 的贪心前提是『路径越长权值累计越大』，负权边破坏该单调性：顶点 v 出队后，可能存在经过负权边的绕行路径更短，但 v 已定型不再更新。Floyd 的 DP 转移不依赖该单调性，只要无负回路即正确。破局思维：判断算法适用性永远先问『正确性证明用到了什么前提』，平移变换陷阱可用『路径边数不同则增量不同』两步构造反例。

</details>

### 第 5 题 (难度: ⭐⭐⭐⭐)
**题干**：若图中存在从 s 出发可到达的负权回路，对同一张图分别运行 Dijkstra（源 s）、Bellman-Ford（源 s）与 Floyd，下列输出行为描述正确的是：

- A. 三者都会陷入死循环，无法终止
- B. 三者都能在有限步内终止，但 Dijkstra 与 Floyd 输出的距离值无意义，Bellman-Ford 可通过第 n 次迭代仍有松弛来检测并报告负回路
- C. 只有 Floyd 能检测负回路，方法为检查 dist[i][j] 是否为负
- D. Bellman-Ford 会输出 -∞ 作为最短路距离

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：Dijkstra、Floyd、Bellman-Ford 的循环结构与负回路无关，均必然有限步终止，『死循环』是计算机直觉替代算法分析的典型陷阱（SPFA 若不加入队次数限制才可能被恶意数据卡但也不会真死循环）；选项C陷阱：检测条件错误——应为检查对角元素 dist[i][i]<0，任意 dist[i][j]<0 只说明存在负权路径，不一定是回路；选项D陷阱：有限次迭代下数值只会是某具体整数（不断减小但每次迭代有界），算法输出的是检测报告而非 -∞，混淆数学概念与算法实际输出。

**【深度解析】**:
三者循环次数均由算法结构（n 轮 / n^2 次松弛 / n 阶段）固定，故必然终止。但负回路使最短路在数学上不存在（可无限绕行），Dijkstra 与 Floyd 输出的有限数值已失去『最短』意义；Bellman-Ford 恰好利用『n-1 轮后应收敛』这一性质，第 n 轮仍能松弛即证存在可达负回路。Floyd 检测手段是 dist[i][i]<0。破局思维：区分『终止性』与『结果正确性』两个独立维度。

</details>

// Dijkstra 邻接矩阵实现 O(n^2)
#include <stdio.h>
#define N 6
#define INF 0x3f3f3f3f
int g[N][N], dist[N], vis[N], pre[N];

void dijkstra(int s) {
    for (int i = 0; i < N; i++) { dist[i] = INF; vis[i] = 0; pre[i] = -1; }
    dist[s] = 0;
    for (int cnt = 0; cnt < N; cnt++) {
        int u = -1;
        for (int j = 0; j < N; j++)          // 找未确定的最小 dist
            if (!vis[j] && (u == -1 || dist[j] < dist[u])) u = j;
        if (u == -1 || dist[u] == INF) break;
        vis[u] = 1;                           // 出队即定型
        for (int v = 0; v < N; v++)           // 松弛所有邻边
            if (!vis[v] && g[u][v] != INF && dist[u] + g[u][v] < dist[v]) {
                dist[v] = dist[u] + g[u][v];
                pre[v] = u;                   // 记录前驱以还原路径
            }
    }
}

// Floyd 实现 O(n^3)，k 必须在最外层
void floyd(int d[N][N], int p[N][N]) {
    for (int i = 0; i < N; i++)
        for (int j = 0; j < N; j++) p[i][j] = (i != j && d[i][j] < INF) ? i : -1;
    for (int k = 0; k < N; k++)
        for (int i = 0; i < N; i++)
            for (int j = 0; j < N; j++)
                if (d[i][k] != INF && d[k][j] != INF && d[i][k] + d[k][j] < d[i][j]) {
                    d[i][j] = d[i][k] + d[k][j];
                    p[i][j] = p[k][j];        // 记录中转前驱
                }
}

**【命题人解题思维点拨】**:
本题系统考察两大最短路算法的协同设计能力。陷阱一：(1) 问中第 3 轮确定顶点 3 后，其松弛对已定型的顶点 4 不生效，若考生机械地对所有顶点松弛会误改 dist；陷阱二：(2) 问 k=0 轮『看似应该有更新实则没有』，考察考生是否真正逐项验证而非想当然地认为每轮必有更新；陷阱三：(3) 问扩容场景是典型的选型陷阱——稠密图矩阵实现占优、稀疏图堆优化占优，n=1000 且 e=5000 属稀疏，O(n^2)=10^6 与 O(e log n)≈5×10^4 量级差异需定量比较而非定性口诀；陷阱四：(4) 问负权边场景考察两种算法正确性前提的本质差异——Dijkstra 的『出队即定型』依赖边权非负的单调累积性，负权边使已定型点可能被更短绕行路径推翻，而 Floyd 的 DP 转移只要求无负回路，允许负权边，故 Floyd 仍正确。阅卷时应重点检查 Floyd 代码 k 循环位置与 Dijkstra 的 vis 标记逻辑，这两处是历年考生失分重灾区。
