### 第 1 题 (难度: ⭐⭐⭐⭐)
**题干**：对含有 n 个互不相同元素的数组执行快速排序（每次以当前子区间第一个元素为枢轴，采用枢轴与两端指针交替移动的划分算法）。下列说法正确的是：

- A. 若初始序列已经有序，则递归深度为 O(logn)，时间复杂度为 O(nlogn)
- B. 划分过程中，指针相遇位置即枢轴的最终位置，且该位置左侧元素均小于枢轴、右侧均大于枢轴，故每一趟划分至少能确定一个元素的最终位置
- C. 快速排序的空间复杂度在任何情况下均为 O(logn)，因为递归栈深度由划分的平衡性决定
- D. 若每次划分恰好将区间分为长度为 n-1 与 1 的两段，则总比较次数为 O(n^2)，但比较次数仍严格小于完全排序所需比较次数的下界 nlogn

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：初始有序时每次划分极度不平衡，递归深度退化为 O(n)，时间退化为 O(n^2)，恰好说反，是快排最经典的反直觉陷阱；选项C陷阱：最坏情况递归深度达 O(n)，空间复杂度应表述为 O(logn) 最好、O(n) 最坏，平均 O(logn)，笼统说任何情况均为 O(logn) 错误；选项D陷阱：前半句正确，但后半句荒谬——O(n^2) 远大于比较排序下界 O(nlogn)，下界是最优算法的下限而非所有算法的下限，利用考生对『下界』含义的模糊认识设置陷阱。

**【深度解析】**:
破局关键：快排性能完全由枢轴划分的对称性决定。初始有序+首元素为枢轴时，每趟只能剔除一个元素，形成 n 层递归链：比较次数为 (n-1)+(n-2)+...+1 = n(n-1)/2，故 O(n^2)；递归深度即 O(n)。B 选项考察划分的机制本质：双指针相遇点即为枢轴归位点，这是『每趟至少确定一个元素最终位置』的依据，也是判断快排趟数的通用判据。记忆锚点：有序/逆序输入是快排天敌，随机化枢轴或三者取中可规避。

</details>

### 第 2 题 (难度: ⭐⭐⭐⭐)
**题干**：已知关键字序列 (46, 79, 56, 38, 40, 84)，采用大顶堆进行堆排序。下列关于建堆过程的说法正确的是：

- A. 建初始大顶堆需从最后一个元素 n-1 开始逐个向上筛选，共执行约 n 次筛选调整，时间复杂度为 O(nlogn)
- B. 自底向上建初始堆时，最后一个非叶结点下标为 ⌊n/2⌋-1，对 46, 79, 56, 38, 40, 84 建成的大顶堆层序为 84, 79, 56, 38, 40, 46
- C. 建堆时间复杂度为 O(n) 的原因是：大多数结点位于底层，其下沉高度很小，高度为 h 的结点至多 ⌈n/2^(h+1)⌉ 个，对全部结点的下沉代价求和收敛
- D. 建好初始堆后，第一次将堆顶 84 与末尾 46 交换，随后对前 n-1 个元素重新筛选，此时堆顶层序为 79, 46, 56, 38, 40

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `C`

**【各选项排雷剖析】**:
选项A陷阱：建堆只从最后一个非叶结点 ⌊n/2⌋-1 开始筛选，且总代价求和后是 O(n) 而非 O(nlogn)——把『每次筛选 O(logn)』机械相乘是考生最常犯的复杂度误算；选项B陷阱：建堆应从 i=⌊n/2⌋-1=2（元素56）开始向前筛选，逐个手算可得结果，该选项给出的堆序是错误模拟的产物，考察动手推演能力；选项D陷阱：交换 84 与 46 后对前 5 个元素筛选：46 与 79、56 比较后与 79 交换，79 再与 40 比较，结果应为 79, 46, 56, 38, 40 需逐步验证——实际 46 下沉后 79 位于堆顶，第二层为 46 与 56，第三层 38 与 40，即 79, 46, 56, 38, 40 表面上对，但此处 46 在左子树中会继续与 38 比较不交换，最终序列需以严格筛选规则验证，任何跳步模拟都会出错，属于模拟陷阱。

**【深度解析】**:
破局关键：建堆 O(n) 的证明是选择题高频考点。设高度为 h 的结点最多 n/2^(h+1) 个，每个下沉代价 O(h)，求和 Σ h·n/2^(h+1) = O(n·Σ h/2^h) = O(2n) = O(n)。本质是『底层结点多但几乎不下沉，顶层结点下沉深但数量极少』的加权平均思想。注意区分：建堆 O(n)，而排序全过程（含 n-1 次调整，每次 O(logn)）为 O(nlogn)。手算堆题必须严格按『从最后一个非叶结点起、自右向左自下而上』的顺序筛选，不可跳步。

</details>

### 第 3 题 (难度: ⭐⭐⭐⭐)
**题干**：关于排序算法的稳定性与适用场景，下列判断正确的是：

- A. 简单选择排序是稳定的，因为每次选择最小元素时若与当前元素相等可不做交换
- B. 快速排序、堆排序、希尔排序均不稳定，其中堆排序不稳定的原因是：堆顶与末尾元素交换可能跨越多个相等元素的相对位置
- C. 归并排序在归并两个有序段时，若两段当前元素相等，先取右段元素可提高效率且不破坏稳定性
- D. 对基本有序的序列，直接插入排序时间接近 O(n)，而堆排序时间也接近 O(n)，因为堆已基本建成

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：标准简单选择排序用交换实现时，长距离交换会跨越相等元素破坏稳定性（如 2a, 2b, 1 → 1, 2b, 2a），是『直觉稳定实则不稳定』的经典反例；选项C陷阱：归并必须先取左段（左段元素先进入原序列）才能保证稳定性，先取右段恰恰破坏稳定性，且取哪边不影响比较次数，效率说法也是幌子；选项D陷阱：堆排序对初始序列的有序性完全不敏感，无论输入是否有序均为 O(nlogn)，『基本有序』只利好插入类和冒泡类排序，混淆了不同算法对初始状态的敏感机制。

**【深度解析】**:
破局锚点表格：不稳定四人组——快排、堆排、希尔、直接选择（口诀：快些堆选不稳定）；稳定组——插入、冒泡、归并、基数。判断稳定性的通用思维：凡涉及『远距离交换』或『按关键位重新分配』的算法，需重点检查相等元素相对次序是否被破坏。归并稳定的核心是归并时相等取左（先到先得）。另一高频结论：序列基本有序时，直接插入 O(n)、冒泡 O(n)，而快排反而退化 O(n^2)、堆排与归并保持 O(nlogn)——初始状态敏感性是各算法的『性格』，须逐个掌握。

</details>

### 第 4 题 (难度: ⭐⭐⭐⭐⭐)
**题干**：对外部排序的 k 路平衡归并，设初始归并段数为 m，下列分析正确的是：

- A. k 越大，归并趟数 ⌈log_k m⌉ 越少，故总 I/O 次数一定越少，应尽可能增大 k
- B. 采用败者树后，每次从 k 个归并段中选出最小关键字只需 O(logk) 次比较，故 k 路归并一次扫描 n 个记录的总比较次数为 O(nlogk)
- C. 若 m=100，k=5，采用最佳归并树需补充虚段，补充虚段个数 = (5-1)×(100-1) % 5 = ... 需补充 3 个虚段，虚段应附加在权值最大的归并段处
- D. 置换-选择排序生成的初始归并段平均长度为内存工作区容量的 2 倍，且生成归并段的过程本身就是外部排序中减少归并段数 m 的手段之一

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `D`

**【各选项排雷剖析】**:
选项A陷阱：k 增大虽减少归并趟数，但每趟每个记录的比较次数变为 O(logk)（未用败者树时为 k-1 次），且需更多缓冲区，I/O 次数并非单调减少，『越大越好』是典型的单因素思维陷阱；选项B陷阱：败者树选最小仅需 O(logk) 次比较是对的，但这是『每次选出一个冠军』的代价；一次扫描输出 n 个记录时总比较次数为 O(n⌈logk⌉)，数值上该选项结论其实正确，但极易与『k-1 次线性比较』混淆，若不用败者树则每选一个需 k-1 次，总 O(nk)，考察败者树机制是否真正掌握；选项C陷阱：补充虚段数 u=(k-1-(m-1)%(k-1))%k，m=100,k=5 时 (100-1)%4=3，需补 1 个虚段而非 3 个；且虚段（权值 0）在哈夫曼构造中应放在最小的权处参与合并，而非最大权处，双重错误。

**【深度解析】**:
破局关键：外排序三要素——减少初始归并段数（置换-选择，平均段长 2 倍内存容量）、减少归并趟数（增大 k）、减少每趟代价（败者树/最佳归并树）。最佳归并树本质是 k 叉哈夫曼树：m 个初始段为叶子，段长为权，补充虚段（权 0）使叶子数满足 (m-1)%(k-1)=0，虚段必须最先参与合并（权最小处）。趟数公式 ⌈log_k m⌉。综合思维：外部排序优化永远围绕『I/O 是瓶颈』展开，内存计算代价的优化服务于减少访外次数。

</details>

### 第 5 题 (难度: ⭐⭐⭐⭐)
**题干**：对序列 (49, 38, 65, 97, 76, 13, 27, 49*) 执行一趟快速排序（以 49 为枢轴，双端指针交替移动：先从 high 端向左找小于枢轴者，再从 low 端向右找大于枢轴者，交替进行直至两指针相遇）。则一趟划分结束后的序列及枢轴位置为：

- A. (27, 38, 13, 49, 76, 97, 65, 49*)，枢轴位于下标 3
- B. (27, 38, 13, 49, 76, 97, 65, 49*)，枢轴位于下标 4
- C. (13, 38, 27, 49, 76, 97, 65, 49*)，枢轴位于下标 3
- D. (27, 38, 65, 13, 76, 97, 49, 49*)，枢轴位于下标 6

**【正确答案】**: `A`

**【各选项排雷剖析】**:

- (4) 对比堆排序与快速排序在最坏时间复杂度、平均空间复杂度、稳定性上的差异，并说明堆排序的优先适用场景。

**【核心算法/推导实现】**:

```cpp
// (1)(2) 手算推导：
// 初始序列: 53 27 36 15 69 42 (n=6, 最后非叶结点 i=2)
// 对 i=2(36): 子结点 69(下标4) 为其唯一参与比较方向? 36 的孩子为 42(5) 与 69(4)?
//   下标2的孩子为 5(42) 和 6(不存在? n=6 下标0~5, 孩子 2*2+1=5, 2*2+2=6 越界)
//   36 与孩子 42 比较: 42>36 交换 → 53 27 42 15 69 36
// 对 i=1(27): 孩子 69(4), 15(3)? 孩子 3(15) 和 4(69), 与 69 交换 → 53 69 42 15 27 36
// 对 i=0(53): 孩子 69(1), 42(2), 与 69 交换; 53 下沉到 1, 其孩子 15(3), 27(4), 与 27 交换
//   → 69 53 42 15 27 36  …… 即最终大顶堆层序: 69 53 42 15 27 36
// (2) 第一趟: 堆顶69与末尾36交换 → 36 53 42 15 27 | 69; 筛选: 36与53交换, 36与27比较不换
//   → 53 36 42 15 27 | 69 …… 注意 36 的孩子为 15,27, 与 27 交换得 53 42? 严格推演:
//   36 与孩子 53,42 中大者 53 交换 → 53 36 42 15 27; 36 孩子 15,27, 与 27 交换 → 53 27 42 15 36
//   第一趟后: 53 27 42 15 36 [69]
// 第二趟: 堆顶53与末尾36交换 → 36 27 42 15 [53 69]; 筛选: 36与42交换 → 42 27 36 15
//   第二趟后: 42 27 36 15 [53 69]

// (4) 完整堆排序参考代码:
#include <stdio.h>

void Swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }

void SiftDown(int A[], int n, int i) {   // 大顶堆下沉调整, O(logn)
    while (2 * i + 1 < n) {
        int j = 2 * i + 1;               // 左孩子
        if (j + 1 < n && A[j + 1] > A[j]) j++;  // 取较大孩子
        if (A[i] >= A[j]) break;
        Swap(&A[i], &A[j]);
        i = j;
    }
}

void BuildHeap(int A[], int n) {         // 自底向上建堆, O(n)
    for (int i = n / 2 - 1; i >= 0; i--)
        SiftDown(A, n, i);
}

void HeapSort(int A[], int n) {          // 总复杂度 O(n) + (n-1)*O(logn) = O(nlogn)
    BuildHeap(A, n);
    for (int end = n - 1; end > 0; end--) {
        Swap(&A[0], &A[end]);            // 堆顶(当前最大)归位
        SiftDown(A, end, 0);             // 对前 end 个元素重新调整
    }
}

int main(void) {
    int A[] = {53, 27, 36, 15, 69, 42};
    int n = sizeof(A) / sizeof(A[0]);
    HeapSort(A, n);
    for (int i = 0; i < n; i++) printf('%d ', A[i]);
    // 输出: 15 27 36 42 53 69
    return 0;
}

// (3) 复杂度推导:
// 高度为 h 的结点至多 ⌈n/2^(h+1)⌉ 个, 每个下沉代价 O(h)
// T(n) = Σ_{h=0}^{⌊logn⌋} ⌈n/2^(h+1)⌉·O(h) = O(n·Σ_{h>=0} h/2^h) = O(2n) = O(n)
```

**【命题人解题思维点拨】**:
系统级破局分析：本题四问层层递进，覆盖堆排序从机制（筛选）、手算（趟次模拟）、理论（复杂度证明）到横向对比（与快排权衡）的完整认知链条。命题陷阱点评：(a) 手算建堆时最常见错误是混淆数组下标与树的孩子计算（孩子为 2i+1、2i+2，最后一个非叶结点为 ⌊n/2⌋-1），n=6 这类偶数规模会让最右叶子缺兄弟，极易推错；(b) 第(2)问中 69 与 36 交换后 36 下沉路径需逐层比较两个孩子取大者，考生常漏比较直接与左孩子交换；(c) 第(3)问若只会背结论不会推导，在证明题中只能得一半分，Σh/2^h 收敛是必须掌握的级数；(d) 第(4)问核心洞察：堆排是唯一兼具 O(nlogn) 最坏时间与 O(1) 空间、且对输入分布完全不敏感的比较排序，但缓存局部性差导致实际常数大，这正是工程中快排更常用而考试中堆排更『安全』的原因，理解这一软硬件协同的权衡才是 408 高分考生的素养。
