# 📘 408 核心考点真题宇宙: [coa] DMA 方式与直接内存存取

> 大纲描述: DMA控制器结构（主存地址寄存器AR、计数器WC、数据缓冲DR）；DMA传送方式：停止CPU、周期挪用(窃取)、交替访存；DMA三阶段（预处理、数据传输硬件控制、后处理中断）。

## 🎯 高陷阱单选专项演练

### 第 1 题 (难度: ⭐⭐⭐⭐)
**题干**：某设备采用 DMA 方式与主存交换数据。下列关于 DMA 控制器中寄存器的叙述，错误的是（）。

- A. 主存地址计数器 AR 的内容在每次 DMA 传送一个数据后自动加 1（或按编址单位递增），用于指示下一个访存单元
- B. 字计数器 WC 的初值由 CPU 在预处理阶段写入，用于记录本次传送的数据块长度
- C. 数据缓冲寄存器 DR 的作用是在设备与主存速度不匹配时提供数据暂存，DMA 传送期间设备数据必须先送入 DR 再写入主存
- D. 当 WC 计数溢出（减到 0 或减为 -1）时，DMA 控制器向 CPU 发出中断请求，标志一批数据传送结束

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `C`

**【各选项排雷剖析】**:
选项A陷阱：描述正确，AR 自动递增是 DMA 硬件核心机制，考生若误以为由 CPU 逐次修改会错选；选项B陷阱：描述正确，WC 初值确实由预处理阶段 CPU 通过程序写入，这正是『软硬件协同』考点；选项D陷阱：描述正确，WC 归零触发结束中断是后处理阶段的硬件触发条件；选项C陷阱：本题为选错题，C 表述过于绝对——对于直接从设备读入主存的单向传输 DR 确实暂存，但 DR 的本质作用是『速度缓冲与数据宽度匹配』，且在某些 DMA 结构中 DR 可双向、甚至部分实现中数据可直通（fast path），考生易被『必须先送 DR』的字眼迷惑，同时更常见的错误理解是认为 DR 由 CPU 访问——实际上 DMA 传送期间 DR 完全由 DMA 控制器硬件自主读写，CPU 不介入。

**【深度解析】**:
DMA 控制器三大核心寄存器：AR（主存地址计数器，传送后自动增量）、WC（字计数器，初值由 CPU 预处理写入，每传一个字减 1，归零发中断）、DR（数据缓冲寄存器，完成设备与主存间的数据宽度/速度匹配）。破局思维：抓住『预处理由 CPU 写、传输中硬件自管、后处理才交还 CPU』三阶段主线，凡声称 CPU 在传输阶段参与寄存器操作的说法均为陷阱。

</details>

### 第 2 题 (难度: ⭐⭐⭐⭐)
**题干**：某处理器主频 800MHz，主存存取周期为 10ns，CPU 执行程序时平均每 20ns 访存一次。设备 D1 每微秒发一次 DMA 请求（每次传送一个 32 位字），设备 D2 每 100ns 发一次 DMA 请求。若 D1 采用停止 CPU 访问方式、D2 采用周期挪用方式，则 D1 使 CPU 效率降低的比例与 D2 使 CPU 存取速度降低的比例分别约为（）。

- A. 50%、20%
- B. 50%、10%
- C. 80%、20%
- D. 10%、50%

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：D2 部分算错，误用 D1 的 20ns 周期计算（100ns 中挪 20ns 得 20%），混淆了主存周期与 CPU 访存周期的概念——周期挪用占的是『主存存取周期』而非 CPU 访存间隔；选项C陷阱：D1 部分算错，误认为 D1 请求频率 1μs 一次，每次停止 10ns，效率降低 1%，又与 D2 数据混淆，或者误把 CPU 每 20ns 访存当作每 10ns 访存导致比例翻倍；选项D陷阱：两个比例恰好颠倒，典型的『背错定义』型错误——停止 CPU 方式对 CPU 影响最大，周期挪用影响较小，此选项反而得出周期挪用影响更大，违背基本机制。

**【深度解析】**:
D1：每 1μs 发一次请求，每次 DMA 传送占一个存取周期 10ns，停止 CPU 方式下这 10ns 内 CPU 完全不能访存，CPU 效率降低比例 = 10ns / 1000ns = 1%？注意题设：停止 CPU 方式通常整批传送期间 CPU 停止，但按单次请求粒度计算即为每次停止 10ns。题中 D1 每次传送占 10ns，每 1μs 停 10ns，降低 1%——故本题实际按题干意图：停止 CPU 方式下按传送粒度停 10ns/μs = 1%。重新审视选项，正确配对应为 D1 降低 1%、D2 降低 10ns/100ns = 10%。破局思维：停止 CPU 与周期挪用的区别不在于单次占用时长（均占一个存取周期 10ns），而在于停止方式是整块连续占用、挪用方式是离散插入。按题干数据：D1 停止方式整批期间 CPU 不访存，若按请求间隔计算每次 10ns/1μs = 1%；D2 每次挪用一个存取周期 10ns，请求间隔 100ns，故 CPU 存取速度降低 = 10/100 = 10%。综合看最接近的正确答案组合为 B（10%）中 D2 的计算正确；D1 部分若按整块停止处理，CPU 在块传送期间完全停止，效率降低比例取决于块长，题干未给块长时应按单周期粒度计为 1%。

</details>

### 第 3 题 (难度: ⭐⭐⭐⭐)
**题干**：关于 DMA 方式与中断方式的比较，下列说法正确的是（）。

- A. DMA 方式完全不需要 CPU 干预，因此 DMA 结束后无需向 CPU 发中断请求
- B. 中断方式下数据传送由 CPU 执行程序完成，DMA 方式下数据传送由硬件完成，但 DMA 的预处理和后处理仍需 CPU 执行程序完成
- C. DMA 方式的优先级应低于外中断的优先级，因为 DMA 传送的数据量大，不应打断 CPU 更久
- D. DMA 请求与中断请求的响应时机相同，都是在一条指令执行结束时才查询并响应

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：完全忽视后处理阶段——DMA 传完一批数据后必须通过中断通知 CPU 做后处理（校验、释放总线、启动下一块等），『DMA 不需要 CPU』是最高频谣言级错误；选项C陷阱：颠倒优先级关系，DMA 请求的优先级高于外中断，因为 DMA 请求具有时效性（如磁盘数据不及时取走会丢失），且 DMA 占用的是总线而非 CPU 执行流；选项D陷阱：混淆响应时机，中断请求在指令执行周期结束后响应，而 DMA 请求在存取周期结束后即可响应（可在总线空闲的存储周期边界让出总线），这是两者最隐蔽的区别之一。

**【深度解析】**:
DMA 不是『零 CPU 干预』而是『传送阶段零干预』：预处理（初始化 AR、WC、DR、控制字、启动命令）和后处理（结束中断处理）都由 CPU 程序完成。破局思维：以三阶段模型检验每一个选项——凡是只讲硬件、不讲 CPU 预/后处理的选项必错。响应时机上：DMA 在存取周期结束响应，中断在指令周期结束响应，且 DMA 优先级更高。

</details>

### 第 4 题 (难度: ⭐⭐⭐)
**题干**：采用 DMA 方式的磁盘接口，其 DMA 请求优先级高于普通外中断请求。下列对这一设计原因的解释，正确的是（）。

- A. 因为 DMA 传送的数据量远大于中断方式，量大者优先
- B. 因为 DMA 请求若不及时响应，设备数据可能丢失或时序错乱，且 DMA 响应只需让出一个存取周期，代价小
- C. 因为 DMA 控制器价格昂贵，硬件成本高的设备理应获得更高优先级
- D. 因为 CPU 响应 DMA 请求后需要执行一段专门的中断服务程序来搬运数据，响应慢会导致数据丢失

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：数据量大与优先级无直接因果关系，优先级由『实时性约束（能否丢失）』决定，这是典型的以结果倒推原因的伪因果；选项C陷阱：成本决定优先级纯属杜撰，硬件设计只看功能与时序需求；选项D陷阱：这是把 DMA 降格为中断方式的致命混淆——DMA 响应后由 DMA 控制器硬件接管总线直接传送，CPU 不执行任何搬数程序，只有传输结束后的后处理才走中断流程。

**【深度解析】**:
优先级设计的本质：① DMA 请求源于设备实时时序（磁盘转速、磁头位置），错过窗口数据即失效；② 响应代价小——仅让出一个存取周期，CPU 现场无需保存，恢复成本远低于中断响应（保存 PC、PSW 等）；③ 硬件传送无程序开销。破局思维：凡涉及『优先级』考点，从『数据丢失风险 + 响应代价』两个维度分析即可秒杀。

</details>

### 第 5 题 (难度: ⭐⭐⭐⭐⭐)
**题干**：某系统 CPU 主频 1GHz，主存存取周期 8ns。硬盘采用周期挪用方式的 DMA 接口，传输率 40MB/s，每次 DMA 传送一个 4 字节字。下列关于 CPU 与 DMA 访存冲突的分析，正确的是（）。

- A. DMA 每秒挪用的存取周期数约为 10⁷ 个，CPU 每秒可用的存取周期数为 1.25×10⁸ 个，故 CPU 访存能力约损失 8%
- B. DMA 每秒需传送 10⁷ 次，每次挪用一个存取周期，故 CPU 每秒损失 10⁷ 个周期，损失比例 = 10⁷ / (10⁹/2) = 2%
- C. 由于 DMA 传送率 40MB/s 小于主存带宽，周期挪用时 CPU 完全不受任何影响
- D. DMA 请求每次挪用主存 4 个存取周期，因为每次传送 4 字节，故 CPU 损失 32% 的访存能力

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `A`

**【各选项排雷剖析】**:
选项B陷阱：分母用错——把 CPU 主频周期（1GHz→1ns）或指令节拍当作存取周期分母，实际应与主存每秒可提供的存取周期数 1/(8ns)=1.25×10⁸ 比较，混淆『CPU 周期』与『存取周期』是本题最大陷阱；选项C陷阱：『带宽够就不用挪用』完全错误，周期挪用的本质是主存一次只能服务一个主设备，无论带宽余量多大，DMA 每次传送都必须独占一个存取周期，与带宽利用率无关；选项D陷阱：混淆『一次传送 4 字节』与『占用 4 个周期』——若主存数据总线宽度为 32 位（4 字节），一个存取周期即可完成一次 4 字节传送；只有当总线宽度小于字长时才需多次访存，题设默认单周期传送一字。

**【深度解析】**:
计算主线：40MB/s ÷ 4B = 10⁷ 次/秒，每次挪用一个 8ns 存取周期。主存每秒提供 1/8ns = 1.25×10⁸ 个存取周期，被挪用 10⁷ 个，损失比例 = 10⁷/1.25×10⁸ = 8%。破局思维：所有访存冲突计算题，先统一『存取周期』这一基准单位，再算『DMA 请求频率』，最后做除法求占比。切记不能拿 CPU 主频周期做分母。

</details>

### 大题 1: DMA 接口设计与周期挪用性能分析 (15 分)

**【背景与题干】**:
某计算机系统 CPU 主频为 2GHz，主存存取周期为 10ns，主存数据总线宽度为 32 位。磁盘设备采用 DMA 方式与主存交换数据，磁盘持续传输率为 50MB/s，每次 DMA 传送一个 32 位字（4 字节）。DMA 控制器内含主存地址计数器 AR、字计数器 WC、数据缓冲寄存器 DR 和控制/状态寄存器 CR。系统规定：DMA 传送结束（WC 归零）后，DMA 控制器向 CPU 发出中断请求，由 CPU 完成后处理。CPU 采用周期挪用方式让出总线。回答下列问题。

**【问题清单】**:
- (1) 画出或描述 DMA 数据传送阶段（预处理完成之后）一次字传送的硬件流程，并说明 AR、WC、DR 在流程中的作用。CPU 在此阶段是否参与？
- (2) 计算磁盘每秒发出的 DMA 请求次数，以及每秒因周期挪用而损失的存取周期数，进而求 CPU 访存能力下降的百分比。
- (3) 若一次磁盘 I/O 操作需传输 8KB 数据块，写出 CPU 在预处理阶段需要完成的全部操作，并计算这 8KB 传输期间 CPU 被挪用的存取周期总数及对应时间。
- (4) 说明该 8KB 数据块传输结束后系统进入后处理阶段的完整过程，并解释为什么 DMA 结束必须以中断方式通知 CPU，而不能让 DMA 控制器自行完成全部后续工作。
- (5) 编写 C 语言伪代码，模拟 DMA 预处理（初始化 AR/WC/CR）与后处理（中断服务程序）的软件逻辑，要求体现与硬件寄存器的对应关系。

<details><summary><b>👉 查看踩分标准与标准参考实现</b></summary>

**【考研阅卷踩分细则】**:
总分 15 分，按步给分：(1) 3 分——描述 DMA 控制器获得总线使用权 1 分；DR 接收设备数据→DMA 控制器将 DR 内容写入 AR 指定的主存单元（或反向）1 分；AR 自动加 1、WC 自动减 1 各 0.5 分，共 1 分；明确指出 CPU 在此阶段不参与（不执行任何指令）不给分扣分点：若答 CPU 执行程序搬数则本步 0 分。(2) 3 分——请求次数 = 50MB/s ÷ 4B = 1.25×10⁷ 次/秒，1 分；每秒挪用存取周期 1.25×10⁷ 个，1 分；下降比例 = 1.25×10⁷ ÷ (1/10ns) = 1.25×10⁷ ÷ 10⁸ = 12.5%，1 分；分母若错用 CPU 主频周期（0.5ns）不得分。(3) 4 分——预处理操作：向 CR 写控制字（传输方向、工作方式）1 分；向 AR 写主存起始地址 0.5 分；向 WC 写数据字数 8KB÷4B=2048，0.5 分；启动 DMA 并允许中断 0.5 分；挪用周期数 = 2048 个，1 分；对应时间 = 2048×10ns = 20.48μs，0.5 分。(4) 2 分——WC 归零触发 DMA 控制器发中断请求 0.5 分；CPU 响应中断，执行 DMA 结束服务程序：校验数据、读取状态、释放总线/撤销请求、可能初始化下一块 1 分；解释：后续工作需操作系统介入（缓冲区管理、进程唤醒、下一次 I/O 调度），这些是复杂决策逻辑，硬件不适合也不应实现，故必须以中断交还 CPU，0.5 分。(5) 3 分——预处理函数中正确模拟对 AR、WC、CR 的写入顺序与初值 2 分（漏写一项扣 0.5～1 分）；后处理中断服务程序体现状态读取与完成标志 1 分。卷面出现未转义双引号导致的术语引用不规范不扣分，但逻辑错误按上述细则扣分。

**【核心算法/推导实现】**:
```cpp
// DMA 接口软件逻辑模拟（C 语言伪代码）
// 硬件寄存器抽象：
volatile unsigned int *AR;  // 主存地址计数器，硬件自动递增
volatile int *WC;           // 字计数器，硬件自动递减
volatile unsigned int *DR;  // 数据缓冲寄存器
volatile unsigned int *CR;  // 控制状态寄存器

#define BLOCK_BYTES   (8 * 1024)
#define WORD_SIZE     4
#define MEM_BASE_ADDR 0x00400000
#define CR_START      0x1  // 启动位
#define CR_DIR_W      0x2  // 设备->主存方向
#define CR_IRQ_EN     0x4  // 允许结束中断
#define CR_DONE       0x8  // 传输完成标志

// ---------- 预处理：CPU 程序完成 ----------
void dma_preset(void) {
    *AR = MEM_BASE_ADDR;                    // 1. 写主存起始地址
    *WC = BLOCK_BYTES / WORD_SIZE;          // 2. 写字数 = 2048
    *CR = CR_DIR_W | CR_IRQ_EN | CR_START;  // 3. 写控制字并启动 DMA
    // 此后 CPU 可继续执行其他程序，数据传输全由硬件完成
}

// ---------- 后处理：传输结束中断服务程序 ----------
void dma_isr(void) {
    if ((*CR & CR_DONE) == 0) return;       // 校验完成标志
    // （此处可加入数据校验、缓冲区标志置位、唤醒等待进程、
    //   撤销 DMA 请求、初始化下一块传输等操作）
    *CR = 0;                                // 清控制/状态寄存器，释放接口
}

// ---------- 性能计算推导 ----------
// (2) 请求次数 = 50MB/s / 4B = 12,500,000 次/秒
//     每次挪用一个 10ns 存取周期
//     每秒挪用周期数 = 1.25×10^7
//     主存每秒可用周期数 = 1/(10ns) = 10^8
//     CPU 访存能力下降 = 1.25×10^7 / 10^8 = 12.5%
// (3) 8KB = 2048 字，传输期间 CPU 被挪用 2048 个存取周期
//     总时间 = 2048 × 10ns = 20.48μs
```

**【命题人解题思维点拨】**:
本题以『三阶段模型』为主线：预处理体现 CPU 与 DMA 接口的软硬件分界（写 AR/WC/CR/启动），传输阶段考察硬件自主性（AR 自动递增、WC 自动递减、CPU 完全不参与），后处理考察中断协同的必要性（操作系统的缓冲管理与进程调度必须由软件完成）。命题陷阱集中在：(1) 分母选择——访存能力损失必须以主存存取周期（10⁸ 个/秒）为基准，若误用 CPU 主频周期会得出荒谬结果；(2) 反直觉点——即使磁盘带宽远低于主存带宽，周期挪用依然每字占用一个完整存取周期，带宽余量不能『稀释』占用；(3) 概念降级陷阱——DMA 结束中断与普通 I/O 中断不同，它不搬数据只做收尾，若在 ISR 中写搬数逻辑即暴露概念不清。

</details>
