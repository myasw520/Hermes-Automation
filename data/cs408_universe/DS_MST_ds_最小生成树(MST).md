# 📘 408 核心考点真题宇宙: [ds] 最小生成树(MST)

> 大纲描述: Prim算法（以顶点为中心，稠密图适用，复杂度O(V^2)）与Kruskal算法（以边为中心，稀疏图适用，并查集辅助，复杂度O(E log E)）。

## 🎯 高陷阱单选专项演练

### 第 1 题 (难度: ⭐⭐⭐⭐)
**题干**：已知无向连通图 G 有 n 个顶点、e 条边，各边权值互不相同。下列关于最小生成树的叙述中，正确的是（　）。

- A. G 的最小生成树是唯一的，但 Prim 与 Kruskal 算法求出的树可能不同
- B. 若将图中某一条边的权值增大，最小生成树一定发生改变
- C. G 的最小生成树是唯一的，且 Prim 与 Kruskal 算法求出的树必然相同
- D. 从不同顶点出发执行 Prim 算法，得到的最小生成树可能不同

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `C`

**【各选项排雷剖析】**:
选项A陷阱：前半句正确但后半句反直觉——当所有边权互不相同时，MST 唯一，任何正确的 MST 算法必然得到同一棵树，考生误以为不同算法构造顺序不同就结果不同；选项B陷阱：若被增大的边不在原 MST 上，则 MST 不变，这是经典的边界条件陷阱，考生误以为图中任何边都影响 MST；选项D陷阱：Prim 从不同起点出发构造的中间过程不同，但最终结果由 MST 唯一性保证必然相同，考生混淆『过程不同』与『结果不同』。

**【深度解析】**:
破局关键：边权互不相同 ⇒ 若存在两棵不同的生成树，比较两树边集，设权最小的差异边，用反证法与环性质可推出矛盾，故 MST 唯一；MST 唯一时，任何正确的贪心算法（Prim/Kruskal）输出的都是同一棵树，与起点、边处理顺序无关。对于 B，只有增大『位于 MST 上』的边才可能改变 MST，若增大的是非树边（本权已大于路径上所有边），增大后仍非树边，MST 不变。本题考查唯一性定理这一底层机制，而非算法步骤记忆。

</details>

### 第 2 题 (难度: ⭐⭐⭐⭐)
**题干**：关于 Prim 算法与 Kruskal 算法的时间复杂度及适用场景，下列说法正确的是（　）。

- A. Prim 算法基于并查集实现时复杂度为 O(eloge)，适用于稀疏图
- B. Kruskal 算法在最坏情况下需要检查图中所有的边，复杂度与边数 e 有关，适用于稀疏图；Prim 不依赖堆结构时复杂度为 O(n^2)，适用于稠密图
- C. Prim 算法的复杂度恒为 O(n^2)，与图的存储结构无关
- D. Kruskal 算法必须先对边按权值排序，故其复杂度为 O(e^2)，只适用于极小规模图

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：张冠李戴型陷阱，把 Kruskal 的并查集与 O(eloge) 硬安到 Prim 头上；Prim 以顶点为中心，朴素实现用数组维护最短低开销边，与并查集无关；选项C陷阱：『恒为』过于绝对——Prim 用邻接矩阵+朴素数组是 O(n^2)，但用邻接表+二叉堆可优化为 O(elogn)，复杂度与存储结构和辅助数据结构密切相关，408 常考此表述的绝对化错误；选项D陷阱：Kruskal 排序后还要配合并查集做近 O(e) 次合并查找（近似线性），总复杂度 O(eloge) 而非 O(e^2)，考生夸大了排序的代价并低估了算法适用性。

**【深度解析】**:
破局关键：抓住两个算法的『中心』——Prim 以顶点为中心，每轮需在全部候选顶点中选最小，朴素实现 O(n^2)，n 小 e 大（稠密）时占优；Kruskal 以边为中心，核心代价是对 e 条边排序 O(eloge)，e 小（稀疏）时占优。并查集是 Kruskal 判环的辅助结构，其近线性的复杂度不构成瓶颈。408 命题惯用『张冠李戴』与『绝对化表述』设置陷阱，见到『恒为』『一定』『必须』需警惕。

</details>

### 第 3 题 (难度: ⭐⭐⭐⭐)
**题干**：对带权无向连通图分别执行 Prim 和 Kruskal 算法。若图中存在权值相同的边，则下列叙述正确的是（　）。

- A. Kruskal 算法在选取权值相同的边时，若两条等权边会构成环，则选择先后顺序不同会得到不同的最小生成树
- B. 从不同顶点出发执行 Prim 算法，构造过程中加入顶点的顺序一定不同
- C. Prim 算法每次必须选择『树内顶点集到树外顶点集之间』权值最小的边，当有多条权值相同的最小边时任选其一均不影响最终 MST 的权值和
- D. 若图的最小生成树不唯一，则 Prim 与 Kruskal 求出的结果一定不同

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `C`

**【各选项排雷剖析】**:
选项A陷阱：概念偷换——等权边若构成环，则两条都不能同时选，选哪条先处理不影响最终树形态（被环排除的边本来就不能加入），考生混淆『等权边构成环』与『等权边可选』两种情形；选项B陷阱：『一定』太绝对——不同起点出发加入顶点的顺序完全可能恰好相同（例如存在一条主导性的低权边链时），反例即可推翻；选项D陷阱：MST 不唯一时两种算法可能碰巧得到同一棵树，『一定不同』错误，正确说法是『可能不同』，408 极爱考『一定/可能』的措辞差异。

**【深度解析】**:
破局关键：贪心正确性保证——无论等权边如何选取，每一步所加边的权值都是当前候选最小值，故 MST 的总权值和唯一（即使树不唯一）；Kruskal 中构成环的边无论先后都会被并查集判环排除；Prim 中等权的最小横切边任选其一都满足割性质。B 用反例：星形图所有边等权时，从任意点出发顺序仅为依次加入邻点，不同起点顺序结构可一致。本题综合考查贪心交换引理与反例思维。

</details>

### 第 4 题 (难度: ⭐⭐⭐⭐⭐)
**题干**：对 n 个顶点、e 条边的连通图执行 Kruskal 算法，采用路径压缩与按秩合并的并查集判环。下列关于算法执行过程的描述，错误的是（　）。

- A. 当选中并加入的边数达到 n-1 条时，算法可提前终止，不必继续扫描剩余边
- B. 若图不连通（有多个连通分量），算法结束后得到的边数小于 n-1，说明不存在生成树
- C. 算法中并查集的作用是判断当前边两个端点是否已在同一连通分量中，若是则放弃该边以避免成环
- D. 若 e 条边已按权值升序排好序，则 Kruskal 算法的总体复杂度可降至 O(e·α(n))，其中 α 为反阿克曼函数

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `D`

**【各选项排雷剖析】**:
选项D陷阱：本题要选错误项——即使边已排好序，Kruskal 求出的是生成树而非完整连通分量结构，复杂度分析中主要开销已从排序转移，但说总体复杂度『可降至 O(e·α(n))』在 408 大纲语境下属于超纲且表述失当：大纲只要求 O(eloge) 层面，且排序开销若计入预处理则并未消失，考生若课外读过高级并查集分析易被带偏；选项A/B/C 均为正确描述：A 是标准剪枝（选满 n-1 条边即成树）；B 是连通性判定的正确推论；C 是并查集在 MST 中的本职作用。命题意图：在四个叙述中夹入一个『看似高级实则失当』的选项检验考生的知识点边界意识。

**【深度解析】**:
破局关键：408 大纲对 Kruskal 的要求停留在『排序 O(eloge) + 并查集判环』层面，题目若给出超纲的高深表述（反阿克曼函数），在单选『选错误项』题型中往往就是答案——因为 408 不考此层面的精确复杂度界，且题目未声明排序开销是否计入。A、B、C 是教材级正确结论，用排除法锁定 D。这体现了『知己知彼』的应试思维：识别超出大纲深度的表述。

</details>

### 第 5 题 (难度: ⭐⭐⭐⭐⭐)
**题干**：将带权无向图 G 的每条边的权值都减去同一个正常数 c 后得到图 G'。下列关于 G 与 G' 的最小生成树关系的说法，正确的是（　）。

- A. G 与 G' 的最小生成树对应的边集一定相同，但总权值不同
- B. G 与 G' 的最小生成树对应的边集可能不同，因为各边权值的相对大小发生了改变
- C. G 与 G' 的最小生成树对应的边集一定不同
- D. G' 的最小生成树的总权值等于 G 的最小生成树总权值减去 c

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `A`

**【各选项排雷剖析】**:
选项B陷阱：反直觉陷阱——所有边同减常数 c，任意两条边的差值 |wi-wj| 不变，边的相对大小次序完全不变，Prim/Kruskal 的所有比较结果均不变，故 MST 边集不变；考生直觉上误以为『权值都变了树也会变』；选项C陷阱：与 B 同源的错误，且方向相反，『一定不同』明显荒谬但仍有考生在混淆相对次序后错选；选项D陷阱：算术陷阱——生成树有 n-1 条边，G' 的 MST 总权值应等于 G 的 MST 总权值减去 (n-1)·c 而非减去 c，考生漏乘边数，这是最隐蔽的计算陷阱。

**【深度解析】**:
破局关键：MST 算法本质上只依赖『边权之间的大小比较』而不依赖权值绝对数值。同减常数是保序变换：wi-c 与 wj-c 的大小关系与 wi、wj 一致，故贪心决策序列完全相同，MST 边集不变；总权值差为树边数 (n-1) 乘以 c。若改为『每条边乘以同一正常数』结论相同（乘正数也保序）；但若『加的常数因边而异』或『除以不同数』则保序性破坏，B 才可能成立。此题为数学变换视角下的机制理解题。

</details>

**【核心算法/推导实现】**:
```cpp
// ---- Kruskal 手工模拟（边按权升序） ----
// 排序后边序列: 1-3(1) 4-6(2) 2-5(3) 3-6(4) 1-2(6) 2-3(5) 1-4(5) 2-3(5) 3-5(6) 5-6(6)
// 实际升序排列为: 1-3(1), 4-6(2), 2-5(3), 3-6(4), 2-3(5), 1-4(5), 1-2(6), 3-5(6), 5-6(6) [同权可任意排列]
// 1) 取 1-3(1)  接受, 分量 {1,3}
// 2) 取 4-6(2)  接受, 分量 {4,6}
// 3) 取 2-5(3)  接受, 分量 {2,5}
// 4) 取 3-6(4)  接受, 合并 {1,3} {4,6} -> {1,3,4,6}
// 5) 取 2-3(5)  接受, 合并 {2,5} {1,3,4,6} -> 全部连通, 已选 5 = n-1 条边, 终止
// 拒绝示例: 若继续扫描, 1-4(5) 两端点已在同一分量, 判环拒绝

// ---- Prim 手工模拟（从顶点 1 出发） ----
// 第1轮: 树={1}, 候选横切边: 1-3(1)最小 -> 加入 3
// 第2轮: 树={1,3}, 最小横切边: 3-6(4) 与 1-4(5)/3-4(5) 比较, 3-6(4)最小 -> 加入 6
// 第3轮: 树={1,3,6}, 最小横切边: 4-6(2) -> 加入 4
// 第4轮: 树={1,3,4,6}, 最小横切边: 2-3(5) 或 1-2(6), 2-3(5)最小 -> 加入 2
// 第5轮: 树={1,2,3,4,6}, 最小横切边: 2-5(3) -> 加入 5
// MST 边集: {1-3(1), 3-6(4), 4-6(2), 2-3(5), 2-5(3)}, 总费用 = 1+4+2+5+3 = 15

#include <stdio.h>
#include <limits.h>

#define N 6
#define INF INT_MAX

// 基于邻接矩阵的 Prim 算法, G 为 n 阶邻接矩阵, 0 表示无边(权记为 INF 处理)
void Prim_MST(int n, int G[N][N]) {
    int lowcost[N];   // lowcost[i]: 树外顶点 i 到当前树的最小边权
    int adjvex[N];    // adjvex[i]: 上述最小边的树内端点
    int inTree[N];    // 标记顶点是否已入树
    int i, j, k, total = 0;

    for (i = 0; i < n; i++) {
        lowcost[i] = G[0][i] ? (G[0][i] > 0 ? G[0][i] : INF) : INF;
        adjvex[i] = 0;
        inTree[i] = 0;
    }
    inTree[0] = 1;          // 从顶点 1(下标 0) 出发
    lowcost[0] = 0;

    printf("Prim MST edges:\n");
    for (i = 1; i < n; i++) {
        int min = INF; k = -1;
        for (j = 0; j < n; j++)            // 在树外顶点中选 lowcost 最小者
            if (!inTree[j] && lowcost[j] < min) {
                min = lowcost[j]; k = j;
            }
        inTree[k] = 1;
        total += min;
        printf("%d - %d : %d\n", adjvex[k] + 1, k + 1, min);
        for (j = 0; j < n; j++)            // 用新顶点 k 松弛树外顶点
            if (!inTree[j] && G[k][j] > 0 && G[k][j] < lowcost[j]) {
                lowcost[j] = G[k][j];
                adjvex[j] = k;             // 必须同步更新来源顶点
            }
    }
    printf("Total cost = %d\n", total);
}

int main(void) {
    /* 输入示例: 按 1-2:6,1-3:1,1-4:5,2-3:5,2-5:3,3-4:5,3-5:6,3-6:4,4-6:2,5-6:6 建邻接矩阵 */
    int G[N][N] = {0};
    int edges[10][3] = {{1,2,6},{1,3,1},{1,4,5},{2,3,5},{2,5,3},{3,4,5},{3,5,6},{3,6,4},{4,6,2},{5,6,6}};
    int e;
    for (e = 0; e < 10; e++) {
        int u = edges[e][0] - 1, v = edges[e][1] - 1;
        G[u][v] = G[v][u] = edges[e][2];
    }
    Prim_MST(N, G);
    return 0;
}
// 复杂度: 朴素 Prim 时间 O(n^2), 空间 O(n^2)(矩阵) + O(n)(辅助数组)
// 堆版 Prim: 邻接表 + 小根堆, 每条边至多触发一次堆调整, 时间 O(elogn), 空间 O(n+e)
// 结论: 稠密图(e~n^2) 用朴素 Prim O(n^2) 或堆版 O(elogn)=O(n^2 log n) 相比朴素更差, 故朴素 Prim 更优;
//       稀疏图(e~n) 用堆版 Prim O(n log n) 或 Kruskal O(eloge) 更优。
```

**【命题人解题思维点拨】**:
系统级破局分析：本题综合考查 MST 的『手工模拟能力』『贪心正确性论证』『编码实现』『复杂度场景分析』四层能力，正对应 408 大题的典型命题结构。关键陷阱点有三：其一，Kruskal 模拟中同权边（2-3 与 1-4 均为 5）的排序次序可任意，但考生必须对每条边给出成环判定的明确理由，阅卷时成环判定是主要采分点；其二，Prim 模拟中第 3 轮易错选 3-4(5) 或 1-4(5) 而遗漏 4-6(2)——加入 6 之后 4-6 才成为横切边，这是『候选边集合随树增长而动态变化』的机制理解陷阱；其三，代码实现中最易丢失 adjvex 的同步更新，导致输出的树边端点错误，这是 408 上机题的高频扣分点。两算法所得 MST 相同的根本原因是：本题各边权中虽然存在等权边（多个 5、多个 6），但每一步贪心选择均满足割性质，且等权边的存在只影响树形态的可能性，实际模拟证明两算法收敛到同一棵树，总权值 15 恒唯一。复杂度场景分析（第 4 问）是 408 命题组长最爱的收尾问：朴素 Prim 与堆版 Prim 的优劣临界点在 e 与 n^2 的关系上，须能写出 O(elogn) 与 O(n^2) 的对比推导，而非死记『Prim 适合稠密图』的结论。
