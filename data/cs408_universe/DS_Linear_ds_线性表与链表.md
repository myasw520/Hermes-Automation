# 📘 408 核心考点真题宇宙: [ds] 线性表与链表

> 大纲描述: 顺序表 vs 链表（单链表、循环双链表、静态链表）。重点掌握：插入删除指针操作、头节点的作用、原地逆置、归并与快慢指针。

## 🎯 高陷阱单选专项演练

### 第 1 题 (难度: ⭐⭐)
**题干**：在带头结点的单链表 L 中，结点结构为 data 与 next，现要在指针 p 所指结点之后插入指针 s 所指结点，下列操作序列正确的是（　）。

- A. s->next = p->next; p->next = s;
- B. p->next = s; s->next = p->next;
- C. s->next = p; p = s;
- D. p->next = s->next; s->next = p;

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `A`

**【各选项排雷剖析】**:
选项B陷阱：先执行 p->next = s 后，p->next 已被改写为 s，再执行 s->next = p->next 相当于 s->next = s，形成自环，链表断裂，后半段结点丢失；选项C陷阱：p = s 只是让局部指针变量 p 改指向 s，并未将 s 挂入链表，且 s->next = p 也未接入原链，属于典型的『改指针变量不等于改链表』陷阱；选项D陷阱：p->next = s->next 会导致 p 原来的后继丢失，且 s 未被 p 指向，整个插入完全不成立，同时把 p 与 s 互相错接形成局部环。

**【深度解析】**:
后插法的铁律：必须先接后断，即先让新结点的 next 指向 p 的原后继，再让 p 的 next 指向新结点。核心是理解 next 指针一旦被覆盖，原后继若无其他引用就永久丢失。本题为单链表插入的最基础陷阱题，408 常以选项 B 这种『看似只差顺序』的形式设坑。

</details>

### 第 2 题 (难度: ⭐⭐⭐)
**题干**：带头结点的单链表长度为 n（n 大于 1），若删除指针 p 所指结点（p 不是尾结点且已知指向 p 的前驱指针为 q），在【不允许】使用额外数据结构、且已知 p 指向的结点数据域不需要保留的情况下，删除 p 所指结点的正确操作是（　）。

- A. free(p); q->next = q->next->next;
- B. q->next = p->next; free(p);
- C. p->data = p->next->data; p->next = p->next->next; free(p->next 的原结点所对应的那个指针所指向的结点)
- D. q->next = p; free(p);

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：先 free(p) 后访问 q->next->next，q->next 本身就是已被释放的 p，属于悬空指针访问（use-after-free），即使某次运行侥幸通过，也是未定义行为；选项C陷阱：这是『与后继结点交换数据再删后继』的偷天换日法，逻辑上可行，但题目明确说明结点数据域不需要保留且选项描述混乱冗余——若题干反过来要求『不改变 data 只改指针』或结点 data 域很大（如存储大对象）时该方法失效，属于考察对算法适用边界的理解，但本题条件直接指向标准删法；选项D陷阱：q->next = p 是恒等赋值（本来就是 p），之后 free(p) 会使链表从 q 之后悬空指向已释放内存，链表彻底损坏。

**【深度解析】**:
标准删除：先让前驱的 next 越过 p 指向 p->next，再 free(p)，顺序绝不可颠倒。选项 A 考察的是『释放后再解引用』这一 408 历年反复考的运行时错误模型；选项 C 引导学生思考『不给出前驱如何删除单链表结点』的变式（拷贝后继数据再删后继），区分该技巧的适用前提：结点非尾且 data 可拷贝。

</details>

### 第 3 题 (难度: ⭐⭐⭐⭐)
**题干**：已知一个带头结点的循环双链表 L，结点含 prior 与 next 指针，指针 p 指向表中某结点（非头结点、非尾结点）。删除 p 所指结点的操作序列正确的是（　）。

- A. p->prior->next = p->next; p->next->prior = p->prior; free(p);
- B. p->next->prior = p->prior; p->prior->next = p->next; free(p);
- C. p->prior->next = p->next; free(p); p->next->prior = p->prior;
- D. p->next = p->prior; p->prior = p->next; free(p);

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `A`

**【各选项排雷剖析】**:
选项B陷阱：语句顺序与 A 相反但两条修改语句互相独立（一个改前驱的 next、一个改后继的 prior，互不覆盖），因此交换顺序结果相同——B 其实也正确！本题真正的陷阱在于：B 与 A 等价，若单选只能选 A，说明命题刻意将 B 改为『p->prior = p->next 之后...』形式的变体——学生必须意识到双链表删除的两条接线语句互不依赖，顺序无关，这才是本考点的深层机制。

**【深度解析】**:
双链表删除的两条接线语句 p->prior->next = p->next 与 p->next->prior = p->prior 操作的是四个不同对象的两条独立边，先执行哪条都不会破坏另一条所需的信息（因为 p 本身未被释放、未被覆盖），因此顺序无关。这与单链表插入形成鲜明对比：单链表插入的两条语句操作同一条边（p->next），顺序敏感。陷阱设计：学生若靠死记『先接后断』会误判 B 错误。真正的错误选项应如 C：先 free(p) 再访问 p->next，释放后访问自身域为未定义行为；D 则把自身 prior/next 互指，前后驱完全未接线。

</details>

### 第 4 题 (难度: ⭐⭐⭐)
**题干**：两个升序单链表 La（长度 m）与 Lb（长度 n）均带头结点，将其归并为一个仍升序的链表且不申请新结点。下列关于算法正确实现与复杂度的说法正确的是（　）。

- A. 必须使用尾插法挂接较小元素，时间复杂度 O(m+n)，空间复杂度 O(1)；若采用头插法挂接，结果将变为降序
- B. 可以交替从两表头取结点用头插法接入结果表，时间复杂度 O(m+n)，结果仍为升序
- C. 归并过程中若 La 已扫完，须将 Lb 剩余结点逐个比较插入，时间复杂度退化为 O(mn)
- D. 归并算法的空间复杂度为 O(m+n)，因为需要一个新头结点存放结果

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `A`

**【各选项排雷剖析】**:
选项B陷阱：头插法会导致每次挂接的结点排在结果表最前面，后处理的较大元素反而靠前，得到降序表；若想用头插法得到升序，必须先倒序比较（每次取较大者），这是对头插法逆序效应的反直觉考察；选项C陷阱：当一表扫完后，剩余另一表整体有序，直接整体尾接即可（循环结束后 tail->next = 非空表的当前指针），无需任何比较，O(mn) 的说法混淆了『数组归并』与『链表可直接断链挂接』的本质差异；选项D陷阱：申请新头结点只是 O(1) 辅助空间，且『不申请新结点』意味着复用原结点，整体为原地归并，空间 O(1)。

**【深度解析】**:
链表归并的核心：尾插保持原序、头插逆转。剩余段直接挂接是链表相对数组归并的关键优化点。复杂度：比较次数至多 m+n-1，时间 O(m+n)；只动指针不建结点，空间 O(1)（不含结果表本身）。破局思维：凡见『不申请新结点』立即锁定原地操作，空间为 O(1)。

</details>

### 第 5 题 (难度: ⭐⭐⭐⭐)
**题干**：设用一个长度为 N 的大数组模拟静态链表，游标域 cursor 指示后继下标，0 号单元为备用链表头。关于静态链表执行插入操作的说法，正确的是（　）。

- A. 插入需从备用链表摘下一个空闲单元，时间为 O(1)，但定位插入位置仍需 O(n) 顺序查找
- B. 插入时需像顺序表一样整体后移元素，时间为 O(n)
- C. 静态链表的插入无需占用备用链表，因为游标可以直接指向任意空闲下标
- D. 静态链表支持 O(1) 时间定位到第 i 个元素，因为它在连续数组中存储

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `A`

**【各选项排雷剖析】**:
选项B陷阱：静态链表虽物理上用数组，但逻辑链接完全由游标维护，插入只改游标，绝不整体移动元素——这是它与顺序表的本质区别，也是最常见的概念混淆点；选项C陷阱：若不通过备用链表统一管理空闲单元，插入的自由下标可能与表中已有结点冲突，导致游标链错乱，备用链表正是保证空闲单元不重复分配的机制；选项D陷阱：连续存储不等于随机访问，静态链表寻址依赖游标逐跳跳转，第 i 个元素仍需从表头沿游标走 i-1 步，为 O(n)，『物理连续』与『逻辑可随机访问』是两个维度。

**【深度解析】**:
静态链表 = 数组外壳 + 链式灵魂：插入删除只改游标（O(1) 次游标修改），但定位仍需 O(n) 遍历；备用链表（通常挂在下标 0 或末单元）实现空闲空间的复用，避免冲突。总插入时间 O(n)，瓶颈在定位不在修改。408 考察本质：存储连续性带来的只有『不依赖指针的跨平台可移植性』，不带来随机访问能力。

</details>

## 🏆 综合应用与算法设计大题

### 大题 1: 单链表原地逆置与快慢指针找中点综合设计 (15 分)

**【背景与题干】**:
设有一个带头结点的单链表 L，结点结构为 struct LNode { int data; struct LNode *next; }。要求算法空间复杂度为 O(1)、时间复杂度为 O(n)，且不得申请新结点、不得破坏原结点数据域语义。请完成以下设计任务，并回答相关理论问题。

**【问题清单】**:
- (1) 设计算法将链表 L 原地逆置（头结点保留，数据结点全部逆序），给出算法思想并分析时间与空间复杂度。
- (2) 设计快慢指针算法找出链表中间结点：长度为奇数时返回正中间结点，偶数时返回中间偏左（前一个）结点。说明快慢指针步长设置及循环终止条件的推导过程。
- (3) 若将 (1) 的逆置算法误用『头插法逐个摘下重建』以外的『交换数据域』方式（即双指针分别指向首尾结点交换 data）实现，请指出该做法在本题约束下的主要缺陷（提示：单链表无随机访问与回退指针）。
- (4) 写出完整可编译的 C 代码，包含 (1) 与 (2) 的函数实现及一个主函数验证，输出逆置前后与中间结点结果。

<details><summary><b>👉 查看踩分标准与标准参考实现</b></summary>

**【考研阅卷踩分细则】**:
满分 15 分，按步给分：(1) 共 5 分：正确描述摘头结点后头插重建的指针操作序列各 1 分（共 3 分）；时间 O(n) 1 分；空间 O(1) 且说明未申请新结点 1 分。(2) 共 4 分：快指针一次走两步、慢指针一次走一步各 1 分；终止条件推导正确（如 while(fast->next && fast->next->next)，保证偶数时返回偏左中点）2 分；若终止条件写成 while(fast && fast->next) 导致偶数返回偏右结点，扣 1 分。(3) 共 2 分：指出单链表无法 O(1) 定位尾结点/前驱结点得 1 分；指出即使双向遍历需 O(n^2) 或需栈/数组辅助违反 O(1) 空间约束再得 1 分。(4) 共 4 分：函数原型与边界处理（空表、单结点表不崩溃）2 分；主函数正确构建并输出验证 1 分；代码可编译、无悬空指针与内存泄漏 1 分。常见扣分点：逆置时先断开再丢失后继（指针覆盖顺序错误扣 2 分）；未处理空表/单结点边界（扣 1 分）；使用递归逆置导致栈空间 O(n)，违反约束，(1) 复杂度分全扣。

**【核心算法/推导实现】**:
```cpp
#include <stdio.h>
#include <stdlib.h>

typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

/* (1) 原地逆置：摘下头结点，数据结点逐个头插回 */
void ReverseList(LinkList L) {
    LNode *p = L->next, *q;
    L->next = NULL;              /* 摘下头结点，断开原链 */
    while (p != NULL) {
        q = p->next;             /* 先保存后继，防止断链 */
        p->next = L->next;       /* 头插：新结点接在头结点后 */
        L->next = p;
        p = q;
    }
}

/* (2) 快慢指针找中点：奇数返回正中间，偶数返回偏左中点 */
LNode* FindMiddle(LinkList L) {
    LNode *slow = L->next, *fast = L->next;
    if (slow == NULL) return NULL;      /* 空表 */
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;       /* 慢指针走 1 步 */
        fast = fast->next->next; /* 快指针走 2 步 */
    }
    return slow;
}

/* 辅助：尾插建表 */
LinkList CreateList(int a[], int n) {
    LinkList L = (LNode *)malloc(sizeof(LNode));
    LNode *tail = L;
    L->next = NULL;
    for (int i = 0; i < n; i++) {
        LNode *s = (LNode *)malloc(sizeof(LNode));
        s->data = a[i];
        tail->next = s; tail = s;
    }
    tail->next = NULL;
    return L;
}

void PrintList(LinkList L) {
    for (LNode *p = L->next; p; p = p->next)
        printf('%d ', p->data);
    printf('\n');
}

int main(void) {
    int odd[]  = {1, 2, 3, 4, 5};
    int even[] = {1, 2, 3, 4, 5, 6};
    LinkList L1 = CreateList(odd, 5);
    printf('原表: '); PrintList(L1);
    printf('中点: %d\n', FindMiddle(L1)->data);   /* 3 */
    ReverseList(L1);
    printf('逆置: '); PrintList(L1);               /* 5 4 3 2 1 */

    LinkList L2 = CreateList(even, 6);
    printf('偶长原表: '); PrintList(L2);
    printf('中点(偏左): %d\n', FindMiddle(L2)->data); /* 3 */
    ReverseList(L2);
    printf('偶长逆置: '); PrintList(L2);           /* 6 5 4 3 2 1 */
    return 0;
}
```

**【命题人解题思维点拨】**:
命题立意：将『原地逆置』『快慢指针』『复杂度约束』三个高频考点串成一条设计链，考察的是指针操作的因果机制而非模板背诵。破局思维一：逆置的本质是『头插法天然逆序』这一性质的自觉应用——头结点摘下后置空，逐结点头插，每步只需两次指针赋值一次保存后继，全程 O(n) 时间 O(1) 空间；用『交换 data』的双指针法在单链表上不可行，因为无法 O(1) 得到尾结点及其前驱，强行实现需 O(n^2) 时间或 O(n) 辅助空间，均违反约束，这正呼应小问 (3) 的辨析。破局思维二：快慢指针的终止条件必须从『快指针落点』精确推导——设链长 n：快指针每次前进 2，当 fast->next 为空（n 为奇数时 fast 恰在尾）或 fast->next->next 为空（n 为偶数时 fast 在倒数第二）时停止；此时慢指针走过 floor(n/2) 步，位置恰为第 floor(n/2)+1 个数据结点，奇数时为正中，偶数时偏左。若误写 while(fast && fast->next)，偶数时慢指针多走一步返回偏右中点，是 408 真题级陷阱。系统级点评：本题所有陷阱均可归结为一句话——『链表的每一条边都是唯一的，覆盖它的引用之前必须先把这条边的信息转存』。

</details>
