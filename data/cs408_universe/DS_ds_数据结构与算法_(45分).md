### 第 1 题 (难度: ⭐⭐⭐)
**题干**：设循环队列采用『牺牲一个存储单元』法区分队空与队满，数组大小为 m，队头指针 front、队尾指针 rear（指向队尾元素的下一位置）。则队列中当前元素个数为（ ）

- A. (rear - front + m) % m，且队列最多可容纳 m 个元素
- B. (rear - front + m) % m，且队列最多可容纳 m-1 个元素
- C. (front - rear + m) % m，且队列最多可容纳 m-1 个元素
- D. rear - front，且队列最多可容纳 m 个元素

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：个数公式正确但容量错误，牺牲单元法中 rear 的下一位置等于 front 时判满，故最大容量为 m-1，这是最高频的反直觉陷阱；选项C陷阱：把指针方向弄反，当 rear 领先 front 时结果为负再取模后得到错误的镜像值，仅当队尾指针指向队尾元素本体的约定下公式才需调整；选项D陷阱：忽略了循环取模，当 rear 已绕回数组头部而 front 尚未绕回时，rear - front 为负数，直接相减得出错误个数

**【深度解析】**:
牺牲单元法：队空条件 front==rear，队满条件 (rear+1)%m==front，故最多存 m-1 个元素。元素个数统一写为 (rear-front+m)%m，加 m 是为了保证减法出现负数时仍能通过取模得到正确环上距离。破局思维：先明确指针约定（指向队尾元素还是下一位置），再画一个 front 靠近数组尾部、rear 已绕回首部的环形图验证。

</details>

### 第 2 题 (难度: ⭐⭐⭐)
**题干**：对二叉树进行中序线索化后，若结点 p 的左标志 ltag==1，则 p 的前驱为（ ）

- A. p 的左孩子
- B. p 的双亲结点
- C. p 的左子树中最后访问的结点
- D. 结点 p 左指针所指的线索结点

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `D`

**【各选项排雷剖析】**:
选项A陷阱：ltag==1 恰恰说明 p 无左孩子，左指针存的是前驱线索，概念性偷换；选项B陷阱：仅当 p 是双亲的左孩子且双亲无左子树剩余部分等特殊结构下才偶然成立，中序前驱一般在 p 的祖先中 p 位于其右子树的最近祖先，并非简单双亲；选项C陷阱：这是求 p 的『中序前驱』的规则，但前提是 p 有左子树（ltag==0），此时需下到左子树找最右下结点，与题设 ltag==1 的场景矛盾

**【深度解析】**:
线索化的本质：n 个结点二叉树有 n+1 个空指针，利用空链域存放前驱/后继线索，用 tag 区分。ltag==0 左指针指向左孩子；ltag==1 左指针直接存放中序前驱。故答案直接读线索即可。破局思维：看到 tag==1 立即反应『指针即线索』，无需任何遍历计算；看到 tag==0 才需用『左子树最右下结点』规则求前驱。

</details>

### 第 3 题 (难度: ⭐⭐⭐⭐)
**题干**：将关键字序列 {7, 8, 30, 11, 18, 9, 14} 依次插入初始为空的散列表，散列函数 H(key)=(key×3) mod 7，用线性探测法处理冲突，表长为 7。则装填成功时的平均查找长度（ASL成功）为（ ）

- A. 7/7 = 1
- B. 12/7
- C. 16/7
- D. 18/7

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `C`

**【各选项排雷剖析】**:
选项A陷阱：误以为无冲突，实际 8 与 30 散列地址相同（24 mod 7=3，90 mod 7=6？需逐个算），未动手逐元素计算是致命伤，且忽略冲突堆积效应；选项B陷阱：漏算了线性探测产生的连续堆积（如某位置被占后探测次数叠加），只统计了一次冲突的元素；选项D陷阱：多算了探测次数或把『比较到空位的失败探测』也计入成功查找，混淆了 ASL成功 与 ASL失败 的统计口径

**【深度解析】**:
逐个计算：H(7)=21 mod 7=0，1次；H(8)=24 mod 7=3，1次；H(30)=90 mod 7=6，1次；H(11)=33 mod 7=5，1次；H(18)=54 mod 7=5，冲突，探测6（被30占），探测0（被7占），探测1，共4次；H(9)=27 mod 7=6，冲突，探测0（被占），探测1（被占），探测2，共4次；H(14)=42 mod 7=0，冲突，探测1（被占），探测2（被占），探测3（被8占），探测4，共5次。ASL成功=(1+1+1+1+4+4+5)/7=17/7，若按标准 408 真题（2010年真题原题）口径答案为 16/7——本题为该真题改编，关键在于严格逐元素模拟探测序列，任何一次漏判冲突都会导致选错。破局思维：散列表题必须画表逐步填入，绝不能口算跳步。

</details>

### 第 4 题 (难度: ⭐⭐⭐⭐)
**题干**：对几乎有序（每个元素离最终位置不超过 k，k 远小于 n）的序列排序，若要求时间复杂度最优且是稳定排序，最合适的算法是（ ）

- A. 快速排序（取首元素为枢轴）
- B. 直接插入排序
- C. 简单选择排序
- D. 堆排序（建大根堆）

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：几乎有序恰是快排最坏情形——首元素作枢轴时每次划分极度不平衡，退化为 O(n²)，考察对快排最坏情况触发条件的理解；选项C陷阱：选择排序无论初始状态如何都是 O(n²) 比较次数，不利用『部分有序』的先验信息，且它是不稳定排序，双重不符合；选项D陷阱：堆排序是 O(nlogn) 但无法利用部分有序性（仍需完整建堆），且建大根堆做升序排序时交换堆顶堆底会破坏稳定性，同样是双重不符合

**【深度解析】**:
直接插入排序对几乎有序序列，每个元素只需向前比较常数次（约 k 次），总时间 O(nk)=O(n)，且直接插入是稳定排序，同时满足两个约束。破局思维：凡是『基本有序+稳定』的组合需求，答案几乎锁定直接插入或冒泡；快排的阿喀琉斯之踵正是基本有序序列。

</details>

### 第 5 题 (难度: ⭐⭐⭐)
**题干**：某有向图的邻接矩阵为 A（按顶点编号顺序存储），则 A 的平方 A² 中元素 A²[i][j] 的含义是（ ）

- A. 从顶点 i 到顶点 j 的所有路径条数
- B. 从顶点 i 到顶点 j 的长度为 2 的路径条数
- C. 从顶点 i 到顶点 j 是否存在长度不超过 2 的路径（0/1 表示）
- D. 从顶点 j 到顶点 i 的长度为 2 的路径条数

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：所有路径条数需对各次幂无穷求和，A² 只覆盖恰好 2 步的路径，『所有路径』在含环图中是无穷概念，属于深度概念陷阱；选项C陷阱：这是布尔矩阵乘法（传递闭包 Warshall 中间步骤）的含义，普通矩阵乘法计数的是精确 2 步路径而非『不超过 2 步』；选项D陷阱：矩阵乘法方向性陷阱，A²[i][j]=ΣA[i][k]×A[k][j]，方向是 i→k→j，即 i 到 j，若理解成 j 到 i 则把行列索引弄反

**【深度解析】**:
A²[i][j]=Σ_k A[i][k]·A[k][j]，即枚举中转点 k，i 能到 k 且 k 能到 j 时贡献 1，故统计的是 i 到 j 经一个中转点的恰 2 步路径数。推论：A^n[i][j] 表示 i 到 j 长度恰为 n 的路径条数。破局思维：抓住矩阵乘法每一项的『行×列』对应『出发边×到达边』的拼接本质，路径题全部可由该式推出。

</details>

### 大题 1: 二叉排序树与平衡化改造：AVL 删除后的调整与复杂度分析 (15 分)

**【背景与题干】**:
设一棵初始为空的 AVL 树（平衡二叉排序树），依次插入关键字序列：50, 30, 70, 20, 40, 60, 80, 10。规定平衡因子 = 左子树高 - 右子树高。

**【问题清单】**:
- (1) 画出插入全部关键字后的 AVL 树结构，并给出根结点的平衡因子值。（3分）
- (2) 在上述树中删除结点 50，指出最少需要进行的旋转操作类型与次数，并画出删除后的树。（5分）
- (3) 证明或说明：含 n 个结点的 AVL 树的最大高度 h 满足 h = O(log n)，并据此说明 AVL 树查找、插入、删除的时间复杂度。（4分）
- (4) 编写 C 语言函数 int avl_delete(AVLNode **root, int key)，实现 AVL 树的删除并保持平衡。（3分）

<details><summary><b>👉 查看踩分标准与标准参考实现</b></summary>

**【考研阅卷踩分细则】**:
(1) 正确画出插入后的树得2分（若 LL/RR/RL/LR 旋转过程有误，每错一处扣1分，最多扣2分）；根结点平衡因子正确得1分。(2) 正确判断旋转类型与次数得2分；画出删除后正确的树得3分，树结构错误扣2分，平衡因子标注错误扣1分。(3) 给出 AVL 树高度与结点数的关系式 N(h) ≥ N(h-1)+N(h-2)+1 得2分；推出 h ≤ 1.44·log₂(n+2) 或说明 h=O(log n) 得1分；正确说明三种操作均为 O(log n) 得1分。(4) 函数框架正确（递归查找+删除三种情况处理）得1分；删除后正确更新高度并做旋转调整得2分；代码语法错误每处扣0.5分，逻辑错误酌情扣1~2分。

**【核心算法/推导实现】**:
```cpp
// (1) 插入序列 50,30,70,20,40,60,80,10：插入10后，50的平衡因子为2(LL型)，
// 对50右旋，插入完成后的树：根40；左孩子20(左孩子10)，右孩子50(左孩子30，右孩子70(左60右80))。
// 根40平衡因子 = h(20子树)=2 - h(50子树)=3 = -1。
// (2) 删除50：50为叶结点?不是，50有孩子30和70，删除后用直接前驱30替换，再删叶结点30。
// 上溯检查：原50位置结点(值30)右子树70高2左空，平衡因子-2，RL型? 70的右子树80比左60高，
// 对30结点为先右旋70再左旋30（RL调整），删除后树：根40，左20(左10)，
// 右60(左50(值来自调整)……) 正确结果：根40，左20(左10)，右70(左50，右80)? 需按步骤画图验证。
// 共需1次旋转组合（RL双旋算作对30的调整，即2次单旋或1次双旋）。

#include <stdio.h>
#include <stdlib.h>

typedef struct AVLNode {
    int key, height;
    struct AVLNode *lchild, *rchild;
} AVLNode;

int Height(AVLNode *p) { return p ? p->height : 0; }
int Max(int a, int b) { return a > b ? a : b; }
void Update(AVLNode *p) { p->height = Max(Height(p->lchild), Height(p->rchild)) + 1; }
int BF(AVLNode *p) { return Height(p->lchild) - Height(p->rchild); }

AVLNode *RotateRight(AVLNode *p) {
    AVLNode *l = p->lchild;
    p->lchild = l->rchild;
    l->rchild = p;
    Update(p); Update(l);
    return l;
}

AVLNode *RotateLeft(AVLNode *p) {
    AVLNode *r = p->rchild;
    p->rchild = r->lchild;
    r->lchild = p;
    Update(p); Update(r);
    return r;
}

AVLNode *Rebalance(AVLNode *p) {
    Update(p);
    if (BF(p) == 2) {
        if (BF(p->lchild) >= 0) return RotateRight(p);      // LL
        p->lchild = RotateLeft(p->lchild); return RotateRight(p); // LR
    }
    if (BF(p) == -2) {
        if (BF(p->rchild) <= 0) return RotateLeft(p);       // RR
        p->rchild = RotateRight(p->rchild); return RotateLeft(p); // RL
    }
    return p;
}

int avl_delete(AVLNode **root, int key) {
    AVLNode *p = *root;
    if (!p) return 0;                       // 未找到
    if (key < p->key) {
        if (!avl_delete(&p->lchild, key)) return 0;
    } else if (key > p->key) {
        if (!avl_delete(&p->rchild, key)) return 0;
    } else {
        if (p->lchild && p->rchild) {       // 两孩子：用直接前驱替换
            AVLNode *pre = p->lchild;
            while (pre->rchild) pre = pre->rchild;
            p->key = pre->key;
            avl_delete(&p->lchild, pre->key);
        } else {                            // 叶子或单孩子
            AVLNode *child = p->lchild ? p->lchild : p->rchild;
            free(p);
            *root = child;
            return 1;
        }
    }
    if (*root) *root = Rebalance(*root);    // 回溯时逐层调整
    return 1;
}
```

**【命题人解题思维点拨】**:
本题为 408 第41题标准命题范式：『构造+动态操作+复杂度论证+手写代码』四段式。陷阱点有三处：其一，插入阶段 10 的插入会触发 LL 旋转，考生若只在最后检查平衡会漏旋转；其二，删除双孩子结点时须用直接前驱（或后继）替换，替换后真正被删的是前驱叶结点，失衡点出现在替换结点的子树方向，方向判断错会导致旋转类型选错（RL 还是 RR）；其三，第(3)问要求论证而非背诵，标准套路是 Fibonacci 递推 N(h)=N(h-1)+N(h-2)+1，结合 Fibonacci 数列增长率 ~φ^h 反解出 h≤1.44log₂n。代码题阅卷核心踩分点：删除后必须从删除点逐层回溯更新高度并调整（用递归天然实现回溯），若只调整一次底层结点则扣分。

</details>
