## 🎯 高陷阱单选专项演练

### 第 1 题 (难度: ⭐⭐⭐⭐)
**题干**：单链表可能存在环，head 为头指针。快指针 fast 每次走两步，慢指针 slow 每次走一步，两者从 head 同时出发。若链表有环，则两指针必在环内相遇。下列关于该结论正确性的分析，哪一项是准确的？

- A. 该结论成立的前提是环内结点数为奇数，若环长为偶数，fast 可能永远跳过 slow 而无法相遇
- B. 该结论无条件成立：进入环后，每走一次 fast 相对 slow 前进 1 步，相对距离每轮缩小 1，故必然追上且不会跳过
- C. 该结论成立的前提是 fast 与 slow 从同一结点出发，若初始相距奇数步则永远无法相遇
- D. 该结论仅在环上无『尾巴』（head 直接连入环）时成立，若有尾巴则 fast 会先绕环多圈导致永远错开

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：利用考生对『步长为2会跳过』的直觉恐惧，实际上进入环后是相对速度为1的追逐问题，相对距离模环长递减，与环长奇偶无关，每轮恰好缩小1不可能跳过；选项C陷阱：混淆了『相遇点判定』与『能否相遇』，从同一出发点即使有尾巴，fast 先入环后仍在环内以相对速度1逼近 slow，必然相遇；选项D陷阱：尾巴只影响 fast 需绕多少圈才追上（影响时间），不影响能否相遇，fast 绕圈时 slow 也在环内移动，相对位移仍为每轮1。

**【深度解析】**:
破局关键：将问题转化为相对运动。进入环后，以 slow 为参考系，fast 每轮相对前移 1 个结点。设环长为 L，则相对距离 d 每轮做 (d+1) mod L 的变化（追及视角下距离每轮减1），d 从某初始值递减到 0，最多 L 轮内必相遇，绝无『跨过』一说——因为每轮只减 1，不会从 1 直接跳到 L-1。这正是 Floyd 判圈法保证 O(1) 空间判环正确的根本原因。时间复杂度 O(n)：slow 入环前最多走 n 步，入环后最多再走 L 步即被追上，而 fast 总步数不超过 slow 的两倍。

</details>

### 第 2 题 (难度: ⭐⭐⭐⭐⭐)
**题干**：设链表有 n 个结点（n≥2），使用 Floyd 判圈法判环。相遇后，将一指针 p 重新置于 head，另一指针 q 留在相遇点，两指针每次各走一步，再次相遇的结点即环的入口。下列哪项是该结论的核心推导依据？

- A. head 到环入口距离 a，入口到相遇点距离 b，环长 L，相遇时 slow 走了 a+b，由 2(a+b)=a+b+kL 推得 a=kL-b，故从 head 走 a 步与从相遇点走 kL-b 步到达同一点
- B. 相遇点必为环入口，因为 fast 速度是 slow 的两倍，首次相遇恰好发生在 slow 刚进入环的瞬间
- C. 由 fast 绕环圈数必为偶数，可推出 a 与 b 必然相等，故两指针同步前进即相遇于入口
- D. head 到入口的距离 a 必等于入口到相遇点的距离 b，这是由 fast 每轮相对 slow 前进 1 步的对称性直接决定的

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `A`

**【各选项排雷剖析】**:
选项B陷阱：极端反直觉错误，相遇点一般不是入口，slow 入环时 fast 已在环内某处，二者在环内某点相遇，位置取决于 a、b、L 的具体数值；选项C陷阱：伪造『绕环圈数为偶数』这一不存在的不变量，且由它推不出 a=b，属于用伪规律包装的错误推理；选项D陷阱：a=b 仅在极特殊数值下成立（如 a=2,b=2），并非一般规律，命题者利用考生希望『对称美观』的心理设置陷阱。

**【深度解析】**:
标准推导：设 head 到入口距离 a，入口到相遇点距离 b，环长 L。相遇时 slow 走 a+b 步（注意 slow 入环后到相遇点最多走一圈，这是不等式 2(a+b)=a+b+kL 中 k≥1 且 slow 未被多绕圈的隐含约束），fast 走 2(a+b) 步，且 fast 比 slow 多走的都是整数圈，故 2(a+b)-a+b=a+b... 严格地：2(a+b)=a+b+kL，即 a+b=kL，a=kL-b。这说明从 head 出发走 a 步到达入口，等价于从相遇点出发走 kL-b 步（即先沿环走若干整圈再退回 b），二者路径终点重合。因此 p 从 head、q 从相遇点同步每次走一步，必然在入口首次相遇。若 k=1 则 a=L-b 恰好互补；若 k>1 则 q 会先绕环 k-1 圈，不影响结论。

</details>

### 第 3 题 (难度: ⭐⭐⭐⭐)
**题干**：求单链表的中间结点：要求 n 为奇数时返回正中间结点，n 为偶数时返回『中间偏后』的第 n/2+1 个结点。采用快慢指针法（fast 每次两步、slow 每次一步，fast 从 head 出发），下列循环条件与出发方式中正确的是？

- A. fast 与 slow 都从 head 出发，循环条件为 while(fast != NULL && fast->next != NULL)，循环内 fast 前进两步
- B. fast 从 head 出发、slow 从 head 出发，循环条件为 while(fast->next != NULL && fast->next->next != NULL)，循环内 fast 前进两步
- C. fast 从 head->next 出发、slow 从 head 出发，循环条件为 while(fast != NULL && fast->next != NULL)
- D. fast 与 slow 都从 head 出发，循环条件为 while(fast->next != NULL)，循环内 fast 前进两步

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：该写法在 n 为偶数时返回的是『中间偏前』的第 n/2 个结点，与题目要求的偏后不一致，属于最经典的边界方向混淆；选项C陷阱：改变 fast 初出发点等效于让 fast 领先一步，结果同样变成返回偏前的中点，且 fast 从 head->next 出发在 n=1（head->next 为 NULL）时会解引用空指针；选项D陷阱：循环条件只检查 fast->next 而不检查 fast->next->next，执行 fast=fast->next->next 时可能对 NULL 解引用，程序崩溃，属于典型的『少判一层』空指针陷阱。

**【深度解析】**:
设结点编号从 1 开始。方案B中，循环结束时 fast 停在最后一个结点（n 奇）或倒数第一个 NULL 前（n 偶），slow 走的步数 = (fast 领先步数)/2。n 为奇数时 slow 走 (n-1)/2 步，到达第 (n+1)/2 个结点，即正中间；n 为偶数时 slow 走 n/2 步，到达第 n/2+1 个结点，即偏后中点，恰好满足题意。而方案A（fast 每轮先判 next 再走两步的标准写法）中 n 偶数时 slow 只走 n/2-1 步，落在第 n/2 个结点。破局口诀：『判两层返回偏后中点，判一层（且判到 fast 非空）返回偏前中点』。同时必须养成先判 fast 非空再判 fast->next 非空的短路顺序，防止空指针解引用。

</details>

### 第 4 题 (难度: ⭐⭐⭐⭐)
**题干**：关于找链表倒数第 k 个结点（k 从 1 计，保证 1≤k≤n）的双指针方案，p1 先走 k 步后 p1、p2 同步走，直到 p1 为 NULL。下列分析正确的是？

- A. p1 先走 k-1 步即可，这样 p1 到达 NULL 时 p2 恰好指向倒数第 k 个结点，且节省一次循环
- B. p1 先走 k 步，之后当 p1 走到 NULL 时 p2 恰好指向倒数第 k 个结点；若先走 k-1 步，p1 停在尾结点时循环结束，p2 会指向倒数第 k+1 个结点
- C. p1 应先走 k+1 步，以补偿 p1 走到 NULL 判定时多消耗的一步
- D. 先走几步不影响结果，只要两指针间距为常数，最终 p2 与 p1 同步到达链表尾部附近，位置由 n 与 k 共同决定

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：差一错误（off-by-one）经典陷阱，先走 k-1 步时 p1 与 p2 间距为 k-1，p1 到 NULL 时 p2 前进了 n-(k-1) 步，指向倒数第 k-1 个结点（并非选项所称倒数第 k 个），且此说法与自身后续『节省循环』的逻辑自相矛盾；选项C陷阱：过度补偿，先走 k+1 步后 p2 将停在倒数第 k+1 个结点，恰好是删除倒数第 k 个结点时需要的『前驱』位置，命题者故意诱导考生混淆『找结点』与『删结点找前驱』两种需求；选项D陷阱：模糊化处理的诡辩选项，间距决定了 p2 的最终落点，间距不同结果必然不同，『不影响结果』直接错误。

**【深度解析】**:
核心不变量：同步阶段中，p2 始终落后 p1 恰好 k 个结点。p1 从第 k+1 个结点（先走 k 步后）出发走到 NULL 共走 n-k 步，p2 从 head 同步走 n-k 步，到达第 n-k+1 个结点，即倒数第 k 个结点。验证边界：k=n 时 p1 先走 n 步直接到 NULL，循环体不执行，p2=head，正确；k=1 时 p2 停在尾结点，正确。工程陷阱：若题目未保证 k≤n，先走 k 步的循环中必须判 p1 是否中途变 NULL，否则解引用空指针；若需求是『删除倒数第 k 个』，通常改用先走 k+1 步找前驱，或引入虚拟头结点统一处理删除 head 的边界。

</details>

### 第 5 题 (难度: ⭐⭐⭐⭐)
**题干**：对含大量重复关键字的序列使用三路划分 quicksort（小于区 | 等于区 | 大于区）。设数组元素全相等，传统二路 Partition（以首元素为基准，小于等于基准的都划到左侧）与三路划分的时间复杂度分别为？

- A. 二路 Partition：O(nlogn)；三路划分：O(nlogn)
- B. 二路 Partition：O(n^2)；三路划分：O(n)
- C. 二路 Partition：O(n)；三路划分：O(n^2)
- D. 二路 Partition：O(nlogn)；三路划分：O(n^2)

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：惯性套用快排平均复杂度 O(nlogn)，完全忽略全相等这一最坏退化输入，属于『背模板不审题』的致命失误；选项C陷阱：把两个算法的结论正好写反，混淆了二路划分在重复元素下退化、三路划分恰好吸收重复元素的优劣关系；选项D陷阱：一半对一半错更具迷惑性，二路 O(nlogn) 错误而三路 O(n^2) 荒谬，三路划分单趟就是线性扫描，绝不可能是平方级。

**【深度解析】**:
二路 Partition（Hoare/Lomuto 的常见写法，等于基准的元素划入一侧）在元素全相等时，每趟划分极度不平衡：所有元素都进入『小于等于』一侧，递归区间每次只缩小 1 个元素（基准），需递归 n 层，每层 O(n) 扫描，总时间 O(n^2)。三路划分（Dutch National Flag）维护 lt、gt、i 三个边界，等于基准的元素直接留在中段不再参与递归，全相等时一趟扫描后中段覆盖整个数组，递归立即终止，总时间 O(n)。命题陷阱点评：本题考察考生是否理解三路划分的诞生动机——正是为了解决重复元素大量存在时二路快排的退化问题；同时提醒：若使用二路划分的『两端向中间交换』写法，全相等时表现可能好于此处描述，故题干明确锁定『小于等于划左侧』的 Lomuto 型写法，审题时必须锁定前提。

</details>

## 🏆 综合应用与算法设计大题

### 大题 1: 链环定位与三路划分综合设计题 (15 分)

**【背景与题干】**:
某系统的任务队列用单向链表组织，因并发修改缺陷，链表可能意外成环。请设计算法完成如下需求：给定单链表头结点指针 head（结点含 int val 与 next 指针，结点数可达 10^6，内存紧张，禁止使用哈希表等额外线性空间）。(a) 判断链表是否带环；(b) 若带环，返回环入口结点指针，并将环『剪开』：即修改入口结点前驱（环内最后一个指向入口的结点）的 next 置为 NULL，使链表恢复为普通单链表（注意入口可能在 head 处）；(c) 剪开后，对链表结点值序列执行三路划分：给定基准值 pivot，将链表重排为『小于 pivot 的结点段 → 等于 pivot 的结点段 → 大于 pivot 的结点段』，要求保持各段内结点相对次序不变（稳定），只允许修改 next 指针、O(1) 额外空间、一趟扫描完成。要求给出完整可编译 C 代码与复杂度分析。

**【问题清单】**:
- (1) 说明判环与找环入口的算法原理，推导 head 到入口距离与相遇点位置的数学关系，并分析时间与空间复杂度。
- (2) 说明如何在 O(1) 空间内找到入口结点的前驱并安全剪环，特别讨论环入口就是 head 的边界情形。
- (3) 给出三路划分的链表实现思路（三个虚拟段头尾指针），证明一趟扫描与稳定性如何同时保证，并给出总复杂度。
- (4) 写出完整 C 代码，包含 hasCycleAndCut、partitionList 两个函数及必要辅助函数。

<details><summary><b>👉 查看踩分标准与标准参考实现</b></summary>

**【考研阅卷踩分细则】**:
总分15分。(1) 4分：正确给出 2(a+b)=a+b+kL 及 a=kL-b 推导得2分；正确说明双指针从 head 与相遇点同步单步走必遇入口得1分；复杂度 O(n) 时间、O(1) 空间各0.5分。(2) 3分：利用 fast 停在相遇点、slow 继续走到 next 指回入口的结点即为前驱的思路得2分（等价方案：从相遇点同步走到再次指向入口者亦可）；入口为 head 时正确处理（前驱即环内最后一个结点）得1分，遗漏此边界扣1分。(3) 4分：三虚拟段 small/equal/greater 各配头尾指针得2分；一趟扫描 O(n)、尾结点 next 置 NULL、各段拼接顺序正确各得0.5分、0.5分、1分；说明每结点只被访问一次故各段内相对次序不变（稳定）得1分。(4) 4分：判环循环条件与空指针防护正确1分；剪环正确1分；三路划分指针操作无内存错误（尤其拼接后尾指针置空）1分；代码整体可编译、风格规范1分。凡出现解引用空指针风险、忘记将链尾 next 置 NULL、使用额外数组/哈希者，相应得分点记0分。

**【核心算法/推导实现】**:
```cpp
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int val;
    struct Node *next;
} Node;

/* (a)(b) 判环、找入口并剪环。
   返回值：带环时返回环入口结点；不带环返回 NULL。 */
Node* hasCycleAndCut(Node *head) {
    if (head == NULL || head->next == NULL) return NULL;
    Node *slow = head, *fast = head;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) break;          /* 相遇 */
    }
    if (fast == NULL || fast->next == NULL) return NULL; /* 无环 */

    /* 找入口：p 从 head，q 从相遇点，同步单步走 */
    Node *p = head, *q = slow;
    while (p != q) { p = p->next; q = q->next; }
    Node *entry = p;

    /* 找入口的前驱：从 entry 沿环走一圈，next 指向 entry 者即前驱。
       边界：入口为 head 时，前驱是环内最后一个结点，本循环同样覆盖。 */
    Node *prev = entry;
    while (prev->next != entry) prev = prev->next;
    prev->next = NULL;                     /* 剪环 */
    return entry;
}

/* (c) 三路稳定划分：一趟扫描，O(1) 额外空间。
   返回新链表头。 */
Node* partitionList(Node *head, int pivot) {
    Node sDummy, eDummy, gDummy;          /* 三段虚拟头 */
    Node *sTail = &sDummy, *eTail = &eDummy, *gTail = &gDummy;
    sDummy.next = eDummy.next = gDummy.next = NULL;

    for (Node *cur = head; cur != NULL; cur = cur->next) {
        if (cur->val < pivot)      { sTail->next = cur; sTail = cur; }
        else if (cur->val == pivot){ eTail->next = cur; eTail = cur; }
        else                       { gTail->next = cur; gTail = cur; }
    }
    sTail->next = eDummy.next;            /* 小于段 接 等于段 */
    eTail->next = gDummy.next;            /* 等于段 接 大于段 */
    gTail->next = NULL;                   /* 关键：新链尾置空 */
    return sDummy.next != NULL ? sDummy.next
         : (eDummy.next != NULL ? eDummy.next : gDummy.next);
}

/* 复杂度：判环+找入口 O(n) 时间 O(1) 空间；
   找前驱沿环一圈 O(n)；三路划分一趟 O(n)。总计 O(n) 时间、O(1) 空间。 */
```

**【命题人解题思维点拨】**:
系统级破局分析：本题将三大手撕神技串成一条工程链路——先用 Floyd 判圈法在 O(1) 空间判环并定位入口（数学核心是 a=kL-b），再利用『入口在环上唯一、其前驱即环内唯一指向入口的结点』这一结构性质剪环，天然覆盖了入口即 head 的边界情形（此时前驱是环内最后一个结点，沿环走一圈的循环依然正确，无需特判 if）。三路划分采用三虚拟头尾指针技术：一趟扫描中每个结点只被尾插到唯一确定的段，尾插保证段内相对次序不变（稳定性），最后按序拼接并把新链尾置 NULL（遗漏置空是本题最大的隐藏扣分点，会造成野指针与死循环）。命题陷阱点评：考生常见错误包括——用哈希表记访问结点判环（违反空间限制直接扣分）；剪环时从 head 找前驱（有环时 head 到入口的前驱根本不在链上，逻辑错误）；三路划分后忘记 gTail->next=NULL；以及判环循环中先走后判导致漏判两结点小环。所有陷阱都指向同一命题思想：边界条件与不变量的严格性。
