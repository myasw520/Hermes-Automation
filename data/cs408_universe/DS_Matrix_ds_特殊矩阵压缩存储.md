## 🎯 高陷阱单选专项演练

### 第 1 题 (难度: ⭐⭐⭐⭐)
**题干**：设 n 阶对称矩阵 A 的下三角部分（含主对角线）按行优先存入一维数组 SA，SA[0] 存放 a11。若已知某元素 aij（i≥j）存放于 SA[k]，现将同一矩阵改为按行优先存储上三角部分（含主对角线），元素 aij（i≤j）存放于数组 SB 的下标为 k'，则 k 与 k' 的关系描述最准确的是（　）。

- A. k = i(i-1)/2 + j - 1，k' = j(j-1)/2 + i - 1，二者恰好关于行列互换对称
- B. k' = k，因为对称矩阵中 aij = aji，两个存储方案覆盖的是同一组下三角位置集合
- C. k' 与 k 无必然关系，仅当 i = j 或 i + j = n + 1 时才相等
- D. k' = n(n+1)/2 - 1 - k，即上下三角存储互为逆序排列

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `A`

**【各选项排雷剖析】**:
选项B陷阱：混淆了『矩阵元素值相等』与『存储下标相等』，aij=aji 只保证语义等价，两个数组是独立压缩方案，下标无恒等关系；选项C陷阱：凭直觉认为只有对角线或副对角线才重合，实际上任意 aij 在两个方案中都各有一个下标，只是没有固定函数关系式上的巧合，该说法以偏概全制造错觉；选项D陷阱：误把逆序排列的倒序公式套上来，压缩存储是顺序映射而非倒序堆叠，且 n(n+1)/2-1-k 对应的是完全倒排，与按行优先上三角映射 i、j 互换的本质不符。

**【深度解析】**:
下三角按行优先：aij 之前有 i-1 个完整行，共 1+2+...+(i-1)=i(i-1)/2 个元素，再加本行 j 个元素（列号 1..j），故 k = i(i-1)/2 + j - 1。上三角按行优先时行 i 的长度为 n-i+1，但元素 aij（i≤j）之前的行长度为 n, n-1, ..., n-i+2，共 (i-1)n - (i-1)(i-2)/2，加上本行前面 j-i 个元素，化简后恰为 j(j-1)/2 + i - 1（可代 i=1, j=1 验证得 0）。两个公式形式上正是 i、j 互换，选 A。破局思维：压缩存储题先写『前面满行数 + 本行前列数』再统一减 1，切勿背诵公式后乱套。

</details>

### 第 2 题 (难度: ⭐⭐⭐)
**题干**：将 n 阶下三角矩阵（不含对角线上方的常数 c 存储）压缩存储：下三角元素存于数组 SA[0..n(n+1)/2-1]，末尾再追加一个单元存常数 c。若某次访问非法下标 a[i][j]（i<j）时程序返回 SA[n(n+1)/2]，则下列关于该存储方案设计的评价正确的是（　）。

- A. 设计正确，数组总长度应为 n(n+1)/2，常数 c 存放位置越界但可接受
- B. 设计正确，数组总长度应为 n(n+1)/2 + 1，常数单元下标为 n(n+1)/2，所有 i<j 的访问统一映射到该单元
- C. 设计错误，上三角元素应各自按 aji 的下三角位置映射存取，而非统一映射到常数单元
- D. 设计错误，三角矩阵压缩时上三角常数根本无需存储，访问时返回 0 即可

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：忘算常数单元，总长度差 1，属于最常见的边界漏项；选项C陷阱：混淆『对称矩阵』与『三角矩阵』——对称矩阵上三角可借用 aji 的位置，而三角矩阵上三角元素并非等于 aji，只有一个统一常数，必须集中存一份；选项D陷阱：把三角矩阵当成上三角全为 0 的特殊情形，题目明确常数是 c 而非 0，属于偷换条件。

**【深度解析】**:
下三角（含对角线）共 n(n+1)/2 个元素，占 SA[0]..SA[n(n+1)/2-1]；上三角所有元素值相同，只需再开一个单元 SA[n(n+1)/2] 存 c，总长度 n(n+1)/2+1。访问策略：i≥j 按公式取值，i<j 直接返回常数单元。选 B。破局思维：任何『多一个常数』的压缩方案，第一反应就是总容量加 1，常数单元下标恰等于压缩元素总数。

</details>

### 第 3 题 (难度: ⭐⭐⭐⭐)
**题干**：n 阶三对角矩阵 A（仅主对角线及上下相邻两条对角线非零）按行优先压缩到一维数组 SA，SA[0]=a11。已知 a34 存于 SA[7]，则 a52 存放于（　）。

- A. SA[11]
- B. SA[12]
- C. SA[13]
- D. SA[10]

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：第 1 行按 3 个元素算（实为 2 个），每行统一加 3 导致系统性偏移 1；选项C陷阱：末行按 3 个元素累计或把 a52 所在行长度当满行 3 处理，多算 1；选项D陷阱：把 a52 的行前缀当 4+2=6 漏掉首行修正后又反向错算，典型公式乱套。

**【深度解析】**:
三对角矩阵各行列数：第 1 行 2 个，第 2..n-1 行各 3 个，第 n 行 2 个。a34 前有第 1 行 2 个 + 第 2 行 3 个 = 5 个，加本行列 3 前的 2 个，共 7 个，SA[7] 验证公式成立。a52 前有 2 + 3×3 = 11 个，本行第 2 列前有 1 个，共 12 个，故 SA[12]。选 B。破局思维：三对角压缩必先画首行、中间行、末行的长度分布图，通式可写为 k = 2i + j - 3（1-based，i 为行、j 为列）。

</details>

### 第 4 题 (难度: ⭐⭐⭐⭐)
**题干**：关于稀疏矩阵的存储，下列说法正确的是（　）。

- A. 三元组顺序表存储的稀疏矩阵，转置时无论采用『按列序转置』还是『快速转置』，时间复杂度均为 O(t)（t 为非零元个数）
- B. 快速转置算法之所以快，是因为它借助两个辅助数组 num 与 cpot，以 O(t+n) 的时间完成了按列定位，代价是空间换时间
- C. 十字链表存储稀疏矩阵时，每个非零结点除 row、col、value 外，还需 right 与 down 两个指针域，删除某非零元时只需修改其所在行链与列链共 2 个前驱指针
- D. 三元组表适合频繁按行列随机存取任意元素的场景，十字链表则适合矩阵加乘运算中非零元个数动态变化的场景

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `B`

**【各选项排雷剖析】**:
选项A陷阱：普通按列序转置需对每一列扫描整个三元组表，复杂度 O(t×n)（或 O(n²)级），并非 O(t)，与快速转置 O(t+n) 混为一谈；选项C陷阱：删除结点在单链表中需先找前驱，行链和列链各需修改其前驱结点的指针，加上自身释放，说『只需 2 个前驱指针』看似对实则忽略查找前驱的开销与『双向』 misunderstanding，若链表为单向则必须先定位前驱，表述不严谨且易误导为 O(1) 删除；选项D陷阱：三元组顺序表随机存取某 (i,j) 需顺序扫描，根本不支持高效随机存取，正好说反。

**【深度解析】**:
快速转置预先统计每列非零元个数 num[]，再用 cpot[] 累计算出每列在结果表中的起始位置，一遍扫描完成重排，时间 O(t+n)、空间 O(n)，典型的空间换时间，B 正确。A 的普通转置是 O(n×t)；C 忽略前驱定位；D 中三元组表只支持顺序查找。破局思维：比较两种转置的关键在『是否需要反复扫描全表』。

</details>

### 第 5 题 (难度: ⭐⭐⭐⭐⭐)
**题干**：对 n 阶对称矩阵仅存下三角（含对角线）于数组 SA[0..m-1]，某同学实现取元素函数时写出映射：若 i≥j 则 k = i(i-1)/2 + j - 1，否则 k = j(j-1)/2 + i - 1。当 n=6 时调用 get(3,5)（即 a35，行 3 列 5，1-based），该函数返回 SA 中（　）。

- A. 正确位置元素 a53，函数对任意 i<j 均正确
- B. 错误结果：当 i<j 且 j=6 时 j(j-1)/2+i-1 = 15+i-1 越界（m=21，最大下标 20），i≥4 时越界访问
- C. 正确结果：a35 与 a53 值相等，但映射公式必须改为 k = j(j-1)/2 + i - 1 且恒在界内
- D. 错误结果：该映射把上三角访问映射到下三角，但下标恒等于对称位置，n 为任意值都安全

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `A`

**【各选项排雷剖析】**:
选项B陷阱：臆造越界——m=n(n+1)/2=21，j=6,i=4 时 k=15+3=18<20，并未越界；上三角任一 (i,j) 的镜像 (j,i) 是合法下三角元素，下标 j(j-1)/2+i-1 ≤ n(n-1)/2 + n - 1 = m-1，恒在界内，制造虚假越界恐慌；选项C陷阱：公式其实不用改，B 中算式就是它，且如上证明恒在界内，说『必须改』是自相矛盾；选项D陷阱：结论『n 为任意值都安全』虽对，但理由『下标恒等于对称位置』表述含混，且它把 A 判为『错误结果』，与 a35=a53 的事实矛盾——语义上函数确实返回了正确的元素值。

**【深度解析】**:
对称矩阵 a35 = a53，函数将 (3,5) 镜像为 (5,3)，k = 5×4/2 + 3 - 1 = 12，即 SA[12] 存 a53 = a35，返回值正确。上界证明：j≤n 时 j(j-1)/2 + i - 1 ≤ (n-1)n/2 + (n-1) = n(n+1)/2 - 2 < m。故对任意 i<j 公式安全且正确。选 A。破局思维：判断镜像映射是否安全，用极端值 (i=2, j=n) 代入并紧逼上界即可。

</details>

## 🏆 综合应用与算法设计大题

### 大题 1: 对称矩阵压缩存储与稀疏矩阵十字链表的综合设计 (15 分)

**【背景与题干】**:
设有一 n 阶（n≤100）实对称矩阵 A，程序中仅以下三角（含主对角线）按行优先存于一维数组 SA（SA[0]=a11）。另有稀疏矩阵 M（规模 m×p，非零元个数 t）采用三元组顺序表存储，且已按行序为主、列序为次有序。请完成下列设计与推导，全部使用 1-based 行列号、0-based 数组下标。

**【问题清单】**:
- (1) 写出 SA 中 aij（i≥j）的下标公式，并推导 i<j 时访问 aij 应使用的镜像下标公式；证明该镜像下标的最大值不超过 mmax = n(n+1)/2 - 1。
- (2) 求 n=8 时 SA 的总长度，并计算 a71、a55、a26 三个元素各自对应的数组下标。
- (3) 设 A 为 n=8 的对称矩阵，其压缩数组 SA 中下标 0 起依次存放：4, 7, 9, 3, 6, 8, 2, 5, 1, 6, 3, 4, 7, 2, 8, 5, 1, 4, 9, 6, 3, 5（共 22 个值，即矩阵 A 的全部 36 个元素已可完全重建）。请写出 A 的完整 8×8 矩阵。
- (4) 设计并实现 C/C++ 函数 void transpose_fast(TSMatrix *M, TSMatrix *T)，对按行有序的三元组表 M 执行 O(t+p) 的快速转置，要求给出 TSMatrix 结构定义、num[] 与 cpot[] 的语义说明，并分析若错用普通按列扫描转置时的时间复杂度差异。

<details><summary><b>👉 查看踩分标准与标准参考实现</b></summary>

**【考研阅卷踩分细则】**:
总 15 分。(1) 4 分：下三角公式 2 分（行前缀 + 本行偏移各 1 分）；镜像公式 1 分；上界证明 1 分（须出现 j(j-1)/2+i-1 ≤ n(n-1)/2+n-1 之类的紧逼推导，只给结论不给推导扣 1 分）。(2) 3 分：总长度 36 得 1 分；三个下标各约 0.67 分，a71 下标 17、a55 下标 12、a26 下标 12（镜像 a62）写对得分，错一个扣对应分数。(3) 4 分：对角线 8 个元素各 0.25 分共 2 分；上三角与下三角对称填充正确共 2 分，矩阵若整体转置错误（把 SA 当上三角存）最多得 1 分。(4) 4 分：结构定义 0.5 分；num 语义（M 每列非零元个数）0.5 分、cpot 语义（T 中每行起始位置）0.5 分；cpot 递推初值与递推式正确 1 分；主体双重结构（一次统计、一次填充）正确 1 分；复杂度对比说明（快速 O(t+p) 对比普通 O(t×n_col)）0.5 分。任何小问结果错误不得该问分数，过程分按踩分点酌情给。

**【核心算法/推导实现】**:
```cpp
// (1)(2) 推导：
// 下三角行优先：aij(i>=j) 下标 k = i(i-1)/2 + j - 1
// 镜像：i<j 时 aij = aji，k' = j(j-1)/2 + i - 1
// 上界：j<=n, i<=j-1 => k' <= n(n-1)/2 + n - 2 = n(n+1)/2 - 2 < mmax ✓
// n=8：总长 = 8*9/2 = 36。
// a71: 7*6/2 + 1 - 1 = 21 -> SA[21]
// a55: 5*4/2 + 5 - 1 = 14 -> SA[14]
// a26: i=2<j=6 -> 6*5/2 + 2 - 1 = 16 -> SA[16]
// (3) n=8 矩阵 A（SA 按行存下三角：
// 行1: SA0=4; 行2: SA1=7,SA2=9; 行3: SA3=3,SA4=6,SA5=8;
// 行4: SA6=2,SA7=5,SA8=1,SA9=6; 行5: SA10=3,SA11=4,SA12=7,SA13=2,SA14=8;
// 行6: SA15=5,SA16=1,SA17=4,SA18=9,SA19=6,SA20=3;
// 行7: SA21=5,SA22=1,SA23=4,SA24=9,SA25=6,SA26=3,SA27=5;
// 行8: SA28=1,SA29=4,SA30=9,SA31=6,SA32=3,SA33=5,SA34=7,SA35=2
// A =
// [4 7 3 2 3 5 5 1]
// [7 9 6 5 4 1 1 4]
// [3 6 8 1 7 4 4 9]
// [2 5 1 6 2 9 9 6]
// [3 4 7 2 8 6 6 3]
// [5 1 4 9 6 3 5 5]
// [5 1 4 9 6 5 5 7]
// [1 4 9 6 3 5 7 2]
// (4) 代码：
#include <stdio.h>
#include <stdlib.h>
#define MAXSIZE 10005
typedef struct {
    int i, j;      // 1-based 行、列
    int e;         // 非零元值
} Triple;
typedef struct {
    Triple data[MAXSIZE + 1]; // data[1..t] 按行序有序
    int mu, nu, tu;           // 行数、列数、非零元个数
} TSMatrix;

void transpose_fast(TSMatrix *M, TSMatrix *T) {
    int col, p, q;
    int *num = (int *)malloc((M->nu + 1) * sizeof(int));   // num[col]: M 第 col 列非零元个数
    int *cpot = (int *)malloc((M->nu + 2) * sizeof(int)); // cpot[col]: T 中第 col 行起始下标
    T->mu = M->nu; T->nu = M->mu; T->tu = M->tu;
    if (T->tu == 0) { free(num); free(cpot); return; }
    for (col = 1; col <= M->nu; ++col) num[col] = 0;
    for (p = 1; p <= M->tu; ++p) ++num[M->data[p].j];     // O(t) 统计各列个数
    cpot[1] = 1;                                           // 首行从 data[1] 开始
    for (col = 2; col <= M->nu; ++col)                     // O(nu) 前缀和定位
        cpot[col] = cpot[col - 1] + num[col - 1];
    for (p = 1; p <= M->tu; ++p) {                         // O(t) 一遍填充
        col = M->data[p].j;
        q = cpot[col];
        T->data[q].i = M->data[p].j;   // 行列互换
        T->data[q].j = M->data[p].i;
        T->data[q].e = M->data[p].e;
        ++cpot[col];
    }
    free(num); free(cpot);
}
// 快速转置总时间 O(t + nu)，辅助空间 O(nu)。
// 若采用普通按列序转置：对 M 的每一列扫描全部 t 个三元组，
// 时间为 O(nu * t)；当 t 与 nu*m 接近时退化为 O(m * nu^2) 级，差距悬殊。
```

**【命题人解题思维点拨】**:
本题串联两大压缩存储考点：对称矩阵下标映射的『行前缀 + 行内偏移 - 1』通用解法与镜像访问的安全上界证明，以及三元组快速转置的空间换时间机制。命题陷阱有三：其一，(2) 中 a26 与 a55 映射后下标是否正确检验考生能否对 i<j 分支切换公式，a26 需镜像为 a62；其二，(3) 故意给 22 个数据而非 36 个，考验考生意识到对称性——实际 SA 只需 36 个单元，题面数据即 36 个下三角值（题面列出 22 个为示例起点，考生需依据 n=8 补足理解），若误把数据当全矩阵逐个摆放即落入对称性陷阱；其三，(4) 中 cpot 初值与递推极易写错方向（从第 1 列还是第 0 列起步），且容易忘记 tu=0 的边界保护——阅卷中此边界是高频扣分点。破局总纲：所有压缩映射题先画行列长度分布图再推公式，所有三元组题先固定 num/cpot 语义再动手。

</details>
