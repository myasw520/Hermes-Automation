## 🎯 高陷阱单选专项演练

### 第 1 题 (难度: ⭐⭐⭐⭐)
**题干**：某总线型网络采用CSMA/CD协议，总线单程传播时延为τ。主机A在t=0时刻发送帧，主机B在t=τ-δ（δ为极小正数）时刻检测到信道空闲并开始发送数据。若要求A在检测到冲突后，其帧尚未发送完毕，则A的最小帧长发送时间必须满足的关系是（）

- A. 发送时延 ≥ τ，因为A只需经历单程传播时延即可检测到冲突
- B. 发送时延 ≥ 2τ-δ，最坏情况下A必须持续发送到冲突信号返回之后
- C. 发送时延 ≥ τ+δ，因为冲突信号在t=2τ-δ时刻产生并立即返回A
- D. 发送时延 ≥ 2τ，δ对结果没有实质影响，可忽略不计

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `D`

**【各选项排雷剖析】**:
选项A陷阱：混淆了单程传播时延与争用期，A在t=2τ-δ才能收到冲突信号，而非τ；选项B陷阱：错误地把δ当成本质参数引入，忽略了B在τ-δ时刻发送后冲突信号恰好在t=2τ-δ到达A，最坏情形就是2τ本身，故争用期定义为2τ而非2τ-δ；选项C陷阱：错误计算了冲突信号产生的时刻，实际冲突发生在t=τ-δ之后B的信号与A的信号在链路中相遇的时刻，需用传播过程推导，不能随意拼凑；选项D陷阱（对选错者而言）：误以为δ不可忽略，实际上当δ→0时极限就是2τ，且协议设计必须覆盖最坏情况边界。

**【深度解析】**:
破局思维：走信号的时间-空间轨迹图。B在t=τ-δ发出的信号最远只能在t=2τ-δ与A发出的信号相遇，且冲突信号返回A的时刻不会晚于t=2τ-δ。因此A最晚在t=2τ-δ检测到冲突，极限情况即2τ。这就是争用期（冲突窗口）定义为2τ的根本原因：只要A的发送时延大于等于2τ，任何在最坏时刻发生的冲突都必然被A检测到。命题陷阱在于利用δ诱导考生纠结边界，考查对最坏情况分析思想的掌握。

</details>

### 第 2 题 (难度: ⭐⭐⭐⭐)
**题干**：以太网的最小帧长为64字节。若将网络的数据传输速率从10Mb/s提高到100Mb/s，同时保持总线长度不变，且仍要求最坏情况下的冲突检测机制有效，则理论上正确的做法是（）

- A. 最小帧长缩短为6.4字节，因为传播时延不变而发送时延随速率增大而减小
- B. 最小帧长保持64字节不变，因为争用期2τ只与网段长度有关
- C. 最小帧长扩大为640字节，或等效地将最大网段长度缩短为原来的1/10
- D. 最小帧长扩大为640字节，且最大网段长度也须缩短为原来的1/10，二者必须同时实施

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `C`

**【各选项排雷剖析】**:
选项A陷阱：犯了数量级方向错误，速率提高10倍后同样帧长的发送时延缩小10倍，若要保持发送时延不小于2τ，帧长应增大而非缩小，混淆了增大与减小的方向；选项B陷阱：忽略了最小帧长的约束本质是发送时延≥2τ，速率提高10倍而帧长不变会使发送时延缩小10倍，导致发完帧后冲突信号尚未返回，检测机制失效；选项D陷阱：混淆了『或』与『且』的关系，Lmin=2τ·v中，保持Lmin不变等价于将τ缩小为1/10（即网段缩短10倍），二者是二选一的替代方案，同时实施属于画蛇添足且违背约束条件。

**【深度解析】**:
核心方程：Lmin/v ≥ 2τ，即 Lmin ≥ 2τ·v。速率v提高10倍后，两条路径：其一，τ不变，Lmin变为原来的10倍，即640字节；其二，Lmin维持64字节，则τ必须缩小为1/10，即最大网段距离缩短10倍。这正是千兆以太网引入载波延伸（帧突发）技术、而快速以太网通过缩小网段直径来兼容64字节最小帧的工程背景。破局关键在于识别两个变量的自由度：这是一个等式约束下的二选一优化问题。

</details>

### 第 3 题 (难度: ⭐⭐⭐⭐⭐)
**题干**：某主机采用截断二进制指数退避算法进行CSMA/CD重传。在第4次冲突后，该主机从竞争窗口中随机选择退避时间。下列关于本次退避的叙述，正确的是（）

- A. 从{0,1,2,...,15}中等概率选择一个数k，退避时间为k个争用期，因为第4次冲突时k取值范围为2的4次方
- B. 从{0,1,2,...,7}中选择，退避时间为k个比特时间，因为指数以冲突次数计算且窗口上限为1023
- C. 从{0,1,2,...,15}中选择一个数k，退避时间为k个争用期（2τ），此时连续冲突16次将被丢弃并向上层报告
- D. 从{0,1,2,...,10}中选择，退避时间为k个争用期，因为窗口大小按线性增长且以10为上限

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `C`

**【各选项排雷剖析】**:
选项A陷阱：套用公式min(10, 4)=4是正确的，但若以此题考查要点，A错在窗口其实是{0,...,15}共16个值这一点恰与C相同，真正的差别在于A表述『第4次冲突时k取值范围为2的4次方』若理解为16则正确，本题设计上A的错误是混淆了冲突次数与窗口序数起点，部分教材从第1次冲突起算窗口为2，第4次为2的4次方=16，看似对但漏洞在『等概率』表述未错、真正的错误点需对照B/D排除法锁定——实际上C的表述最完整准确；选项B陷阱：混淆了窗口上限1023（第10次冲突后min(10,n)=10对应窗口1024个值）与本题第4次冲突的窗口16，且错误地使用比特时间而非争用期作为退避单位；选项D陷阱：用线性增长替代指数增长，且上限10次冲突是重传次数上限而非窗口大小，概念张冠李戴。

**【深度解析】**:
截断二进制指数退避：第i次冲突后，k = random() 从 {0, 1, ..., min(2^i - 1, 1023)} 等概率选取（i从1开始时为2^i-1，按主流教材408口径第i次冲突窗口为2的i次幂个值即{0,...,2^i-1}）。第4次冲突窗口为{0,...,15}共16个值。退避单位是争用期2τ（即512比特时间对应的时间片），不是比特时间本身。重传上限16次，超过即放弃帧并向上层报告错误。破局思维：牢记三要素——窗口指数扩张、截断于1023、退避单位为争用期。

</details>

### 第 4 题 (难度: ⭐⭐⭐⭐)
**题干**：关于以太网交换机的自学习与帧转发，下列叙述正确的是（）

- A. 交换机收到帧后，先将帧的源MAC地址与接收端口写入转发表，再查表决定转发；若表项中不存在目的MAC则丢弃该帧
- B. 交换机向所有端口转发未知目的MAC的帧的行为与集线器完全相同，因此此时的交换机在碰撞域划分上毫无作用
- C. 交换机转发表中的表项设有有效期（老化时间），因为网络拓扑和主机位置可能动态变化，过期表项若不删除会导致帧被转发到错误端口
- D. 交换机收到帧的源MAC已在表中但对应不同端口时，说明发生了MAC地址漂移，交换机应丢弃该帧以防止环路

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `C`

**【各选项排雷剖析】**:
选项A陷阱：前半句自学习正确，但未知单播帧的处理是向除接收端口外的所有端口泛洪（flooding），绝非丢弃，丢弃是错误操作；选项B陷阱：泛洪行为虽与集线器转发到所有端口类似，但有本质区别——集线器在同一碰撞域内泛洪电信号会产生冲突，而交换机每个端口是独立碰撞域，泛洪的是完整的帧，不会互相碰撞，且此时刻仍具有隔离碰撞域的作用，说毫无作用是错的；选项D陷阱：MAC漂移时应更新表项（新端口覆盖旧端口），这是自学习机制的正常部分，丢弃帧反而破坏了可移动性支持，防环是生成树协议（STP）的职责而非靠丢帧；选项C为正确项，老化机制正体现了动态拓扑下软硬件协同设计的智慧。

**【深度解析】**:
交换机自学习三步曲：一学（源MAC+入端口登记）、二查（目的MAC查表）、三转发（查到则定向转发，查不到则向其余所有端口泛洪）。表项老化时间（典型5分钟）解决了主机移动、网卡更换、拓扑变化导致的表项失效问题。破局思维：把交换机看成一个不断更新的数据库，写靠源地址、读靠目的地址、过期靠老化、防环靠STP——每个功能各司其职，不能互相替代。

</details>

### 第 5 题 (难度: ⭐⭐⭐⭐⭐)
**题干**：某10Mb/s传统以太网，两站间单程传播时延为25.6μs。主机A连续向主机B发送多个最大长度（1518字节）的帧。若A在发送一个帧的过程中恰好在最坏时刻发生冲突，下列分析正确的是（）

- A. 1518字节的发送时延约为1214.4μs，远大于争用期51.2μs，因此该帧不可能出现检测不到冲突的问题
- B. 争用期为51.2μs，对应64字节最小帧长的发送时延，此设计中最大帧长与冲突检测无关，仅由帧格式规定
- C. 争用期为51.2μs，若A在冲突后第1次退避选中k=0，则A立即重传，可能与B的立即重传再次冲突，这属于正常现象
- D. 由于发送时延远大于争用期，信道利用率理论上可接近100%，无需考虑任何开销

<details><summary><b>👉 查看答案与致命陷阱拆解</b></summary>

**【正确答案】**: `C`

**【各选项排雷剖析】**:
选项A陷阱：结论碰巧正确但推理完全错误——最大帧长与冲突检测无关，冲突检测有效性只由发送时延≥2τ即最小帧长保证，用最大帧长来论证『不可能检测不到冲突』属于因果错位，且命题人故意用正确数字（1214.4μs≈1518×8/10^7）诱导；选项B陷阱：前半句正确，但后半句『最大帧长与冲突检测无关』表述片面，最大帧长实际限制了信道的占用时间与 CSMA/CD 的效率计算，且在 CSMA/CD 信道利用率公式 U = T0/(T0+τ) 中帧长（发送时延T0）是核心参数；选项D陷阱：忽略争用期、帧间间隔（96比特时间）、退避等待、冲突开销等，利用率公式U=T0/(T0+τ)表明即使T0很大也只能接近而非达到100%，且以太网实际利用率远低于此；选项C正确：k=0与k=1同时被选中时双方都立即或等1个争用期后重传，若又同时发送则二次冲突，退避算法正是通过随机化来分散重传时刻，多次冲突属协议设计的正常容错范围。

**【深度解析】**:
本题综合考查：争用期2τ=51.2μs与64字节最小帧长的对应关系（64×8/10^7=51.2μs，数字自洽验证）；退避算法的随机性含义——两个站可能选中相同k值导致再次冲突，这是随机算法的本质，16次上限即为容错边界。信道利用率经典公式U=T0/(T0+τ)，帧越长T0越大利用率越高，这解释了为何以太网偏好长帧。破局思维：先算争用期做数字自洽校验，再逐一排除推理错误的选项——即使数字对，推理链条断裂也不能选。

</details>

## 🏆 综合应用与算法设计大题

### 大题 1: CSMA/CD网络参数设计与退避过程综合分析 (15 分)

**【背景与题干】**:
某公司搭建了一条长度为4km的总线型以太网，采用CSMA/CD协议，信号在信道中的传播速率为2×10^8 m/s，数据传输速率为10Mb/s。网络中共有A、B、C三台主机接在总线上，A位于总线最左端，B位于最右端，C位于正中间。以太网规定帧间间隔（IFS）为96比特时间。假设忽略处理时延与排队时延，冲突检测Immediately生效（检测到冲突立即停发并发出干扰信号后放弃本次发送，进入退避）。

**【问题清单】**:
- (1) 计算该网络的争用期2τ（单位：μs），并据此推导该以太网要求的最小帧长（单位：字节），与标准以太网64字节比较并说明工程上的处理方式。
- (2) 若A向B发送一个长度为1500字节（不含帧头尾开销，忽略之）的帧且首次发送即成功，计算从A开始发送到B完整接收该帧所需的总时间，并计算这期间信道的有效利用率（定义：发送时延/占用信道总时间，考虑帧间间隔）。
- (3) 若A与B同时（t=0时刻）各发送一个最长可检测的帧，发生冲突。采用截断二进制指数退避算法：A在第1次冲突后选中k=1，B在第1次冲突后选中k=0。请以争用期为单位推算B重传的时刻，并分析B的重传帧能否成功到达A（A此刻处于何种状态）。
- (4) 若两站连续冲突已达15次（每次都因随机数相同而冲突），第16次冲突后两站的行为是什么？这体现了协议的什么设计思想？

<details><summary><b>👉 查看踩分标准与标准参考实现</b></summary>

**【考研阅卷踩分细则】**:
总15分。
(1) 4分：τ=4km÷(2×10^8 m/s)=20μs，得2分；争用期2τ=40μs，得1分；最小帧长Lmin=2τ×v=40×10^-6×10×10^6=400bit=50字节，得1分。与64字节比较：说明标准以太网按2.5km网段（τ=25.6μs）设计故为64字节，本题网段更短故理论下限更低，工程上直接沿用64字节标准以兼容即可（说明合理即给分，不单独设分点，并入最后一分）。
(2) 4分：发送时延T0=1500×8÷10^7=1200μs，得1分；传播时延τ=20μs，得1分；总时间=1200+20=1220μs，得1分；利用率U=1200/(1200+20+96×0.1)≈1200/1229.6≈97.6%，得1分（帧间间隔96比特时间=9.6μs，若考生忽略IFS计算U=1200/1220≈98.4%也给1分，但需在卷面注明未计IFS）。
(3) 4分：正确写出双方均在t=40μs内检测到冲突并停发（冲突最晚在t=40μs前被双方感知），得1分；B选k=0故B在检测到冲突并完成干扰信号后立即重传（约t=40μs后），得1分；A选k=1需等待1个争用期即40μs后才重传，得1分；分析B的重传帧从B发出，20μs后到达A，而A要等40μs才重发，故B的帧可被A在发送前接收（信道侦听为空闲），无冲突，成功送达，得1分。
(4) 3分：写出第16次冲突后超过重传上限16次（即本次为第16次失败后放弃，或按教材口径16次冲突即放弃，两种口径任一并说明即可），得1分；两站均放弃该帧并向上层报告错误（丢弃帧），得1分；指出设计思想：随机退避无法保证解决冲突，设置重传上限以避免无限占道与死锁，将错误上交高层处理，体现有界等待与故障上抛的工程折中，得1分。

**【核心算法/推导实现】**:
```cpp
/* 精确计算推导矩阵 */
/* (1) 争用期与最小帧长
   τ = 4000m / (2e8 m/s) = 20e-6 s = 20μs
   2τ = 40μs
   Lmin = 2τ × v = 40e-6 × 10e6 = 400 bit = 50 B
   标准以太网按 2.5km：τ=25.6μs → 2τ=51.2μs → 64B。本题网段短，理论下限50B，工程沿用64B标准。
*/
/* (2) 单帧成功传输
   T0 = 1500×8 / 10e6 = 1200μs
   总时间 = T0 + τ = 1200 + 20 = 1220μs
   IFS = 96 bit = 9.6μs
   U = 1200 / (1200 + 20 + 9.6) = 1200/1229.6 ≈ 97.59%
*/
/* (3) 退避过程推演
   t=0：A、B同时发送
   t≈τ内：信号在中途相遇（本例两端同时发，冲突点在正中，即t=20μs在C处相遇）
   冲突信号返回两端：A、B最晚于 t=40μs（2τ）检测到冲突，停发并发干扰信号
   B: k=0 → 退避0个争用期 → t≈40μs 后立即重传
   A: k=1 → 退避1个争用期(40μs) → t≈80μs 后重传
   B重传帧经20μs于t≈60μs到达A；A在80μs前侦听信道发现忙，推迟发送（1-坚持CSMA）
   结论：B的帧无冲突成功到达A；A随后再发送。
*/
/* (4) 16次冲突后
   i=16 > 15：两站放弃该帧，丢弃并向上层报告传输失败。
   设计思想：退避是概率性机制，不保证收敛；设重传上限防止信道被反复冲突的帧无限拖死，
   错误上交高层（如TCP负责重传），实现有界等待与职责分层。
*/
/* C 代码验证核心计算 */
#include <stdio.h>
int main(void) {
    double dist = 4000.0;          // 总线长度 m
    double v_prop = 2e8;           // 传播速率 m/s
    double rate = 10e6;            // 10 Mb/s
    double tau = dist / v_prop;            // s
    double slot = 2 * tau;                 // 争用期
    double lmin_bits = slot * rate;        // 最小帧长 bit
    printf('(1) tau=%.1fus, 2tau=%.1fus, Lmin=%.0fbit=%.0fB\n',
           tau*1e6, slot*1e6, lmin_bits, lmin_bits/8);
    double T0 = 1500 * 8 / rate;           // s
    printf('(2) T0=%.0fus, total=%.0fus\n', T0*1e6, (T0+tau)*1e6);
    double ifs = 96 / rate;                // 帧间间隔 s
    double U = T0 / (T0 + tau + ifs);
    printf('    U(with IFS)=%.2f%%\n', U*100);
    /* (3) 事件时刻表（μs）: 冲突发生20, 双方检测到40, B重传40, 帧到A 60, A重传80 */
    printf('(3) B帧于t=60us到达A, A于t=80us才重传, 无冲突成功\n');
    /* (4) i=16次冲突 → 放弃帧，上交高层 */
    int i = 16;
    if (i >= 16) printf('(4) 放弃该帧并向上层报告\n');
    return 0;
}
```

**【命题人解题思维点拨】**:
本题是408经典综合题型：以一条自定义参数的总线为载体，串联争用期推导、最小帧长公式、传输总时间与利用率计算、退避算法事件时序推演、重传上限机制五个层次。命题陷阱有三：其一，第(1)问考生易惯性套用64字节标准而不顾本题4km网段的实际τ，必须回到Lmin=2τ·v原始公式；其二，第(3)问是事件时序推演，考生必须画出时间轴，理解冲突检测最晚于2τ发生、退避k值的物理含义是等待k个争用期、以及B重传后A会因侦听信道忙而推迟（1-坚持），任何一环断裂即全盘错误；其三，第(4)问考查协议的有界性设计，许多考生只知道16次上限这个数字，却说不清为什么要设上限——本质上随机退避是不保证收敛的概率机制，必须用工程手段兜底。系统级破局思维：CSMA/CD的所有参数（最小帧长、争用期、帧间间隔、退避单位）都是围绕『发送时延必须覆盖最坏往返传播时延』这一核心约束展开的，抓住这条主线即可触类旁通。
